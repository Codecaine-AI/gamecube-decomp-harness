# Docs Tree Audit

Interactive interview objective: agree the order, numbering, index accuracy, and
block-structure hygiene of the `docs/` tree with Ford section by section, record
every decision in `target_structure.md`, then apply agreed changes via
`codex exec` scoped per approved section.

- `goal.md` — execution contract.
- `target_structure.md` — the living agreement. Source of truth for what gets
  applied. Nothing is edited in `docs/` that is not agreed there first.
- `current_state.md` — resume point for the interview thread.
