### Trace stream `mwcc-trace-v1` (JSON lines written by the traced compiler)

Every line: `{"v":1,"fn":"<mangled>","pass":<int>,"cls":"gpr|fpr|vr|-","ev":"<event>", ...}`. Events:

| `ev` | Fields |
|---|---|
| `function` | `name` (mangled), `display` |
| `vreg` | `vreg`, `kind` (`arg\|local\|temp\|backend_temp\|toc`), `object` (name or `@NNN`), `decl_file`, `decl_line`, `origin` (temp: creating pass + expression text when available), `web` |
| `node` | `vreg`, `degree`, `neighbors` [vreg], `coalesced` (bool), `spill_cost` |
| `push` | `vreg`, `sweep`, `stalled` (bool), `cost_ratio` (when stalled) |
| `color` | `vreg`, `color`, `order` (pop index) |
| `commit` | `vreg`, `reg` (physical, e.g. `r31`, `f1`) |
| `coalesce` | `a`, `b`, `reason` |
| `spill` | `vreg` |
| `inline` | `site` (file:line), `callee`, `pass_index`, `stmt_count`, `verdict` (`inlined\|called`), `reason` |
| `cse` | `temp`, `expr`, `block`, `occurrence` |
| `frame_slot` | `offset`, `size`, `align`, `owner` (object or `@NNN`) |

Unknown fields are allowed; consumers ignore them.

Amendments after integration (S4/S5): `pass` is 0-based; `node.spill_cost` may be null (costs exist only after a stall) and a `node_cost` event `{vreg, cost}` carries them; every record's `fn` is the mangled name (plain name in optional `display`); `decl_file` is the include-resolved path; unknown positions are null, never `?:0`. 1.1p1 is not provisionable (CAPABILITIES lists no points). Migrations after S2/S3: the version-pinned migration tests expect v17; S9's 018 bumps them to v18.

### `mwcc_alloc` operations (new; existing `pcode`/`pair`/`trace`/`coloring` unchanged and stay qemu in milestone 1)

- `api/snapshot.py --capture coloring-native|decisions --unit <unit> --function <name> [--backend auto|native|qemu] [--out <dir>]`
  - `coloring-native` → `mwcc-coloring-snapshot-v1` (same schema the qemu coloring capture writes) plus provenance `{backend, traced_sha1, stock_identity, version}`.
  - `decisions` → `mwcc-decisions-v1`: `{schema, function, unit, version, backend, available_points, unavailable_points, vregs[], inlines[], cse[], frame_slots[], coloring{gpr,fpr}}` derived from the trace stream.
- `api/compare_sources.py --unit <unit> --function <name> --a <manifest.json|@worktree|@base[:rev]|@revert:<file>:<line-range>> --b <...> [--out <dir>]`
  - Manifest: `{"files": {"<repo-relative path>": "<content>" | null}}` (null = deleted), relative to the given base revision (default the sandbox checkout's HEAD).
  - Compiles both variants with the stock compiler and the traced compiler in shadow roots (`stack_check.make_shadow_root`/`compile_in`); requires traced object == stock object per variant (else `{"unavailable":"traced-object-mismatch"}`).
  - Output `mwcc-decision-diff-v1`: `{schema, function, unit, version, available_points, unavailable_points, stock:{a_obj_sha, b_obj_sha, code_class}, changes:[{kind, summary, a, b, match:"exact|by_site|by_origin|ambiguous"}], summary_lines:[...]}`. `kind` ∈ `node_added, node_removed, degree, coalesce, color_order, register, spill, inline_verdict, cse_temp, frame_slot`.
  - Identity across captures: match by function, pass, class, then `decl_file:decl_line` + `object`, then temp `origin`; never by raw vreg number.

### Packet fields (worker context XML)

- `previous_attempt variant="unverified_match"` gains attributes/children: `trusted_base_rev`, `source_path`, `total_edits`, `omitted_edits`, `full_report_locator` (sandbox path, e.g. `build/steering/reports/<observation_id>.json`), and `open_reviews` (evidence-review requests pending for this target).
- When the gate is active and a target has open evidence reviews but no `previous_attempt`, a standalone `open_reviews` block (same rows) renders in the steering-probe section.
- `steering_probe` JSON gains `compiler_delta`: either `{summary_lines:[...], changes:[...], version, observation_id}` or `{unavailable:"<reason>"}`.

### Server-side state

- Certified baseline per target: `(run/game, unit, symbol) → {certified_score, revision, certificate_hash, attempt_id}`.
- Budget grant ledger: `(target, certificate_hash, revision)` unique.
- Restoration record: `(target, trusted_base_rev, proof_hash)`.
- Evidence-review request: `{id, game, unit, symbol, base_rev, site_file, site_lines, group_digest, patch, evidence_json, status: open|approved|rejected, decided_by, note}`; unique on `(game, unit, symbol, group_digest)`.
- Site-bound approval record (gate approvals file): `{game, unit, target (mangled), base_rev, site_file, site_lines, group_digest, callee, symbol, approved_by, provenance}`.
- Explain job: `{observation_id, input_hash, tool_hash, status, compiler_delta_json, error}` unique on `(observation_id, input_hash, tool_hash)`.
