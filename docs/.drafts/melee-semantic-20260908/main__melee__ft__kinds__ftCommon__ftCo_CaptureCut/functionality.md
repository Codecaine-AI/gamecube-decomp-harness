### Release lifecycle

`ftCo_CaptureCut_Enter` first separates the linked pair, then tests the resulting ground/air situation. It writes `-facing_dir * p_ftCommonData->x370` to ground velocity or horizontal self velocity and enters `ftCo_MS_CaptureCut` with arguments 0, 1, 0 and `Ft_MF_None`. Animation completion delegates to `ftCommon_8007D92C`; that helper selects Fall for GA_Air and the grounded completion path otherwise. IASA is empty: it supplies no input-driven interruption, without proving immunity to external state changes. Ground physics applies `x36C * ground_friction` before ground movement; non-ground physics delegates to `ft_80084DB0`. Collision dispatch supplies complementary situation-transition adapters without directly replacing the CaptureCut motion state. ### Pair teardown and placement

`ftCo_800DC920` calls the unknown flag helper for both objects and selects internal roles using the first fighter's `x221B_b7`. Argument position alone does not identify captor versus captive. It clears `x1A5C`, `victim_gobj`, `x221B_b5`, and `x221B_b7` on both participants, with first-role clearing before placement and second-role clearing afterward.

Placement occurs only when role `var_r30` has `x2226_b2`. Kirby's two explicitly named neutral-special capture states refresh model scale and retain the participant's current position as the candidate. Other cases derive a candidate from XRotN, facing, scale and attachment offsets, flatten Z, and restore the joint translation. A connected-floor candidate is accepted only after the floor queries and `sp48 >= x3BC`; the floor index is assigned before that threshold test. This shortcut updates position and collision data but does not explicitly run either situation initializer. Otherwise the fallback starts from the other role's ECB midpoint, probes using ground or non-ground handling, and selects collision-resolved position on success or the candidate position on failure. Non-ground probing first unlocks the ECB. These branches attempt suitable placement; they do not justify an unconditional guarantee of legal placement. [Teardown](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_CaptureCut.c#L84-L196).

`ftCo_800DCE34` calls teardown before testing `gobj1`'s role flag. ### Damage and cross-file lifetimes

`ftCo_800DCFD4` treats its input as damage recipient and follows its still-live `victim_gobj` to the source fighter's `xDF4[1]`. It optionally resets collision when `x1988 != 0`, establishes aerial bookkeeping, transfers capsule-derived damage metadata and an XRotN-derived impact position, and invokes damage and knockback processing. Its final helper argument is exactly `0.0F`; no additional interpretation is required here. It does not directly clear the capture relationship. Throw cleanup calls this utility before teardown only in its `x221B_b5` branch; the other branch separates and invokes common completion without this damage call. Shouldered instead saves linked object, fighter and capsule references before teardown and uses those saved references afterward.
