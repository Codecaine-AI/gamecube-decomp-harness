## Unown and its swarm

The header explicitly identifies this module as Unown. Its four authored state-table rows serve two item kinds: the lead uses the table base, while the swarm registration uses `&it_803F7D60[3]`. Consequently, the fourth aggregate row is the child's local state **0**, not a fourth phase of the lead. See code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_279C.c#L271-L288 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_279C.c#L757-L774.

### Lead lifecycle

Initialization selects one of 26 forms, stores a random ±1 horizontal-acceleration sign, initializes the emission interval to zero and the remaining-emission count from attributes, and enters airborne appearance state 2. Its animation callback delegates appearance-scale processing. Its physics callback calls `it_8027A09C`, which applies gravity and updates the appearance countdown even when returning false; success gates the local velocity assignment and transition to departure state 0. Terrain contact delegates common collision processing with an empty local hook. See code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itunknown.c#L42-L86, code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itunknown.c#L183-L212 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_279C.c#L1077-L1130.

Departure state 0 applies shared gravity and signed horizontal acceleration. Its animation callback tests strict crossings of all four blast-zone bounds; equality does not trigger the transition. Crossing hides the model, clears velocity, chooses a random blast-zone edge and anchor, computes a stored camera-interest-directed velocity, enters state 1, selects one of two sounds and installs effect-hitlag callbacks. The anchor is stored separately rather than assigned directly to the lead's position. Shared gravity uses a pre-update threshold rather than clamping the resulting speed. See code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itunknown.c#L67-L158 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L176-L204.

Hidden state 1 pre-decrements its interval and submits a child spawn only when the result is negative. It then pre-decrements the remaining count and returns true only on exact zero; otherwise it reloads a base-plus-random interval. Its physics and collision callbacks are inert. Finite completion assumes a suitable positive initial count; the code does not special-case an initial zero or negative count. See code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itunknown.c#L160-L181.

### Child creation and lifetime

Each emission constructs one `It_Kind_Unknown_Swarm` descriptor. Jitter uses one third of camera height for either axis, depending on the stored edge selector. It assigns the randomized anchor to `prev_pos`, obtains `pos` separately through a helper, copies route velocity and facing, and supplies the owner and lead object as distinct parent fields. The creation result is ignored, so the scheduler counts attempts, not confirmed successful allocations. The spawn switch lacks a default for invalid selectors, although route setup supplies only 0–3. See code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itunknown.c#L214-L247.

Each child's own attributes and random draws initialize its form, lifetime and angular increments. The incoming velocity selects an axis once: strictly larger absolute X selects Y scaling; ties and larger absolute Y select X scaling. The selected component is multiplied initially by `x1C.f` and on subsequent physics ticks by `x20.f`; attenuation or convergence depends on the loaded values. Three angle accumulators advance without local wrapping and are converted to radians for model rotations. The animation callback pre-decrements lifetime and returns true at zero or below. The collision callback always returns false. Children therefore have their own timers rather than sharing the lead's emission counter. See code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itunknown.c#L249-L322.

Both event adapters forward to common interaction-reference cleanup. That helper clears matching owner, reflector, absorber, fighter and toucher references, with the corresponding source-player reset. This establishes reference cleanup, not a claim that every child is destroyed with the lead. See code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L474-L525.
