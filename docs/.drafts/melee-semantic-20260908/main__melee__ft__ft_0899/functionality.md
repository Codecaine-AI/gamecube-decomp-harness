## Floor-target helper
fn_8008998C reads ik->pos4 and copies the fighter GObj root translation through HSD_JObjGetTranslation2. That accessor asserts the JObj and copies its translate field. The helper zeroes the output normal, then queries mpLib_8004DD90_Floor using the current collision-floor index. The query may traverse connected floor lines and returns a relative Y correction, including a 0.0001 bias, rather than an absolute height. Its failure returns precede output-normal writes. On success the helper computes delta_y = pos4.y + floor_y - root.y. On failure it obtains the current floor's left endpoint and substitutes the right endpoint only if pos4.x exceeds left.x; this is not nearest-endpoint selection. The fallback correction is endpoint.y - root.y and the normal stays zero. The returned flags are unused, and the successful line index is not stored into Fighter. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0899.c#L32-L49; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/mp/mplib.c#L1097-L1173; code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/jobj.h#L574-L578.

If the initial absolute correction is strictly below 0.0001, the helper returns false without changing pos4. Equality proceeds. For unequal target/root X, it compares delta_y/delta_x to +/-0.45 and reconstructs delta_y at the exceeded bound. Equal X forces zero correction but still returns true. It then adds delta_y to pos4.y; no other pos4 component is written by this helper. True is therefore a solver gate, not proof of movement. In particular, the formula adds a floor-versus-root offset to the candidate target; without an additional geometric invariant it does not guarantee that distance from the target to the floor decreases. This narrows the librarian's retention of claims saying that it always moves the target toward the floor. No finite-value validation exists: NaNs can bypass comparisons, and infinities, overflow and underflow are not sanitized. Bounds describe ordinary finite arithmetic, not a universal numerical guarantee. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0899.c#L39-L70.
