## Sandbag initialization and WaitReverse

The owned C file defines Sandbag fighter resources, a single character-local MotionState initializer, a two-u32 special-attribute structure, lifecycle hooks, skeleton setup, and WaitReverse entry/update callbacks. The header declares the same public functions and exported data. Both canonical and rendered files were read completely in the inherited research; rendered names were treated as hypotheses rather than evidence. The independent lead review inspected canonical evidence for every upstream contradiction and reconciled the document with the empty proposal.

### Attribute and model lifetimes

`ftSb_Init_OnLoad` obtains the Fighter from GObj user data, installs attributes, sets `x2228_b2` and `x2226_b0`, and unconditionally calls `ftSb_Init_8014FA30`. `PUSH_ATTRS` copies the external template into existing backup storage and points `dat_attrs` at that storage. By contrast, `ftSb_Init_LoadSpecialAttrs` uses `COPY_ATTRS` to overwrite the existing active block without rebinding its pointer. The payload's two words remain semantically unnamed. [Load](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSandbag/ftsandbag.c#L51-L61), [reload](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSandbag/ftsandbag.c#L99-L102), [macros](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/inlines.h#L21-L41).

The skeleton helper repeats operations for primary `.joint` and secondary `.x4_jobj2` objects. It attaches flag-1 constraints to WaistN referencing RLegJ and LShoulderN; flag-2 constraints to LLegJ referencing RShoulderJ; and flag-2 constraints to LLegJA referencing WaistN. LLegJ receives limit flags 1 and 2 with `-M_PI/2`; LLegJA receives the same flags with `MTXDegToRad(-86)`. The canonical library implementations allocate and prepend RObjs, independently supporting the descriptive hypothesis `ftSb_Init_SetupBoneConstraints`. They do not directly assign joint rotations. Objects remain attached after return; this unit has no duplicate-installation guard or matching teardown. The limit helper guards its value assignment on a non-null allocation, but still calls the surrounding flag/prepend helpers. Allocation failure and eventual evaluation/removal remain external concerns. ### Entry and cross-file orientation selection

`ftSb_Init_8014FBA4` calls `ftCommon_8007D7FC` only when `ground_or_air == GA_Air`. Both paths then call `Fighter_ChangeMotionState(gobj, 0x155, 0, 0.0f, 1.0f, 0.0f, 0)` and `ftCommon_8007EFC0(fp, p_ftCommonData->x5F0)`. The canonical body and callback family support `ftSb_WaitReverse_Enter` as a descriptive name, not recovered original spelling. The common airborne helper has conditional knockback/statistics work before delegating onward; it should not be understood as merely one flag write. [Entry](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSandbag/ftsandbag.c#L108-L118), [common helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftcommon.c#L581-L594).

The load-time flags have visible cross-file consumers: `x2228_b2` selects specialized down-bound orientation processing, while `x2226_b0` selects hip-matrix column 2 rather than column 1. That processing reaches the Sandbag entry in the else branch of `ABS(rot0) < ABS(rot1)`, then the else branch of `facing_dir * rot0 > 0`. Equal-axis and zero-product cases therefore must not be omitted from a description limited to 'predominantly sideways, opposite facing.' The alternative response calls `ft_8008A2BC`; the outer branch also performs common setup, requests a large quake, and calls `ftCommon_8007CCE8` after either entry response. [Caller](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_DownBound.c#L148-L219).

### Update and no-op boundaries

OnDeath, OnKnockbackEnter, OnKnockbackExit, WaitReverse Anim, and WaitReverse IASA are entirely empty. This establishes no character-local work at those boundaries, not absence of common cleanup, animation advancement, damage handling, or other transitions. [Death](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSandbag/ftsandbag.c#L49-L49), [other hooks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSandbag/ftsandbag.c#L104-L132).

Phys forwards the GObj unchanged to `ft_80084F3C`. That helper reads ground friction, multiplies it by the common multiplier only when `ABS(gr_vel) > walk_max_vel`, applies ground friction, then advances ground movement. The comparison is strict; this pass does not establish a numeric lower bound on the multiplier. [Physics delegate](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_084E.c#L42-L53).

Coll forwards unchanged to `ft_80083F88`. Its collision helper synchronizes previous/current collision positions, invokes `mpColl_8004B108`, writes the adjusted position back, and converts the boolean result to `GA_Air` or `GA_Ground`. The caller explicitly enters Fall when the returned value equals `GA_Ground`. That comparison is preserved literally rather than corrected from enum names or the local `fall_off_ledge` name. [Position/result flow](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_081B.c#L392-L404), [Fall guard](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_081B.c#L1027-L1033).
