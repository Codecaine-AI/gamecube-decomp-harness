## Overlay queries
`ftCo_800C0658(Fighter*)` returns `&fp->x408` when `(int) fp->x408.x28_colanim.ptr != 0`, otherwise `&fp->x488`. It does not test the fallback's occupancy, search x508, or inspect enable flags. `ftCo_800C0674(Fighter_GObj*)` forwards `GET_FIGHTER(gobj)` to that selector. Both return borrowed Fighter-embedded storage without allocation or overlay mutation; valid input objects are required. The literal cast-to-int discriminator must not be generalized into a portable pointer-representation guarantee.

`ftCo_800C0694(Fighter*)` returns the selected overlay's `x28_colanim.i` unchanged. Its current return type is `enum_t`; the source explicitly questions the ideal type. There is no validation or special empty-state branch. Active callers compare with 106 during Hammer cleanup and 8 when gradual healing ends; the matching ID is passed to `ftCo_800C0200`, which clears the controller selected by table metadata and conditionally restores persistent overlays. These mappings come from executable callers, not numeric enum names.

`ftCo_800C06B4(Fighter*)` literally returns `(int) &fp->x508.x28_colanim.ptr->x7B`. It takes a member address, not the byte value. The ColorOverlay union contains integer and pointer alternatives; the installer writes the integer alternative. The dispatcher subtracts 0x7B before installing reserved IDs into x508, and its diagnostic calls that domain spycloak colanim. These support intended reserved-ID reconstruction but do not prove compiled displacement or portable behavior for null/fabricated pointer representations. Its consumer short-circuits on x2226_b4, accepts only 0x7B or 0x80, then requires x2226_b5. Individual profile appearances remain unknown.

Unbounded repeated increments also lack protection against signed integer overflow; wraparound is not a portable guarantee.

## Deferred execution and lifetime
Registration only retains pointers. `ftColl_GetWindOffsetVec` initializes its output to zero, skips processing under x2224_b4, and otherwise iterates to the wind count. Non-null Ground and `ftCo_800C0A28` eligibility gate the callback; a true result causes component-wise vector accumulation. Catch traversal is gated by x2219_b1 and invokes its two-argument callback after eligibility, dispatching `ftCo_800C0874` on acceptance. Collision traversal has a match-state early return, computes hit status, checks eligibility, and passes a third output argument cast from a DynamicsDesc pointer address. The callback runs even when hit status is nonzero; descriptor application and final `ftCo_800C0B20` require zero hit status. All loops trust counts rather than physical capacity. Thus null registration can cause out-of-bounds traversal, not just misleading bookkeeping. Source: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftcoll.c#L3414-L3507.

Storage uses ftDevice_Callback0 for wind/collision, declared as a three-argument Boolean callback. Mario's registered collision callback instead declares `(s32, HSD_GObj*)`, ignores its first argument, acts by side effect, and returns zero; this prevents descriptor consumption. Universal callback ABI compatibility and a replacement strongly typed interface remain unresolved. Sources: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/forward.h#L87-L87; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/types.h#L958-L975; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grtmario.c#L175-L192.

Ground objects and callback code must outlive deferred use. Successful callbacks must initialize any output the consumer reads. This TU does not extend lifetimes or enforce these preconditions. Reset stops subsequent count-driven traversal but retains stale callback addresses. Global safety under destruction, reentrancy, or concurrent mutation is unproved.

## Demonstrated clients and boundary behavior
Dream Land registers fn_802112F4 with discriminator 0xA. The callback zeroes y/z and produces negative or positive parameter-derived x for controller states 1/2 only inside strict rectangle bounds; otherwise x becomes zero and it returns false. The rectangle helper orders each endpoint pair. Equal endpoints yield an empty interval; equality at boundaries and NaN comparisons reject inclusion. With finite bounds, infinite coordinates also fail inclusion. Wind magnitude is not checked for finiteness or sign, so left/right physical interpretation presumes the ordinary parameter sign; NaN/infinite outputs can propagate through accumulation. The registrar itself performs no floating-point arithmetic or sanitization. Source: code://c302741689bd67c3617faadb221df3193992c3/src/melee/gr/groldpupupu.c#L479-L556.

Old Kongo registers grOldKongo_80210454 with discriminator 2. It rejects a non-idle barrel or squared distance not strictly less than squared radius; equality, zero radius, and NaN comparisons reject entry. Negative radius is squared rather than rejected, and extreme values can overflow floating-point squares. On acceptance it stores the Fighter, sets the barrel state to 1, and starts entry effects. This is client-specific barrel entry, not a universal meaning assigned to discriminator 2. Sources: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/groldkongo.c#L160-L166; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/groldkongo.c#L523-L563.

Equality or NaN in the comparisons does not trigger. It emits an effect/event, returns zero, and only scales particles when generator creation succeeds. Ground's scale helper has a null-parameter fallback of 1.0.
