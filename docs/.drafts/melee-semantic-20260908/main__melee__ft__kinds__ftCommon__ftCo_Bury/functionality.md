# ftCo_Bury semantic review

## Environmental interactions are separate from buried restraint

`ftCo_800C0874` handles only `BuryType_Unk2`, forwarding the fighter into BarrelWait; its opaque second argument is unused. `ftCo_800C08A0` consumes a dynamics descriptor, initializes timer 1 for type 1 or timer 2 for type 3 before damage admission, conditionally performs collision response using the first hurt capsule, and always calls player bookkeeping. That bookkeeping independently excludes flagged players and accumulates only categories 1 and 3. Registered-device callers supply a Ground_GObj cast into the declared Fighter_GObj source slot. [Dispatch and response](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Bury.c#L57-L95), [callers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftcoll.c#L3414-L3507), [bookkeeping](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/pl/plbonuslib.c#L716-L728).

Initialization snapshots the stage kind and clears timer 1, but clears timer 2 only for OldKongo, Kongo, ShrineRoute, Pushon and Zebes. Countdown has the same stage restriction for timer 2. Both timers are unsigned; guarded decrements preserve zero. Fighter_procUpdate invokes countdown only after its inactive-fighter and hitlag guards. BarrelWait launch refreshes timer 2 outside this TU. Type-2 eligibility additionally excludes BarrelWait, x1A6A bit 0x20 and x2224_b2; type 3 checks only timer 2, and other selectors are accepted. [Cooldown implementation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Bury.c#L97-L166), [update scheduling](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/fighter.c#L2150-L2177), [external refresh](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_BarrelWait.c#L73-L87).

`ftCo_800C0B20` queries contacted floor, ceiling, right wall and left wall in that order when timer 1 is zero. Each assignment replaces the previous descriptor, including NULL results. Only a non-NULL final descriptor triggers cooldown refresh and response. `Ground_801C5700` invokes the stage's nullable on_touch_line callback: it is not a test for stationary terrain. `ftCo_800C0C88` is a pure classifier accepting types 1 and 3; Yoshi and Kirby Egg Lay damage callbacks combine it with a separate damage-category-3 condition to expire captivity. ## Bury and BuryWait

The actual buried-status gate requires HitElement_Ground, GA_Ground and a clear x2227_b6. Entry performs cleanup, changes to Bury, initializes grab_timer from damage, handicap, Player_80033BB8 and common-data coefficients, records the supporting floor and collision box, derives a root-to-hip vertical increment, stores translation and spawns effect 1095. Player_80033BB8 is not independently identified as rank in this review. [Gate and entry](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Bury.c#L221-L272).

Bury animation applies passive timer reduction followed by mash processing, invokes release at a nonpositive timer, and then still decrements/tests its sinking counter: there is no intervening return. Bury physics changes only the stored box bottom, clamping it to one unit below the lower side endpoint. BuryWait requests KeepGfx, resets movement channels and reapplies buried flags without explicitly reinitializing the restraint or terrain data. Its animation continues timer/mash processing; its IASA and physics callbacks are empty. Its collision callback delegates to Bury collision. Both phases release on failed support, changed floor identity or a non-NULL stage descriptor. A blanket static-floor restriction is therefore removed. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Bury.c#L274-L373).

## Effect tracking and breakout

The effect-library adapter passes the effect GObj and parent fighter to `ftCo_800C0FCC`. The saved floor supplies the normal for rotation; the fighter's current floor supplies displacement at the stored translation. Translation changes only on a successful speed query. The active-line helper returns false for -1 or disabled/hidden lines, but traps on other invalid indices. No effect-lifetime safety or teardown guarantee follows from these local guards. [Effect update](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Bury.c#L297-L314), [adapter](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ef/eflib.c#L1366-L1369), [line validation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/mp/mplib.c#L4522-L4538).

Release first checks for a held Hammer and immediately enters HammerJump if present, skipping ordinary BuryJump setup. Otherwise it establishes airborne bookkeeping, zeros horizontal self-velocity, loads vertical velocity from x618, initializes a float progression counter, enters BuryJump and configures collision through x620. Animation increments the counter before testing completion and entering Fall. IASA uses a threshold and eight fixed-priority first-success checks. The initial apparent mismatch between buryjump.x0 and ca.specials.grav was resolved through independent source declarations: both are first float members of overlapping motion unions, not evidence of Captain-specific gravity. This is source-level alias evidence, not a compiled-layout claim. [Breakout callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Bury.c#L375-L432), [outer union](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/types.h#L1780-L1804), [common members](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/types.h#L312-L321), [Captain member](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCaptain/types.h#L55-L58).

BuryJump physics unconditionally applies gravity/terminal-speed limiting and aerial drift. Collision uses the ascent helper at zero or positive vertical velocity and AirCatchHit collision while descending. Both delegated helpers synchronize collision positions and can select basic Landing after accepted contact, subject to an additional veto and velocity threshold. [Delegated collision](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_081B.c#L514-L588).
