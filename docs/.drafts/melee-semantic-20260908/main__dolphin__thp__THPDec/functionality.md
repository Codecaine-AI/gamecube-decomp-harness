THPDec.c implements a stateful JPEG-derived THP video pipeline: metadata probing and work-size calculation; context initialization and marker parsing through SOS; Huffman size/code/threshold and five-bit quick-table preparation; component DC/AC entropy decoding; paired-single inverse DCT; and fixed-640 or supplied-width planar Y/U/V row output. THPInit conditionally enables locked cache, rebuilds address tables and initializes fast-cast registers. Source overlay writes are not compiled-layout proof. The rendered tentative names GetInfo, CalcWorkSize, SetupBuffers, ReadJFIFHeader and SetupDecompressor fit canonical roles and remain tentative. Many assembly-region names remain unchanged due to renderer parse uncertainty.

Important exceptions: THPVideoDecode is preparation, not final pixel decoding; its actual arguments are dimension header, byte status output, mutable context allocation, compressed stream and unused fifth argument. It returns context-as-s32 or zero. The probe can succeed at SOS without complete metadata; sampling rejection is incomplete. SOS validity masks differ from final table indexing. Geometry setup can report unsupported >6-block layouts yet return zero, whereas >16 returns 17. Output rows always decode four Y plus U and V blocks. General width uses integer x/16 transfer counts and u8 MCU indexing, not universal dimension support. Restart handling realigns the count and resets predictors without validating restart marker bytes; interval zero remains enabled.

DHT bits/Vij pointers borrow source bytes; generated arrays and coefficient blocks use the context workspace cursor. Six global Huffman pointers, active IDCT context and a shared 64-float workspace are reused across calls. Caller code retains planar outputs while freeing temporary metadata/context after the row driver. LCStoreData rounds and splits transfers; LCQueueWait(3) is a threshold wait, not a full drain, and neither driver performs a final drain. These lifetimes and hardware constraints must not be collapsed into a synchronous-output guarantee.
