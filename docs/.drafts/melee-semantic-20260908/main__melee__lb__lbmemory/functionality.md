# Bounded Heaps and Compaction

`lbmemory` manages bounded arenas using 131 allocation descriptors and six heap descriptors. `Handle.x8_hi` stores an upper bound on heap handles and an allocation size on child records. Heap allocation lists remain ordered by address; freeing recycles descriptors without clearing payload memory.

Allocation rounds the requested size to 32 bytes, then scans gaps for the least leftover. The initial comparison limit is 0x40000000, and `<=` means later equal candidates win. Size overflow and zero requests are not rejected. Arena-start alignment is not repaired here.

Compaction scans from the heap low address and moves allocations toward a packed cursor. Already packed heaps return 0 without invoking the client callback. A gap starts a continuation and returns 1. Each moved descriptor receives its new address before asynchronous copying completes. Sub-0x80000000 destinations use DevCom; other destinations use alarm-scheduled memcpy chunks of at most 0x19000 bytes. The code requests 3ms delays, not guaranteed intervals. Overlap behavior depends on the foreign memcpy implementation.
