### Configuration and command flow

`GXSetTevIndirect` constructs a fresh BP word containing source-stage, format, bias, alpha, matrix, wrap, LOD and accumulation selectors, addresses it with `tev_stage + 16`, emits it immediately and sets `bpSent` to zero. `GXSetTevDirect` supplies the neutral preset. Warp, tile, bump-ST, bump-XYZ and repeat helpers compose the same encoder rather than implementing separate rendering pipelines. See [encoder](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXBump.c#L22-L44) and [presets](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXBump.c#L190-L322).

`GXSetIndTexMtx` normalizes three identifier families to three physical matrices, silently defaults other identifiers to matrix zero, and emits three column-wise packed words. Each coefficient is multiplied by 1024, converted to int and masked to 11 bits. The signed-byte exponent is incremented by 17 and distributed across three two-bit fields. Masking does not establish portable wrapping for NaN, infinity or out-of-int-range conversions. The tile helper builds a local diagonal matrix using spacing/1024 and zeroes the remaining entries; the setter consumes its coefficients synchronously without retaining the pointer. See [matrix setter](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXBump.c#L46-L104) and [tile matrix](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXBump.c#L268-L274).

Scale changes preserve sibling-stage fields in shared cached registers and emit immediately. Order changes likewise emit `iref` immediately, then mark dirty mask 3. Count changes only modify `genMode` and mark dirty mask 6. The external dispatcher consumes bits 1, 2 and 4 through texture-coordinate setup, BP-mask update and general-mode submission, then clears accumulated dirty state. See [setters](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXBump.c#L106-L188) and [dispatcher](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXGeometry.c#L8-L26).

`__GXUpdateBPMask` coalesces active indirect texture-map references, performs a DEBUG-only direct/indirect overlap check, and emits only when the cached low byte changes. `__GXFlushTextureState` instead unconditionally re-emits the cached word without recomputing it or draining pending dirty state. External TLUT, cache-invalidation and field-mode callers bracket their specialized BP commands with this helper. These are command-stream operations, not proof of GPU completion. `bpSent = 0` must not be interpreted as saying the just-written BP register remains unsent: GXBegin also uses this bookkeeping in deciding whether to send a flush primitive. See [mask helpers](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXBump.c#L324-L378) and [flush-primitive lifecycle](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXGeometry.c#L28-L61).

### Exceptional paths and evidence limits

Assertions are build-dependent. With assertions disabled, an invalid scale stage emits no scale register but reaches the final bookkeeping store; an invalid order stage still emits unchanged `iref` and marks dirty state. Invalid tile sizes fall back to wrapping off. Invalid bump-ST matrix selection leaves `sm` and `tm` uninitialized if execution continues. The mask updater assumes the intended count range 0–4 even though its source field is three bits wide; iterations above stage 3 have no selector case. See [assertion definitions](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/include/macros.h#L4-L27) and the corresponding owned functions.
