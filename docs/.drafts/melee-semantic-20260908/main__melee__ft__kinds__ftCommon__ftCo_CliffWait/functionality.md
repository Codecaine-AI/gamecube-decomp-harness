## Countdown, boundaries, and timeout
ftCo_CliffWait_Anim subtracts one only when x4 > 0 and performs no transition. It does not clamp the result. A positive fraction below one becomes negative; zero, signed zero, and negative values are unchanged. Under ordinary IEEE semantics, NaN is not decremented and does not satisfy the timeout test; positive infinity remains positive infinity; negative infinity satisfies timeout when checked. Sufficiently large finite values can round back to their previous value after subtracting one. These are source-level boundary analyses, not proof that such configurations occur in normal gameplay. Eventual expiry is not an unconditional invariant.

ftCo_8009A9AC tests x4 <= 0. True causes assignment of p_ftCommonData->ledge_cooldown to x2064_ledgeCooldown, sets x2227_b1, calls ftCo_80090780, and returns true. Otherwise it returns false without local writes. False includes unordered NaN, not merely an active finite timer. The check is last in IASA, so earlier successful options bypass it even for a nonpositive timer. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_CliffWait.c#L35-L72.

IASA forwards the unchanged gobj to ftCo_8009AE38, ftCo_8009AFD4, ftCo_8009B170, ftCo_8009AA0C, and ftCo_8009A9AC in that exact order. RETURN_IF returns from the void callback on the first true result. The dispatcher has no direct fighter-field access; this does not make false-returning callees pure. ## Physics and collision delegation
Phys and Coll each unconditionally forward their unchanged gobj once to the corresponding CliffCatch callback. Shared physics validates ledge_id using mpLib_80054ED8. When valid, facing_dir > 0 selects mpLib_80053ECC_Floor, otherwise mpLib_80053DA4_Floor. It writes cur_pos.x = x68C_transNPos.z * facing_dir + endpoint.x and cur_pos.y = endpoint.y + x68C_transNPos.y, leaving z untouched locally. Invalid ledges call ftCo_Fall_Enter. Zero and unordered facing values take the else branch; no finite-value guard protects position arithmetic. Shared collision first tests ft_800821DC; success calls ft_80082B1C and returns. Otherwise ftCo_8009EF68 is tested and success copies the configured ledge cooldown. These guards belong to the delegated implementation, not the wrappers.
