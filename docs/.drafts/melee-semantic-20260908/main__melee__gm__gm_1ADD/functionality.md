## Notice presentation and controller aggregation

This unit implements a persistent notice/message-box presentation layer used by the Memory Card scene. The header declares its twelve entry points. Canonical source, rather than rendered proposed names, establishes these roles.

### Initialization and shared resources
`gm_801ADDD8` clears the sentinel registry and assigns ID `-999`, then calls `gm_801AEBB0`. Resource setup loads `NtMsgWin.dat` / `ScNtcCommon_scene_data`, registers `SIS_MessageData` in slot 3 from `SdMsgBox.usd` when the saved language is US and `SdMsgBox.dat` otherwise, creates a camera, retains a SisLib context identifier, and installs `fn_801AE948` as a process. Neither initializer guards repeated calls or performs prior-resource cleanup. Clearing a populated root would discard its retained list links rather than drain allocations. [Initialization](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1ADD.c#L20-L50), [resource setup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1ADD.c#L329-L353).

### Construction and ownership
`gm_801ADE1C` allocates and appends an outer panel record containing panel/message IDs, coordinates, model and text handles. It requests model 1, positions its root at `(x,y)`, and creates text at `(-14+x,-9-y)` with bounds `(30.8,4.6)`, scale `0.079`, and alignment/fitting values 0. It returns true unconditionally and does not check record or text allocation success.

`gm_801AE050` allocates one option before searching for matching panel IDs. Empty-child and tail-insertion branches retain option/message IDs, coordinates, model 0 and text. Text placement is `(2.2*x-1, -2.232143*y-1.3)`, bounds `(2,2)`, scale `0.1`, alignment 1 and fitting 0. It also returns true unconditionally. With no matching parent, the allocated record is neither linked nor freed. With duplicate matching parents, the outer traversal continues and reuses the same option allocation, potentially aliasing lists, overwriting links and resource handles, and invalidating normal teardown ownership. The observed Memory Card builder avoids this by removing group 0 before creating its replacement. [Constructors](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1ADD.c#L52-L174), [observed caller](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1AED.c#L50-L84).

### Visual updates
`gm_801AE44C` and `gm_801AE544` add the negated float argument to the Y translation of fixed model descendants for every matching panel ID. The latter targets one child deeper. Calls accumulate; neither modifies SisLib text or retained root coordinates, and neither guards the model/hierarchy dereferences. The caller supplies a language-dependent metric transformed as `1.12*(metric-2)` to the first routine and supplies `-2` to the second only for layout mode 0. The precise visual identity of those descendants is not established by source alone.

`gm_801AE640` and `gm_801AE74C` ignore their first argument and traverse options across all panels. Their bool-typed second argument is compared against an integer option ID. Matching model materials and text receive gold `#FFCC33` or gray `#666666`, respectively, with independent handle guards and a text refresh using the retained message ID. Alpha, logical selection and membership are unchanged. Stored option IDs are not intrinsically Boolean merely because the color API and observed caller use binary selections.

`fn_801AE948` ignores its callback argument and reapplies retained X/Y to every non-null panel and option root model. It does not update text, descendant layout offsets or registry state. [Visual mutators](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1ADD.c#L176-L259), [position process](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1ADD.c#L304-L327).

### Model factory and teardown
`gm_801AECC4` creates an indexed JObj-backed model GObj, installs GX link 14, invokes animation setup, and requests/evaluates frame zero. Index 1 additionally hides two fixed descendant subtrees; index 0 has no such override. The factory does not validate indices, loaded descriptors or allocation results. Observed callers use index 1 for panels and 0 for options; these are observed roles, not an exhaustive model-index enumeration.

`gm_801AE848` removes every matching panel in a well-formed registry. It drains option model/text resources and records, repairs outer predecessor/successor links, then removes the panel resources and frees its record, saving successors before frees. Missing handles are independently skipped. It does not reset the scene descriptor or SisLib context or explicitly destroy the shared camera/process objects. Memory Card entry calls the initializer, its builder removes group 0 before replacement, and exit removes group 0. Broader scene-resource cleanup is outside the demonstrated group lifetime. ### Input and scene boundary
`gm_801AEDC8` returns the OR of copied controller `trigger` fields for ports whose master status has `err == 0`. It does not check copied status errors, preserve controller identity, generate events or maintain history. The Memory Card caller uses masks `0x40001` and `0x80002` to select 0 or 1, with the first branch taking precedence, and tests `START|A` for confirmation. Edge/repeat generation requires controller-producer evidence and is not established by this query.

The neighboring scene owns card-condition processing, selection and numeric state transitions; this unit supplies presentation and input aggregation, not the card state machine. Layout modes 0/1/2, message IDs, option IDs and model indices are distinct numeric domains. No additional human-readable meanings are assigned to card result or state numbers.
