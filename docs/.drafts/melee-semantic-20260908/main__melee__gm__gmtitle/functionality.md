# Title presentation and lifecycle

`gmtitle.c` loads localized title assets, constructs title lettering and background models, cameras, lighting and fog, handles title entry and exit requests, and optionally displays the build timestamp. The header declares the public constructors and scene callbacks. Rendered names were treated as hypotheses rather than independent evidence.

## Resources and object lifetimes

`gmTitle_801A1AC0` chooses `GmTtAll.usd` when `lbLang_IsSettingUS()` is true and `GmTtAll.dat` otherwise. It resolves two model descriptors, camera/light/fog descriptors and the cross-file title-mark descriptor `gm_804D67F0`. Each filename occupies eleven C-array bytes including NUL; compiled section allocation is not established. The constructors rely on populated descriptors and do not implement local allocation/load failure recovery. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmtitle.c#L233-L253)

`gmTitle_801A12C4` constructs a title model at the title loop frame, evaluates its animation, translates it by `(0,-3,0)`, hides subtrees 3 and 1, and returns its GObj without installing a process. The opening controller retains this handle: creation requires NULL and movie timing in `[0x3B6,0x3CE)`; destruction requires non-NULL and timing at least `0x3CE`. These are interval/threshold guards, not exact-frame guarantees. The same controller separately constructs the principal title model at timing at least `0x140A`. ## Animation selection and THP handoff

The title and background loop records are `(0,1600,400)` and `(0,1330,130)`. Despite its name, `isActiveTitle` returns false for `GM_TITLE`, and for `GM_OPENING_MV` with scene index `GS_VS`. Those contexts initialize the principal title at frame 400 with the loop-only process and the background at frame 130. Other contexts select introductory animation, reset `bg_initialized`, and start at the configured start frame. The symbolic scene-index comparison is preserved without inferring that this necessarily denotes a versus match. The principal constructor hides subtree 7 unless either character unlock check succeeds, advances the RNG according to the current second, and calls `gm_SetupTitleDemo`. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmtitle.c#L31-L170)

`fn_801A1498` requests frame `gm_804D67EC - 5130` while timing is at most 5400; above 5400 it delegates to the title loop helper. With the background latch false and measured animation frame at least 270, it creates the background, calls `lbMthp_8001F614(0)`, and sets the latch. This does **not** start stream 0: the callee writes a rendering gate, and zero suppresses the THP texture/draw branch. The THP callback still invokes its preceding helper outside that gate. ## Rendering and exceptional paths

The primary camera uses `gxlink_prios=0x209`; its callback dispatches mask 7, selecting passes 0–2 and GX lists 0, 3 and 9. Dispatch and finalization occur only after successful camera activation. Activation can return false, and an invalid render-pass mode also invokes panic. The erase callback reads `fog_desc->color` before activation and, on success, sets erase color, calls screen erasure with `(1,0,1)`, and finalizes. Named erase-flag semantics and relative camera scheduling remain unverified in this pass. [Title cameras](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmtitle.c#L172-L207) · [Dispatcher](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/gobj.c#L158-L183) · [Activation](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/cobj.c#L485-L525)

Lighting installs a render callback only. Fog installs both rendering and animation interpretation. Fog channels can update depth, RGBA and optional adjustment center; this does not prove every channel is present in the title asset. AObj interpretation has null/no-animation guards, first-play behavior, looping and completion branches. `AOBJ_NO_UPDATE` suppresses the ordinary interpretation callback, but boundary stop calls still receive `update_func`, so blanket suppression of all property writes is not established. ## Entry, input and timestamp

Entry sets countdown 20 and frame count 0, loads resources, configures audio, creates visual objects, preloads the title demo and directly constructs the background. The frame callback reads triggered buttons before the countdown guard. Countdown frames decrement and return; subsequent frames increment the counter. A value greater than 600 exits with datum zero before considering input. Otherwise Start performs its audio handoff and exits with the full triggered mask. At debug-ROM level or above, Y, A and X are checked in that order after Start. The counter is elapsed unlocked time, not an idle timer reset by arbitrary activity. Actual destination dispatch is outside this unit. [Frame callback](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmtitle.c#L255-L296) · [Entry](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmtitle.c#L328-L366)

At `DbLevel >= DbLKind_NoDebugRom`, entry converts the timestamp into the static 128-byte buffer and passes it to SisLib at `(30,30)`, enables default kerning and supplies scales `(0.7,0.55)`. The converter emits two bytes per non-NUL input byte, uses a fallback code for unsupported characters, appends NUL, and returns the terminator pointer. It requires `2*strlen(src)+1` destination bytes and performs no capacity check; the local buffer therefore accommodates at most 63 input bytes. The inferred Shift-JIS name describes this restricted mapping, not a general encoding converter. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmtitle.c#L298-L366)
