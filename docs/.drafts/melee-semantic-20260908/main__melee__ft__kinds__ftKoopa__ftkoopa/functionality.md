## Event adapters

`ftKp_Init_80132B38` is a parameterless no-op. Pickup/drop forward their object and boolean with two fixed true options; visibility and knockback adapters forward the object with true. ## Backward throw event ordering

`ftKp_SpecialS_80132E30` first consumes the throw-b4 event, reverses facing, and sets move-local xC. It then returns if command variable zero or victim absent. A missing victim leaves a pending command unconsumed. With both present, it calls common setup, paired throw processing, and thrown-fighter initialization, then clears the command. Grounded and airborne EndB callers independently test animation completion afterward, selecting grounded completion or Fall. Thus command consumption is once per pending command, not a guarantee of once per entire move; turn processing can occur even when release is skipped. The neighboring forward-ending helper has equivalent event logic, so the event itself is not inherently exclusive to backward throws.
