### Target position and exceptional path
`ftBossLib_8015C208` selects through `ftBossLib_8015C244`/`ftLib_8008627C`, then copies the selected fighter's current position through `ftLib_80086644`. Selection minimizes squared XY distance using the candidate position produced by `ftLib_800866DC`, excludes candidates through `ftLib_80086FD4`, excludes `x221F_b3`, and excludes same-team candidates when the team-mode condition applies. Selection can return NULL; the observed helper chain does not guard that result before passing it to the position accessor. Successful positioning therefore assumes a valid selected fighter; no fallback position is established. The local output vector is consumed immediately, and no retained target handle is stored by Cancel. The helper obtains a target position again, computes target X minus current X, and adds either the full difference or a signed `xDC` increment to existing horizontal self-velocity, according to the strict `ABS(x_diff) > xDC` comparison. This is additive velocity adjustment, not a velocity assignment or a demonstrated speed cap. No positivity validation for `xDC` is shown; an unconditional target-directed interpretation is therefore too strong. It changes neither Y nor Z velocity directly. Collision is an empty callback.
