## Fighter-side Egg Throw
Fresh grounded and aerial entries reset `specialhi.x0`, `specialhi.x4`, `u.ys.x2238`, throw flags and command variable 0. They change motion state, reload the Fighter, install `fn_8012E110` in `accessory4_cb`, and only then call animation setup. Both animation callbacks increment the hold counter whenever B is held, independently of animation exhaustion; there is no release-flag guard on this increment. Ground completion calls the common neutral dispatcher, with exceptional branches rather than an unconditional Wait transition. Aerial completion enters Fall.

`ftYs_SpecialS_8012DF8C` computes a planar launch vector. It normalizes absolute horizontal stick input by `xEC`, caps it at one, scales by `xF0`, suppresses values below `xF4`, and applies stick direction. Facing selects the base angle or its pi reflection. Vector magnitude is `specialhi.x4 * x100 + xFC`; z is zero. The source contains no local zero-denominator guard or charge cap. ## Article creation, release and cleanup
The accessory callback has independent creation and release branches, which can both run in one invocation. Creation samples joint 31 and calls the EggThrow constructor with part `0x1F`, storing its nullable result in both `x1984_heldItemSpec` and `u.ys.x2238`. Damage/death callbacks are installed only when the retained pointer is non-null. A release request without an egg is not consumed.

Successful release consumes command variable 0, sets `specialhi.x0`, and passes the computed launch vector, a facing-relative position offset, a charge-scaled spin parameter, and raw charge to `it_802B28C8`. Crucially, `x104/x108` supply a position offset, not another velocity, and `x4*x110+x10C` supplies spin scaling, not lifetime. The raw charge parameter is unused by the item release body. Release clears `u.ys.x2238` and both interruption callbacks. The item subsequently owns its flight, countdown and explosion behavior. [Fighter producer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftYoshi/ftyoshispecialhi.c#L89-L120), [item consumer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshieggthrow.c#L39-L106), [spin calculation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L1063-L1095).

Interruption callback `ftYs_Init_8012BA8C` calls egg cleanup followed by tongue cleanup. Egg cleanup invokes the item destructor only when the retained pointer exists and the literally spelled `mv.ys.specials.x0` is zero; it clears the retained pointer and two callbacks on every path. Neither this body nor the accessory release body explicitly clears `x1984_heldItemSpec` or `accessory4_cb`. Their wider lifetimes must not be inferred from the local pointer clearing. ## Situation changes and physics
Ground loss dispatches `fn_8012E3B4`, which continues into `ftYs_MS_SpecialAirHi`, restores callbacks and clamps air drift. Landing dispatches `fn_8012E44C`, whose destination remains literal `0x16C`; this review does not establish its symbolic equivalence. Common transition helpers pass the current animation frame. Damage callback restoration is conditional on a retained egg; accessory restoration is unconditional.

Before release, aerial collision uses `ft_80082C74`; afterward it uses `ft_80083A48`. Both receive the same landing callback. The latter attempts wall-jump handling and then cliff handling if its ground/ledge test fails; that control flow is not proof that Yoshi can wall jump. Ground physics applies speed-conditioned friction and grounded movement. Air physics reads ordinary gravity, terminal velocity and aerial friction to update fighter velocity, not the attributes themselves. ## Separate tongue cleanup and header
Despite its SpecialS spelling and placement, `ftYs_SpecialS_8012DF18` is a SpecialN-aware tongue cleanup helper. A null target item causes no writes. Otherwise it requests tongue destruction and clears `x1A64` and `target_item_gobj`. Only `SpecialN1_1`, `SpecialN2_1`, `SpecialAirN1_2` and `SpecialAirN2_1` request `destroy_type` clearing; destruction itself is not limited to those states.
