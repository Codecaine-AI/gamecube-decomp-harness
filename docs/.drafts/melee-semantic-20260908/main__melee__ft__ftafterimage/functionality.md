## Rendering and numerical behavior
`ftCo_800C2600` returns before Fighter acquisition when `arg1 != 2`, and before GX changes when `x2100 <= 1`. Active rendering enables color writes, disables alpha writes, selects source-alpha/inverse-source-alpha blending, positive-alpha comparison, LEQUAL depth testing without depth writes, no texture generators, one pass-color TEV stage, vertex-color channel input and no culling. Parameter selection occurs after those state changes, so invalid source inputs do not constitute a clean no-op fallback. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftafterimage.c#L80-L115.

The renderer uses local `cumDist[3]` and `AfterimageVtx vtx_buf[152]`. Source-level vertex members are three f32 coordinates and four u8 color components; compiled size/alignment is not proved. History is traversed newest-to-oldest by decrementing the next-write index with 0-to-2 wrap. For outer points P0, P1, P2 in that order, the distance-loop deltas are P0, P1-P0, and P2-(P1-P0), because line 165 assigns `prevPos = delta`. Only deltas after the first contribute magnitudes. Consequently a three-sample total is not generally the sum of adjacent outer-point distances, and a stationary three-sample trail need not have zero total. A total strictly below `0.00001f` becomes 1; equality does not trigger the fallback. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftafterimage.c#L117-L176.

The extent difference is `x20FC-x20F8`. Inner and outer target scales are `params->x0` and `x4` times that difference plus `x20F8`. Interpolation starts at factor 1, yielding the current extents; later factors are `1-cumDist[distIdx]/totalDist`. Each historical sample emits an inner/outer pair. Alpha is the s32 conversion of `factor*(x8-x9)+x9`, subsequently assigned to u8; inner RGB is xA/xB/xC and outer RGB xE/xF/x10. Guaranteed fading, positive/ordered extents, and exact endpoint alpha matching through intermediate vertices are not general invariants. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftafterimage.c#L178-L240.

For adjacent samples, the caller tests the normalized-cross-product result against NULL. Inside that branch it computes angle, truncates `angle/0.0872664600610733f` to s32 and updates the distance factor, including when subdivision count is zero. A nonzero count enters interpolation setup; positive count n emits n additional pairs using fraction `1/(n+1)`, stepped origins/scales, integer-truncated alpha steps, and rotations of the original current direction by accumulating angle. At ordinary finite nonnegative angles, truncation is floor; values below one step give no intermediate pair, and one step gives one pair. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftafterimage.c#L242-L334.

The active `lbVector_CrossprodNormalized` always returns the supplied result pointer, even for a zero cross product. Normalization only specially handles exact zero length. The angle helper returns zero unless the product of vector lengths exceeds 1e-10; otherwise it bounds cosine with comparisons and applies acosf. Parallel directions ordinarily give zero subdivisions. Antiparallel nonzero directions can give pi with a zero axis, violating the rotation helper's unit-axis precondition. The rotation implementation uses polynomial sine/cosine approximations, so exact length-preserving rotation is not an established invariant even for otherwise valid input. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbvector.c#L18-L31; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbvector.c#L78-L102; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbvector.c#L123-L216.

For valid two/three-sample input and ordinary finite angles in [0,pi], at most 36 inserted pairs per interval give at most 150 constructed vertices for three samples, fitting the 152-element source buffer. This is conditional, not a universal safety proof. No local history/count/buffer bounds checks exist. NaN bypasses the distance fallback; overflow and infinite distances can produce invalid ratios, and nonfinite alpha/subdivision float-to-integer conversions have no verified target behavior here. Zero total uses the unit fallback, but does not force the oldest interpolation factor to zero. Assertions are not established recovery paths.
