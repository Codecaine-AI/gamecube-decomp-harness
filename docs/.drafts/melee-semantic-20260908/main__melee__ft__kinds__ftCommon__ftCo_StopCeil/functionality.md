## Ceiling gate and initialization
`ftCo_8009EF68` tests the intersection of `coll_data.env_flags` and `Collide_CeilingHug`. Nonzero invokes the private entry helper and returns true; zero returns false without a state-changing call. It has no local velocity, input, current-state or null guard. True reports invocation of the entry path, not guaranteed final residence in StopCeil. The external consumer `ft_800835B0` tries accepted contact, wall jump and ledge handling before this gate: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_081B.c#L792-L804. Local evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_StopCeil.c#L16-L23.

Entry obtains the fighter from `gobj->user_data`, clears the whole `throw_flags`, constructs stack vector `(0, ecb.top.y, 0)`, and calls `ftKb_SpecialN_800F1F1C`. That helper requests effect `0x49E` only for Kirby; it is not an ECB-vector adjustment routine. Its spawn kind 2 is `EF_SPAWN_POS_OFFSET`, and the spawn implementation copies the vector into the allocated queue record rather than retaining the stack address. It stores the joint pointer. With a current GObj whose `s_link < 9`, it links the record into the queue; otherwise it calls deferred processing. Allocation failure handling is not local, and joint lifetime/queue teardown remain external responsibilities. ## Animation and empty phases
Anim calls `ftCheckThrowB3`, which clears B3 when set. Success short-circuits the animation query and invokes `ftCo_Fall_Enter`; otherwise a false `ftAnim_IsFramesRemaining` result invokes Fall. Consequently the wrapper has no explicit field assignment but its inline predicate is consuming, not pure: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_StopCeil.c#L47-L53 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/inlines.h#L255-L263.

The animation query scans eligible parts and checks joints through `lb_8000B074`. Blend frames equal to zero select the ordinary joint; otherwise it selects `x4_jobj2`. Both signed zeros select the first branch; an unordered NaN comparison selects the second. No eligible successful part, including an empty scan, yields false. This is not simply a frame-counter comparison. Deeper joint animation completion remains external: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftanim.c#L515-L538.

IASA and Phys are empty, including no argument dereference. They implement no local input checks, gravity, drift, integration, timer or transition. This does not establish global stationarity, universal non-actionability, or animation as the sole exit: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_StopCeil.c#L55-L62.

## Collision dispatch and boundaries
Coll unconditionally forwards the same object and function addresses `ftCo_80096CC8` and `ft_80082B1C` to `ft_80083464`. The dispatcher copies previous/current collision positions, selects `mpColl_80047D20` when ledge cooldown or `x2224_b2` is nonzero, otherwise sets facing and selects `mpColl_8004806C`, then copies position back. Facing less than zero selects -1; zero and unordered comparisons select +1. `ft_80081A00` can suppress acceptance. Accepted contact synchronously invokes the response; otherwise wall-jump then ledge checks run. The wrapper/dispatcher does not store the response callback. Deeper predicate retention is not established. Sources: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_StopCeil.c#L59-L62 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_081B.c#L745-L790.

The predicate rejects line ID -1 before querying flags. Other IDs receive no local validity check. Non-platform lines bypass the stick test; platforms require stick Y strictly greater than `p_ftCommonData->x25C`. Equality or NaN rejects a platform. The response uses strict `self_vel.y > ftCo_800D0EC8(fp)` to select `ft_8008A2BC`; equality or unordered comparison selects basic Landing. The threshold's numeric value/sign and full first-destination behavior are not inferred from aliases.
