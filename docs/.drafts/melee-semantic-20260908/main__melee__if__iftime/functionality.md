## Match-timer UI

`iftime.c` owns the ordinary match-clock presentation, a separately reserved countdown GObj, ten cached digit/separator joints, and countdown animation state. The header declares all eleven public functions consistently with their definitions.

Model loading obtains `ScInfTim_scene_models` and `tdsce` from the interface archive, copying the ordinary model's four asset references into a separate static descriptor. Creation exits after clearing only `match_timer` when both relevant rule flags are false. Otherwise, successful model loading gates construction: it reserves the countdown GObj, constructs and positions the ordinary clock hierarchy, installs its renderer and updater, and caches ten sequential child/sibling joints. Required GObj/JObj allocation failures report and panic. A false model-load result does not perform general state cleanup. [Loading](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/iftime.c#L29-L44) · [Creation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/iftime.c#L228-L273)

`ifTime_SetTime` selects texture-animation frames for the supplied time and freezes their playback rates. With hours enabled, minutes are reduced modulo 60 before digit extraction; otherwise minute tens is extracted from total minutes. The minute-ones expression retains a modulo-60 operation, but this does not change its subsequent modulo-10 result. Hour visibility depends on both the hour count and the root hidden flag. The hour-tens condition uses the extracted digit, not an unrestricted `hours >= 10` threshold; the proposal corrects that existing explanation and records the hidden-root zero-mask behavior. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/iftime.c#L46-L117)

The ordinary updater refreshes digits, then activates the countdown only when `gm_8016B110() == 0`, seconds equal 5, and centiseconds equal 0. It attaches the countdown hierarchy to the previously reserved GObj, installs its updater, requests removal of the ordinary timer, clears its stored pointer, and finally evaluates the original JObj. The latter ordering is explicit; its lifetime safety depends on external GObj removal semantics. The countdown selector returns `max(0, 5-seconds)` at zero centiseconds and `max(0, 4-seconds)` otherwise. It is a stage index, not seconds remaining, and has no upper clamp. Changed stages replace animations and produce two hierarchy evaluations; unchanged stages produce one. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/iftime.c#L147-L226)

Hide/show preserve allocations and independently change hierarchy visibility; show also reformats the ordinary clock. The hidden query tests root flags and returns true if either tracked timer root is hidden. Cleanup removes and nulls tracked GObjs independently. Reset instead zeroes only `ifTime_data`, without destroying objects or clearing the separate ordinary model descriptor.
