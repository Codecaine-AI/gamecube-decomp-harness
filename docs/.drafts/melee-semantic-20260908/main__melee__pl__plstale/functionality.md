## Fighter insertion
`plStale_UpdateStaleMovesFromFighter(gobj, gobj_2)` does nothing if the pointers are equal. Otherwise it interprets the first object as a Fighter, reads its attack ID and instance, and selects its player's table. The accessor occurs before the attack-ID exclusion. ID 1 is excluded. The routine scans ten entries and returns on a pair matching both move ID and instance. Otherwise it overwrites current_index with the pair and changes index 9 to 0, or any other index to old index + 1. A duplicate does not refresh recency.
