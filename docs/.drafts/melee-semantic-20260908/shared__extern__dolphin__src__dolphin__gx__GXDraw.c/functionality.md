## GXDraw.c

Provides immediate GX geometry helpers and a subdivided normal-table generator. Canonical and rendered source were reviewed in full. The rendered view contains no name substitutions or parse errors. No owned subjects, baseline facts, or baseline links exist; no knowledge changes are proposed.

### Vertex state and geometry
- `GetVertState` saves vertex descriptors and vertex-format 3 attributes in shared static arrays, then configures direct XYZ float positions and normals. `RestoreVertState` restores those saved descriptors and format attributes—not all GX state. The single shared snapshot is not a nested save stack. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXDraw.c#L10-L28)
- `GXDrawCylinder` emits a unit-radius side strip between z=-1 and z=1, followed by two cap fans with axial normals. It asserts only an upper edge-count bound of 99; zero is not excluded before division. `GXDrawTorus` uses tube parameter `rc` and major radius `1-rc`, emitting strips and optional TEX0 coordinates when the incoming descriptor is enabled. Its assertion checks `rc < 1`, not nonnegativity or subdivision counts; positive `numc` with zero `numt` reaches modulo by zero. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXDraw.c#L111-L204)
- `GXDrawSphere` emits latitude-band strips for a unit sphere with radial normals and optional TEX0 coordinates. Both angular steps divide by caller-supplied counts without explicit zero guards. The texture format argument is literally `GX_RGBA6`; it is not normalized here into another enum spelling. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXDraw.c#L206-L251)
- `GXDrawCube` emits 24 quad vertices with coordinates scaled by 0.57735026. Incoming NBT and TEX0 enablement controls additional basis-vector normals and signed-byte texture coordinates. Canonical format arguments include `GX_TEX_ST`, `GX_RGBA6`, and `GX_RGB8`; no claim about their cross-enum numeric equivalence is needed. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXDraw.c#L253-L320)
- `GXDrawDodeca` draws twelve five-vertex fans from fixed tables, using one normalized cross-product normal per face. Octahedron and icosahedron drawing traverses eight and twenty indexed triangles respectively at subdivision depth zero. Unlike the dodecahedron, their emitted normals equal vertex positions. `GXDrawSphere1` recursively subdivides the twenty icosahedron faces: each level normalizes edge sums and creates four children, yielding 20 × 4^depth leaf triangles. Normalization asserts a nonzero length before division; recursion depth has no additional resource guard. [Geometry tables and entry points](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXDraw.c#L322-L479); [vector and subdivision helpers](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXDraw.c#L30-L109)

### Normal-table generation
`GXGenNormalTable` recursively subdivides the eight octahedron faces, not the icosahedron used by `GXDrawSphere1`. Leaf vertices are appended as triples to caller-provided storage only if a linear search finds no component-wise floating-point-equal entry. This is exact floating-point comparison, not tolerance-based or bitwise comparison. The return value counts triples. Static pointer/count state is reset at entry, but the pointer remains stored after return; the code neither allocates nor frees the table and provides no capacity or null-pointer check. Shared mutable state precludes independent overlapping invocations. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXDraw.c#L481-L559)
