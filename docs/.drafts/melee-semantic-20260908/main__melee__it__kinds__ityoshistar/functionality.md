## Yoshi Star article

This unit implements the stars created by Yoshi's down-special landing accessory callback. The fighter computes two TransN-relative positions, calls `it_802B2FC8` independently with directions -1 and +1, ignores both nullable results, and clears its accessory callback. Landing installs that callback; the item module does not itself create a pair. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftYoshi/ftyoshispeciallw.c#L27-L42 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftYoshi/ftyoshispeciallw.c#L177-L185.

### Construction and state

`it_802B2FC8` requests `It_Kind_Yoshi_Star`, copies the supplied position into `SpawnItem.prev_pos`, obtains `SpawnItem.pos` through a separate parent-position helper, supplies both parent references, and initializes spawn damage and velocity to zero. Zero spawn damage is not proof of zero attack damage. Creation failure returns NULL without initialization or the debug hook. Success calls `it_802B322C`, invokes the debug hook, and returns the new object. The initializer stores the owner, sets X velocity to `StarAttrs.speed * facing_dir`, sets Y velocity from common attribute `x18`, invokes common setup, and selects motion state 0 with `ITEM_ANIM_UPDATE`. The sign of `x18` is not established by this source. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshistar.c#L24-L46 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshistar.c#L82-L91.

The source defines one state-table entry with animation resource ID 0. That resource ID and the selected motion-state index are distinct concepts even though both equal zero here. The animation callback returns the inverse of a JObj animation-activity query. The query checks traversed joint AObjs, respects the instance traversal restriction, and returns false for an empty traversal; it is not a general check of every material or texture animation. A true animation callback result causes the item dispatcher to destroy the article, not enter another motion state. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshistar.c#L12-L17, code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshistar.c#L93-L99, code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L322-L325, code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lb_00B0.c#L39-L66, and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/item.c#L1280-L1291.

Physics passes common fall-speed parameters to `it_80272860` and adds `StarAttrs.accel * facing_dir` to X velocity. The vertical helper uses a sign-sensitive pre-update speed threshold; it does not hard-clamp the resulting velocity and can overshoot the threshold. The collision callback delegates to `it_8026E0F4` and always returns false, so it does not request dispatcher destruction through its return value. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshistar.c#L101-L114, code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L176-L204, and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/item.c#L1402-L1413.

### Combat and cross-file lifetime

The canonical logic table, decoded using `ItemLogicTable`, establishes the event roles: `it_802B309C` is damage-dealt, `it_802B30C0` is clanked, `it_802B3108` is absorbed, and `it_802B30E4` is hit-shield. These four wrappers call the same helper and return true. The helper spawns effect 0x411 at the item's position, plays sound 0x73 with parameters 0x7F and 0x40, and calls `it_80274C60`. Roles are therefore supported by registration rather than neighboring function order or rendered names. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_3F2F.c#L941-L958, code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/types.h#L26-L71, code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshistar.c#L48-L70, and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L302-L310.

Shield bounce and reflection are separate false-returning responses. Bounce mirrors velocity about the stored collision axis and updates facing unless very small horizontal speed permits preserving an existing nonzero facing. Reflection negates and scales planar velocity, reverses facing, refreshes the life timer from the half-life timer, and sets model Y rotation from the new facing. Neither wrapper explicitly selects another motion state. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshistar.c#L72-L80, code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L418-L456, and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/inlines.h#L242-L251.

`it_802B3348` delegates reference cleanup and discards the helper's owner-match result. Matching owner, reflector, absorber, primary and secondary fighter-source, and toucher references are cleared; primary fighter-source cleanup also sets source player to 6. The common lifecycle caller saves the old owner before invoking the callback and may subsequently destroy the item based on that saved owner and an item flag. Thus reference cleanup is not itself a promise that the article survives. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshistar.c#L116-L119 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L474-L525.
