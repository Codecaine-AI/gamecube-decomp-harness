PADRead traverses pending/resetting/disabled/busy/status/response branches, writes four status records, and schedules receive checks or origin refreshes. Its result mask is accumulated before response validation, not a successful-read mask. Legacy decoders remap buttons and synthesize trigger buttons at 170; modern decoding unpacks mode-dependent fields and clamps origin-relative sticks/triggers.
