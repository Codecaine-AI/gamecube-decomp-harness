# Color Overlay Commands and Rumble Wrappers

Implements ColorOverlay command handlers, update, selective reset and priority-based profile installation, plus archive and HSD controller-rumble wrappers. Local handlers occupy the first 11 positions of a 22-entry table; the final 11 entries are NULL.

## Interpreter and arithmetic

Every due opcode first reaches Command_Execute. Only declined commands use local opcode-0xA dispatch for values below 0x15, or the supplied owner callback for higher values. The local path has no lower-bound guard. Local completion returns before interpolation and lifetime decrement and retains the cursor. Null cursors still permit enabled interpolation and countdown progression.

Both blend setup handlers calculate (0.5f + target byte - current byte) / duration. They do not change the command timer, check zero duration, clamp color values, or automatically stop when that duration passes. The updater adds deltas to floating accumulators and casts to byte channels. Wait/disable commands separately control progression. Table priority arbitration is distinct from the stored x4_pri countdown.
