## Graphics recipes
`efAsync_Dispatch` implements graphics-ID-specific particle and model-effect recipes, with heterogeneous, conditionally consumed variadic arguments. It configures transforms, colors, flags, callbacks, lifetimes and compound effects. Case 0x427 builds up to six linked effects and stops on constructor failure. The common epilogue drains `efLib_AnimCount` in descending order and returns `ret_obj`. Seven handled IDs—0x41B, 0x432, 0x43F, 0x443, 0x44A, 0x44B and 0x44C—can create generators without assigning that return variable. Unhandled IDs execute no recipe but still reach the animation drain. Selected recipes write `EF_LOADKIND_SYNC` without locally restoring the previous value; `efSync_Spawn` resets load kind and animation count before routing into this function. ## Resource preparation
The source catalog has 51 entries, 35 filename/export-name pairs and 16 empty slots. The public request loaders accept indices 0–49 and skip absent filenames. LoadAsync registers a type-3 DVD preload request; it does not wait, initialize a bank, or publish the catalog cache. DVD retrieval separately waits for availability and invokes OnLoad under `load_state == 1`, changing that field to 2 afterward. This initialization state is distinct from the cache's transfer `state`. OnLoad initializes the archive, resolves the indexed export, and calls `psInitDataBankLocate` when either leading bank pointer is nonzero. It has no local index or resolved-export null check. LoadSync additionally skips a non-null cache slot, distinguishes preload reuse from fresh loading, selects the corresponding indexed particle initializer, and stores `&spC->data` rather than the contents of `spC->data`. That address remains tied to archive storage. ## Queue ownership and execution
Spawn allocates a command without checking the result, copies selected vector/scalar values, and stores a borrowed JObj pointer. It does not store the owner GObj or queue head. The original u32 discriminator controls producer decoding, whereas the stored discriminator is u8. Deferral occurs exactly when the current GObj process exists and has `s_link < 9`; commands are inserted at the front. Otherwise the supplied owner is passed directly to the consumer. Flush supplies its own owner argument and processes the ordinary list in reverse insertion order, preserving each successor before destructive processing. Clear returns records without executing requests. Both reset the head only after traversal. The consumer transforms joint origins or offsets at execution time, invokes `efSync_Spawn` or `Camera_RequestQuake`, and frees the record only if control reaches the post-switch free. Assertions and nonreturning downstream failures are not recovery paths. A null JObj with a supplied offset is copied through by the transform helper; a null JObj with a null origin argument is not valid.
