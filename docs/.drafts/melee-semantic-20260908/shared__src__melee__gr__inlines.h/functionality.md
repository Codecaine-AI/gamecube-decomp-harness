## Behavior
- `GET_GROUND` casts GObj user data to `Ground*`. `Ground_JObjInline1` obtains the ground and joint objects, then calls `Ground_801C2ED0` and `grAnime_801C8138` using `map_id`. Callback setup clears only `x8_callback` and `xC_callback`, installs the GX callback with arguments 3 and 0, conditionally replaces `x1C_callback`, invokes initialization before registering the optional process at priority 4. A null `callback3` leaves the previous `x1C_callback` intact. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/inlines.h#L22-L49)
- Target-stage initialization clears `unk8C.b4`, sets `b5`, invokes the supplied creator for IDs 0, 1 and 2 without checking its returns, then calls four ground routines in order. Their rendered camera/target/flipper descriptions are not established by these calls alone. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/inlines.h#L51-L62)
- Star Fox helpers clear all four article pointers, configure fixed animation calls, store a linked object and copy the slot only when both the object and its user data are non-null. The disable helper instead writes `(HSD_GObj*) -1` to only slots 0 and 1: this is distinct from clearing pointers and does not itself destroy objects. Reset affects only the four listed fields. Model attachment passes two joint-lookup results to `lb_8000C2F8`, then clears `linked_gobj`; ownership transfer or destruction is not demonstrated here. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/inlines.h#L64-L118)
- Visibility uses a strict absolute-z depth test. Inside that threshold it zeros z, repeatedly wraps `xDC` into the inclusive bounds ±π, and unhides the hierarchy only when its absolute value is strictly below 1.0471976. Otherwise it hides the hierarchy. Translation is updated in every branch; outside the depth threshold neither z nor the angle is changed. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/inlines.h#L120-L142)
- Sequence update always calls the two interface routines first. Further work occurs only when the sequence map object is absent. Both predicate outcomes decrement `xCC` and test its previous value against zero; a previous value of zero does not trigger creation or the terminal ground call. Creation is unchecked before dereferencing user data, followed by setup, slot increment and timer reset to zero. An existing sequence object suppresses the predicate, timer decrement and creation/terminal branches. The meanings of the selector word and slot, and the lifetime effects of external setup/terminal calls, remain external to this header. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/inlines.h#L144-L168)
- `Ground_ClampSymmetric` writes only when a bound comparison succeeds: it leaves `*out` unchanged for an in-range input under the usual nonnegative-limit assumption. It is not a general assignment of a clamped input. `Ground_WrapAngle` performs at most one ±τ adjustment, with strict comparisons, leaving ±τ unchanged and potentially leaving large magnitudes outside the interval. `rand_range` orders its endpoints before adding `HSD_Randi` of their difference, returning the common endpoint without randomness when equal. Exact random bounds depend on the external generator; endpoint subtraction has no overflow guard. `ZRANDI` bypasses the generator for zero but can evaluate its argument twice. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/inlines.h#L170-L202)
