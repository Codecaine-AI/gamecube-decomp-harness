## Mr. Game & Watch character integration

This unit defines the character-specific motion-state table, resource descriptors, load/death hooks, aggregate move-prop cleanup, held-item event adapters, attribute copying, article-color outputs, and Oil Panic absorption/overlay adapters.

### Dispatch and resources

The 40 MotionState initializers cover the source-commented state range 341–380: jab; rapid-jab start/loop/end; down tilt; forward smash; neutral/back/up aerials and their landings; grounded/aerial Chef; nine grounded and nine aerial Judgment outcomes; grounded/aerial Fire; and grounded/aerial Oil Panic loop/catch/shoot. Every entry uses ftCamera_UpdateCameraBox. Judgment outcomes have distinct submotions but share phase callbacks within each environment; they do not have nine independent callback implementations. Oil Panic shoot descriptors use the corresponding catch motion flags. Five mutable resource strings, a four-string demo descriptor, four identical costume-resource entries with NULL material-animation labels, and ftGw_CostumeList[4] are declared. These are source-level observations, not proof of compiled section composition or layout. ### Initialization and death

OnLoad clears x2222_b6, sets x2223_b1 and x2224_b0, copies external attributes into dat_attrs_backup and points dat_attrs there, and initializes panicCharge to ftGw_Panic_Empty. Attributes supply z scale, outline color, and costume-indexed material color. items[10] is cached in x5AC.xC[4]; items[0..9] are paired with Greenhouse, Manhole, Fire, Parachute, Turtle, Breath, Judge, Panic, Chef, and Rescue respectively. No additional meaning is assigned to the flag bits or cached eleventh resource. LoadSpecialAttrs instead copies the external typed structure into the current dat_attrs destination. ### Cleanup and held items

OnDamage unconditionally dispatches nine ordered cleanup calls for Greenhouse, Manhole, torch, Parachute, Turtle, Sparky, Judgment, Panic, and Rescue. ftGw_Init_8014A538 dispatches the identical sequence only for GA_Air. It observes rather than creates a transition; Attack11 invokes it after common collision processing. Actual teardown and retained-reference changes belong to the move-specific callees. The aggregate sequence must not be extended to independently launched Chef/Breath projectiles. ### Colors and Oil Panic lifetime

ftGw_Init_8014A7F4 writes the costume-indexed primary color to the supplied output; ftGw_Init_8014A814 writes the fixed outline color. Shared item initialization consumes a temporary GXColor for material setup and separately initializes item xBC8. Proposed names remain descriptive hypotheses, not recovered historical symbols. [Outputs](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftGameWatch/ftgamewatch.c#L630-L647) [Consumers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itzako.c#L717-L733)

UnkMotionStates4 requests color animation 5 with secondary argument 0 for full-or-higher charge, without consuming charge. The callee can return failure, which this wrapper ignores. OnAbsorb delegates once: the callee adds absorbed hits and damage without clamping, requests the overlay at full-or-higher charge, chooses grounded catch for GA_Ground and aerial catch otherwise, changes motion state, and updates the bucket model. Release routines consume stored damage and reset charge/damage; load is another charge-reset boundary, whereas this death callback preserves charge.
