## Audio and the restoration correction

**The sound-mode callback applies the current editable selection, not an immutable pre-session backup.** `un_802FF934` forwards `un_804D6DBC` to `lbAudioAx_80024C08`; the Sound Mode descriptor binds that same variable and callback. The setter maps its two accepted modes through `{1,0}`, avoids a redundant synth update and rejects other inputs. The callback does not inspect its result and has no explicit return despite its bool declaration. This replaces the inherited sentence saying that callbacks restore the saved audio value. The sole proposed purpose fact is preserved unchanged.

These bindings are established, not pending research. Their labels must not be used to rename backend buses: the exact three variable-to-callee pairings remain authoritative. DSP handling byte-truncates its value before delegation and forwards the event to the FGM callback. Detailed auxiliary-send/channel terminology remains deferred.

Group selection sums slot-6 counts to produce a flattened interval in entry 7. The FGM callback stops on event 0 and stops before requesting a slot-5 indexed sound on event 1. The BGM callback requests a new selection or toggles the local pause bit on repeated event 1; event 0 stops and resets its local cache.
