## Scope and implementation
The owned C file implements Koopa/Bowser's paired grounded and aerial SpecialHi callback families, corresponding to the existing Whirling Fortress mapping. The header declares all ten exported callbacks. Both canonical and rendered files were read completely; rendered substitutions were treated as hypotheses, not independent evidence.

### Entry and lifetime
Ground entry selects motion state `0x167`; aerial entry selects `0x168`. Both reset command variables 0–3 and selected move-variable fields, consume all available jumps, spawn effect `0x4DA`, set `x2219_b0`, install effect-hitlag callbacks, and call `ftAnim_8006EBA4`. Shared setup assigns `ftKp_Init_80132B38` to damage and secondary-death callbacks; its pinned definition is empty, so these assignments must not be described as effect cleanup. Ground entry zeros vertical self velocity. Air entry clamps `gr_vel` using attribute `x60`, sets vertical self velocity from `x54`, and immediately invokes the grounded-named `ftKp_SpecialHi_Anim`, not the aerial animation callback. [Entry source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKoopa/ftkoopaspecialhi.c#L20-L68).

### Animation and termination
Both animation callbacks increment `mv.co.walk.middle_anim_frame` and call `ftKp_SpecialN_80135780`. The independently read shared helper selects command variable 2 on ground or 1 in air and controls model presentation, hurt capsules, common state, and `x221E_b4`. Ground animation exhaustion calls `ft_8008A2BC`; its neutral router defaults to Wait but includes exceptional early routes, so Wait is not unconditional.

Air animation has an important nested guard: when command variable 2 equals 2, only an airborne fighter takes the exit. That exit destroys effects, clears the effect flag and pre/post-hitlag callbacks, and chooses ordinary Fall for zero `x7C` or `ftCo_80096900` for nonzero `x7C`. If the command equals 2 while not airborne, the natural-completion test is skipped. Only when the command differs from 2 does animation exhaustion select the other fall exit; that branch does not explicitly perform the same effect destruction or callback clearing. Both exits call `ftCommon_8007D60C`, whose canonical body sets airborne state, consumes jumps and locks the ECB rather than performing generic effect cleanup. [Animation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKoopa/ftkoopaspecialhi.c#L70-L109), [shared shell helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKoopa/ftkoopaspecialn.c#L404-L450), [completion dispatcher](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_08A1.c#L54-L109).

### IASA and movement
Both IASA definitions are empty; this establishes no interrupt processing in these hooks, not global uninterruptibility. Command variable 0 selects move-specific movement versus common physics. Ground movement uses `x68` and `x60` for stick-scaled acceleration/target speed and applies floor-relative movement; the alternate path applies common ground friction with an above-walk-speed multiplier. Air movement uses `x58`/`x5C` for gravity/terminal velocity and `x6C`/`x64` for horizontal control; the alternate path uses common fast-fall, gravity and drift processing. These interpretations were checked against canonical common helper bodies. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKoopa/ftkoopaspecialhi.c#L111-L139).

### Collision and continuation
Ground collision transfers to `0x168` specifically when `ft_80082708(gobj) == GA_Ground`, preserving the current animation frame with flags `0x0C4C5292`, restoring callbacks, clamping horizontal self velocity and clearing `x10`. The other branch sets `x10`. The comparison label is preserved literally rather than interpreted as the resulting physical state.

Air collision distinguishes nonnegative vertical velocity from descent. The nonnegative branch converts to ground when `ft_80081D0C(gobj) != GA_Ground` and always runs the shell/orientation helper afterward. Descending accepted ground/ledge contact converts to ground, sets `x10`, updates presentation and reinstalls effect-hitlag callbacks. Descending without contact clears `x10` and may dispatch cliff entry; it does not run the orientation helper on that path. Rotation uses facing-adjusted `atan2f(floor.normal.x, floor.normal.y)` only when command variable 3 and `x10` are both nonzero; otherwise the invoked alignment helper resets rotation.

The landing helper contains `da->x70 = da->x70` and the contradictory condition `x70 < middle_anim_frame && middle_anim_frame < x70`. Its written true branch subtracts `x78`; its ordinary false branch preserves the frame. No intended two-threshold window or reachable offset behavior is inferred.
