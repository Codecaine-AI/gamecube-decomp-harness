## Super Scope physical item

This unit implements the physical Super Scope, not its separately allocated beam projectiles. Its five callback-table indices are **0 resting**, **1 ordinary falling**, **2 held**, **3 dropped/thrown**, and **4 EnteredAir terrain recovery**. States 1 and 3 share animation and collision callbacks but use different physics callbacks. State 2 has no collision callback. State 3 uses animation selector 0; the other rows use -1. [Canonical table](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itsscope.c#L21-L31).

The direct constructor returns a nullable object and invokes resting setup only on success. The Spawned callback initializes `Item.xD4C` from special attributes and selects state 1. Resting setup resets velocity and selects state 0. Pickup selects state 2; drop and throw both select state 3 with mask 6, meaning animation and drop updates. EnteredAir selects state 4. Its -1 animation selector causes the shared state changer to remove animation and clear the script, not install a state-4 animation descriptor. [Constructor and initialization](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itsscope.c#L33-L52), [state changer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/item.c#L1181-L1236).

Ordinary airborne collision tests **nonzero**, not positive, ammunition. With nonzero ammunition it delegates full collision processing and supplies the resting callback, then returns false. With zero ammunition it propagates the floor-contact helper's result. State 4 independently supplies resting and falling callbacks without an ammunition guard; supported-floor dispatch remains conditional inside the shared terrain helper. The ordinary falling helper checks its speed threshold before applying acceleration rather than clamping the resulting velocity exactly. [Airborne behavior](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itsscope.c#L171-L227), [state-4 terrain branches](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itgroundcoll.c#L750-L778), [falling helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L176-L204).

## Charge, ammunition and projectile lifetime

The nominal charge classifier returns 0 at or below attribute `x4`, otherwise returns the integer quotient `duration / 8` below `x8 * 8`, and otherwise returns 9. A universal 0–9 bound requires configuration/input constraints not established here. The cost accessor handles levels 0–9 but has no default or trailing return. The ammunition-aware selector returns -1 for nonpositive ammunition; otherwise it returns the nominal level when affordable or searches downward, returning an exact-cost level or **level + 1** when a lower level costs less than the available ammunition. It can reach the end without returning. It is not an affordable-level clamp, and C source alone does not establish a pointer-valued machine-register result. [Charge helpers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itsscope.c#L62-L146).

Firing debits ammunition and clamps a negative remainder before unconditionally requesting beam creation. Allocation failure does not refund ammunition. Although the local final float parameter is named `scale`, the actual fighter caller supplies facing direction and the beam constructor stores it as `SpawnItem.facing_dir`. The constructor retains the charge variant and fighter references; projectile setup retains its owner and derives velocity, visual scale and lifetime from the variant. The offset getter is consumed by the actual Scope firing path before coordinate conversion and projectile/effect placement. [Firing transaction](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itsscope.c#L138-L154), [fighter consumer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_ItemScopeFire.c#L125-L160), [beam construction and setup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itsscopebeam.c#L37-L109).

Damage dealt, clank and shield hit use the shared victim-bounce response and return false. Reflection delegates velocity/facing reversal and half-life reset. Shield bounce delegates its separate shared response. EvtUnk forwards both object pointers unchanged; its precise dispatch trigger is not established by this wrapper. [Interaction adapters](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itsscope.c#L229-L278), [shared responses](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L395-L456).
