## Functionality

- **Bank loading and ownership:** A six-entry request queue serializes SFX-file loading. The initial header drives separate metadata and sample requests. Completion installs bank-owned metadata allocations and sound-ID hash entries, optionally notifies the requester, advances the bank cursor, and removes the queue head. Active cancellation is cooperative; queued cancellation removes one matching request immediately. Whole-bank unload stops matching voices, unregisters definitions, frees metadata, and rewinds the bank cursor. Selective unload removes only the first matching file allocation and does not itself stop voices or reclaim its ARAM extent. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/synth.c#L49-L352)
- **Relocation:** Group readdressing submits asynchronous payload moves and immediately rebases embedded sample addresses. A shared outstanding-operation counter and separate spin barrier coordinate completion. BankDeflag's final store indexes beyond the declared bank-head array; its intended free-cursor publication cannot be established from declaration order alone. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/synth.c#L354-L429)
- **Voice lifetime:** Core playback resolves resource IDs, acquires AX voices, installs sample and ADPCM parameters, and returns generation-qualified handles. Paired effects mark the secondary slot with -1. Drop handling invalidates the logical effect and defers sibling voice reclamation until the synthesis callback. Ordinary key-off ramps toward silence before release; loading-state nodes take an immediate-release branch. Group replacement requests key-off rather than guaranteeing instantaneous audible exclusivity. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/synth.c#L448-L739)
- **Controls and periodic processing:** Volume setters schedule coalesced pending work. The processor advances channel and per-node targets, computes composite gain, clamps envelope deltas to [-20,20], and completes deferred pause or key-off. The signed composite target itself is not clamped to a nominal 15-bit range. Tracked volume is stored as u16, including narrowing after incremental updates; the settling branch explicitly casts the target to u16 for tracked storage and narrows it into the AX envelope's u16 currentVolume. This is not unconditional exact publication of the signed target. Pan controls feed complementary square-root gains and a quantized ITD table; main, Aux A, and Aux B gains are independent. Pitch uses a base factor and two stored multipliers. [Processing](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/synth.c#L741-L1127), [Tracked storage](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/synth.static.h#L19-L31), [AX envelope](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/include/dolphin/ax.h#L56-L59)
- **Cross-file callbacks:** Single callback slots synchronize synth-node retirement, pause completion, and frame timing with AXDriver records. The master-clock slot accepts an integer while its concrete installed handler is declared parameterless; this prototype mismatch remains explicit. [Synth](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/synth.c#L1129-L1183), [AXDriver](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/axdriver.c#L440-L519)
- **Streaming:** A singleton current handle coordinates a three-slot, 64-KiB-per-slot ARAM ring. Header and payload callbacks initialize AX voices; recurring maintenance updates end addresses, loop addresses, and ADPCM loop history and schedules safe-slot refills. HSD_Synth_804D7778 is an operation-in-flight latch, not a playback-active flag. Running old streams can remain in deferred shutdown after current-handle replacement. Initial stream voice acquisition is unchecked, and the two-voice header path does not reproduce the core SFX player's secondary-slot bookkeeping. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/synth.c#L1185-L1459)
- **Initialization and master gain:** Only bank_size is consumed by HSD_SynthInit; bootstrap and stream reservations are fixed at 0x500 and 0x30000. Initialization establishes channel defaults and registers the synthesis callback. The shared master gain affects both AI hardware-stream channels and AX-backed synthesis envelopes. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/synth.c#L1461-L1534)
