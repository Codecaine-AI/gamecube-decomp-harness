## Regular-ending display

This unit constructs and operates the regular-ending presentation: animated fog, lighting, camera, two background hierarchies, surrounding character-trophy displays, and a separately featured current-character model. The constructor is `gm_801A9630`; its inferred SetupScene name is descriptive, not proof of an original symbol or formal OnEnter registration.

### Inputs and cross-file lifetime

The resources consumed here are produced by `gm_801A6EE4` in `gmregtyfall.c`: selected-character joint data, `GmRegEnd` scene descriptors, `GmRgStnd.dat`, and a mode-selected trophy-display archive. Classic and Adventure have explicit branches; debug mode supplies another mode selector; the default uses All-Star resources. This unit does not load or release those archives itself. Their required lifetime extends through construction and subsequent use of the attached scene resources; complete teardown ownership remains outside the verified evidence. ### Selection and placement

`gm_80480A00` is declared as 52 GObj pointers, but setup clears only entries 0–25. The separate 26-element `gm_80480AD0` array receives random ordering keys for truthy mapped trophy records and zero otherwise. `gm_801A8D54` rebuilds a 26-element output list padded with sentinel 26. Ordinary candidates exclude the current character; candidates 18 and 19 both exclude themselves whenever the current character is Zelda or Sheik. Valid entries are sorted by nondecreasing key, including swaps on equality; this is not a stable-sort or uniform-permutation guarantee. [Tables and selector](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmregenddisp.c#L205-L263), [initialization](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmregenddisp.c#L376-L396).

`gm_801A9094` visits slots 25 down to 0 and skips sentinel entries. Each valid entry selects display metadata and archive joint/material-animation resources, creates a renderable GObj with a uniformly scaled 1.8 root, attaches a model and common stand, evaluates the selected material-animation frame, applies metadata offsets, and stores the GObj by character index. Assertions explicitly cover the selected joint descriptor and loaded model, not every allocation or archive result. [Construction](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmregenddisp.c#L265-L325).

### Featured model and animation

`gm_801A8114` applies metadata selectors 0–2 as child translation, selector 5 as degree-to-radian yaw, and selector 3 times the reciprocal of selector 4 as uniform child scale. Its null-root branch is not a graceful failure path: setters are still called with the resulting child pointer, and the explicit assertion occurs later. No zero-denominator guard exists. The featured model is subsequently passed, with a third-level descendant of the second background, to both constraint-binding helpers. The second background uses joint data from `gm_804D67AC` but animation model data from `gm_804D67A4`; this distinction is intentional evidence, not normalized away. [Transform](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmregenddisp.c#L74-L97), [wiring](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmregenddisp.c#L477-L515).

The light callback delegates to `HSD_LObjAnimAll`. Featured-character and first-background callbacks delegate to `HSD_JObjAnimAll`; downstream hierarchy traversal is null-safe, evaluates a node before descendants, suppresses child traversal at JOBJ_INSTANCE nodes, and invokes accumulated end callbacks afterward. The second-background callback additionally overwrites root Z with 2 after animation and requests sound 0x7EF41 with arguments 0x7F and 0x40 when `gm_801A4BA8()` equals 0x174. That accessor reads the main-loop update token, normally incremented after GObj processing; it is not established merely by the rendered GetFrameCount hypothesis. The callback has no private sound latch. ### Pacing and completion

Both count helpers scan all 26 mappings and count truthy `Toy_803048C0` results. This is not the filtered surrounding-display count, and it does not sum trophy quantities. Fog advances below frame 185 for counts at most 5, below 200 for the next band through 13, and without a custom frame guard above that. Camera advances below 160, below 190, or below its own end frame for the corresponding bands. Counts are recomputed; the second helper is called only after the first count exceeds 5. These guards do not clamp an overshooting animation frame or permanently latch a stopped state. [Count helpers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/inlines.h#L18-L41), [fog](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmregenddisp.c#L29-L54), [camera](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmregenddisp.c#L337-L369).

Setup initializes `gm_804D67C4` to 180. Only camera invocations whose applicable playback guard fails decrement it. Exact zero calls `gm_801A4B60`, which writes scene-request state 1; there is no local saturation or post-zero latch. Thus 180 denotes qualifying callback invocations, not an independently measured wall-clock duration.
