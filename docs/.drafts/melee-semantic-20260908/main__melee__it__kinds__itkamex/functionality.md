## Kamex / Blastoise and Hydro Pump

This translation unit implements two distinct item lifecycles: the Blastoise summon and its Hydro Pump projectiles. The global Pokémon table explicitly registers the actor and projectile separately ([actor registration](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_279C.c#L127-L144), [projectile registration](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_279C.c#L631-L648)). The header declares the implementation's functions and both state tables; its rendered declarations agree with the rendered definitions.

### Actor lifecycle

The actor table has four entries. Initialization establishes the timer sentinel `-1`, clears the firing command flag and shot-side/recoil fields, performs common Pokémon setup, enters state-table index 3, and requests sound `0x271E`. Index 3 has animation identifier `-1`; these are different numeric domains. Its callbacks delegate common appearance scaling, spawn motion/countdown, and terrain processing. The appearance physics wrapper ignores the common helper's completion result; collision supplies the continuation that resets velocity and enters state 0 ([initialization and table](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itkamex.c#L13-L108), [appearance wrappers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itkamex.c#L198-L217), [common appearance behavior](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_279C.c#L1077-L1130)).

State 0 advances to state 1 when its animation predicate becomes zero. State 1 loads its counter and recoil parameters only when the counter equals `-1`, then selects animation/state 1 and installs the firing accessory. Its counter changes only at completed-animation boundaries: a positive value is decremented and state 1 restarts; a nonpositive value is clamped to zero, horizontal velocity is cleared, and state 2 begins. Thus this is not a per-frame countdown or a proven shot count. State 2 returns true when its animation finishes; the generic animation dispatcher turns a true result into item destruction ([actor callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itkamex.c#L68-L196), [dispatcher](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/item.c#L1280-L1290)).

States 0–2 apply falling physics only for `GA_Air` and dispatch terrain handling through the air or ground helper, passing an empty local transition hook. The shared helpers can still mutate collision state; an empty hook does not make their processing a no-op. State-1 physics additionally adds `x6C * facing_dir` under the exact opposing-velocity guards. This normally counteracts recoil but does not clamp velocity to zero. The falling helper likewise uses a pre-update sign/speed test rather than a post-update clamp ([physics and collision](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itkamex.c#L76-L195), [falling helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L176-L204)).

### Firing and projectile lifetime

The accessory consumes a set animation-command flag by making one Hydro Pump spawn attempt, assigning opposite-facing recoil, and clearing the flag. The constructor puts cannon-relative offsets into `spawn.prev_pos`, while `spawn.pos` is independently obtained from the actor's ECB center. It supplies forward horizontal velocity, zero Y/Z velocity, the actor's owner as first parent, and the actor itself as second parent. The depth-side toggle changes before allocation is tested, so failed attempts still alternate sides; the caller still applies recoil and consumes the flag. Only successful creation produces the directional sound, with `0x271D` selected for exactly `facing_dir == 1.0f` and `0x271C` otherwise ([accessory](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itkamex.c#L154-L162), [constructor](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itkamex.c#L219-L254), [ECB output](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L660-L674)).

Each projectile has a separate one-entry state table. Its spawn callback loads attribute `x0` into its lifetime, performs setup and enters state 0, then sets the root model scale to `(0.2, 0.2, 0.2)`. State entry requests effect `0x46A` with scale argument `1.2f` and installs effect hitlag callbacks. Animation pre-decrements the lifetime and returns true when the result is nonpositive. Physics adds `0.06` to every scale component only while pre-update X is below `1.0`; it can overshoot and does not clamp. Collision directly returns the shared terrain helper's result. The named interaction callbacks return constant true for `HitShield` and false for `DmgDealt`, without local side effects; their names alone do not establish every downstream event interpretation ([projectile implementation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itkamex.c#L256-L325), [terrain helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itgroundcoll.c#L366-L387)).

### Cross-file state and reference lifetimes

State changes replace the standard callbacks and clear `on_accessory` and hitlag callbacks. State-1 entry reinstalls its accessory after that reset; state-2 entry does not, so the firing accessory is not implicitly retained into the ending phase ([generic callback replacement](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/item.c#L1229-L1241), [local setup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itkamex.c#L95-L169)). Actor and projectile reference events both delegate to the common cleanup helper, which clears matching owner, reflector, absorber, fighter, unknown-fighter and toucher references, resetting source-player metadata to 6 when the fighter reference matches. Both wrappers discard its owner-match return. The generic invalidation caller separately preserves the old owner for its conditional destruction decision; reference cleanup itself is not proof that an item survives invalidation ([cleanup and caller](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L475-L525)).
