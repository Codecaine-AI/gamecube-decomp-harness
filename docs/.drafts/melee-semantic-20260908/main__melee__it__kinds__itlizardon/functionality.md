## Lizardon / Charizard implementation

The canonical Pokémon registry identifies this parent actor as Lizardon (Charizard), independently of rendered naming hypotheses (`code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_279C.c#L163-L198`). The owned source defines a four-entry parent state table and a separate one-entry emitted-article table; their compiled section sizes and placement are not established by these declarations.

### Parent state machine

Spawn initialization clears three item-command variables, initializes the attack-counter sentinel and direction/emission/sound-parity fields, enters the common airborne state, invokes attribute-dependent Pokémon setup and requests sound 0x2719. State 0 delegates appearance scaling and physics to shared Pokémon routines. Its collision path supplies a callback that resets velocity and enters state 1; shared floor-contact processing restores model scale after invoking that callback. State 1 advances into state 2 when its animation predicate becomes false. States 1–3 share airborne-only falling physics and ground/air terrain dispatch (`code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itlizardon.c#L53-L169`, `code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itgroundcoll.c#L583-L613`).

State 2 initializes x60 only when it equals -1, reading the storage at special attribute x4 through an s32 pointer rather than numerically converting a float. Every entry reloads five effect-cadence fields and installs the accessory callback. At animation completion, a positive x60 is decremented before re-entry; a nonpositive value is clamped to zero and enters state 3. State 3 reports completion when its animation predicate becomes false. The exact visible actions of numeric states 1 and 3 remain less certain than these transitions (`code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itlizardon.c#L128-L159`, `code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itlizardon.c#L268-L312`).

### Emission and exceptional paths

The accessory callback consumes a one-shot direction-change latch independently of the active-emission gate. While emission is enabled, it updates six interval counters: the float article countdown x68, randomized effect countdown x70 and four fixed effect countdowns x74. Article emission requires the decremented float to equal exactly zero; effect emission requires negative integer countdowns. The four synchronized-effect checks are independent, and their shared scale variable is updated cumulatively if several fire in one invocation. No attribute values were inspected to guarantee positive intervals or an upward launch angle (`code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itlizardon.c#L180-L266`).

Child construction uses bone 0x32 for SpawnItem.prev_pos, but obtains SpawnItem.pos separately from the parent's ECB-centered position helper. It computes planar velocity from attribute-derived randomized angle and speed, records both the parent's owner and the parent actor, and requests the caller-selected item kind. Only successful creation toggles sound parity; failed creation neither toggles parity nor requests an emission sound (`code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itlizardon.c#L314-L360`, `code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L660-L674`).

### Emitted articles and lifetime boundaries

Logic34–37 attach effects 0x44E–0x451, respectively, with scale 0.71428573 times item scale, then enter shared article state 0. That state separately delegates lifetime progression, multiplies all velocity components by the child's floating x4 attribute and returns the common collision result. Source proves multiplication, not that arbitrary x4 values necessarily attenuate velocity. Reflection delegates to shared handling; shield and absorption callbacks return true without local cleanup. Parent and child two-object event wrappers delegate reference cleanup, whose canonical implementation clears matching owner/interaction pointers and resets source-player metadata when appropriate. These wrappers do not themselves establish when parent removal occurs or whether emitted articles must disappear with it (`code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itlizardon.c#L362-L464`, `code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L493-L525`).
