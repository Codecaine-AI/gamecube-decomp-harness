## Scope and naming
The TU implements fighter-side LipstickSwing entry, four lifecycle adapters, and an accessory callback. Canonical address-named symbols remain `ftCo_800CDAB4` and `ft_800CDB9C`; rendered Enter/Accessory4 aliases are naming hypotheses, not independent evidence. Inherited full-file and subject coverage is accepted. No compiled section or register assignments are inferred.

## Entry and dispatch

Common setup clears throw flags, changes motion at frame zero, calls `ftAnim_8006EBA4`, sets swing latch x0 to 1, records the variant in x4, and calls `ftCommon_8007E79C(gobj,1)`. The dispatcher maps item-kind 23 to family 5, whose ordinary motion row is `{140,141,142,-1,143}`. Variant 3 instead selects family+341 for Captain and asserts for other kinds; variants 0 and 1 may return through the pickup helper. Item presence is asserted, but arbitrary variant indexes, motion IDs and playback-rate floats are not generally validated. ## Accessory events and boundaries
The callback reads fighter data and joint index before asserting Lipstick item kind, then checks item presence. Since `itGetKind` unconditionally dereferences its object, the later guard does not establish assertion-enabled null safety. Diagnostic argument 99 is not the current source line. If execution reaches the null check with no item, command and throw-bit consumption are skipped.

With an item, any sound command other than exactly 540000 requests one sound: a zero status result selects the command, otherwise SFX 288; both use 127 and 64. The command resets to 540000. Independently, `ftCheckThrowB0` consumes a set bit and gates attribute-offset transformation through the selected joint. A second status query selects effect 1032 when Lipstick resource xD4C is <=0, or `it_80295770` when positive. That helper decrements positive resource before calling `it_8029A114` with item owner, position, facing and mode. One remaining unit permits the request and becomes zero; no rollback appears here. Sound IDs, joint indexes, facing, mode and exceptional floats are not locally sanitized.
