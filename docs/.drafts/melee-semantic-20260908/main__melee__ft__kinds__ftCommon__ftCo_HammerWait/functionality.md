## Animation and callbacks
ftCo_800C4F64 and HammerWait_Anim share one body. Nonzero x2338.x takes priority and requests ordinary fighter hit-capsule reset. Otherwise attack occurrence/metadata and held-item metadata are refreshed only for 0 <= cur_anim_frame < frame_speed_mul. Zero is included; the upper bound is excluded. Nonpositive speed admits no frame, and NaN suppresses the comparison branch. Positive infinite speed admits finite nonnegative frames but not an infinite frame. Headless processing does not depend on these comparisons.

HammerWait_IASA short-circuits jump startup, platform pass, turn and walk in that order. Grounded post-hold Damage IASA also reuses it, so the body is not Wait-exclusive. Phys delegates common ground friction/movement. Coll supplies HammerFall entry to the synchronous ground-loss collision wrapper; the callback is not retained.
