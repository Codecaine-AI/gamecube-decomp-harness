# TEmblem / Roy Target Test controller

The unit defines `grTFe_StageData` for `Gr_Kind_TEmblem`, using `/GrTFe.dat`, and exports that descriptor through its header. Its four-element callback table has three explicitly initialized rows and one implicitly zero-initialized row. This describes source configuration, not verified compiled section membership or physical ordering. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grtemblem.c#L38-L74), [header](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grtemblem.h#L1-L9).

Initialization passes `grTRoy_80224498` to `Ground_InitTargetStage`. The supplied factory forms the callback-row address directly from `gobj_id`, obtains the matching Ground GObj, and installs callbacks only for a non-null result. Failure reports the requested ID and returns NULL. There is no local index-range check; the null check does not validate the table index. Demo initialization and load callbacks are empty; the stage-level predicate always returns false. [Lifecycle and factory](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grtemblem.c#L76-L109).

Object 0 initializes archive-backed animation using its `Ground.map_id` and index 0; its process and fourth callbacks are empty. Objects 1 and 2 initialize through `Ground_JObjInline1`. Their predicates return false and fourth callbacks are empty. Object 1's process delegates collision refresh; object 2 first updates shared dynamics-list state and then delegates collision refresh. Object 2 alone has callback flags `(1 << 30) | (1 << 31)`; these are configuration bits, not locally demonstrated gameplay states. No visible terrain/component identity is established for these IDs. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grtemblem.c#L111-L159).

The animation helper optionally selects the root's child, replaces joint data when available, resets material state, replaces animations using nullable archive arrays, requests frame zero, optionally applies an animation flag, and evaluates the hierarchy. The helper's third parameter is declared `bool` but is used as an index and compared against zero; this pass preserves that source-level ambiguity rather than normalizing its type. [Animation helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/granime.c#L988-L1048).

Collision refresh is disabled when the per-map guard is nonzero. Otherwise it increments a shared generation counter, refreshes matching stage-descriptor joints, and then refreshes archive joints whose stamps differ. The descriptor loop itself has no duplicate-stamp guard, so a universal once-per-joint guarantee is too strong. Both wrappers discard the Boolean result. [Collision helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/ground.c#L1676-L1732).

The dynamics step sums pre-decay scale only for entries with `x0 == 1`, subtracts each entry's decay amount with a zero floor, decrements positive countdowns, increments angles, and recycles entries whose countdown equals zero. Negative countdowns are not decremented or retired by that test. Above aggregate scale 0.1, the state becomes 2 if previously positive, otherwise 1; at or below the threshold it becomes -1 if previously positive, otherwise 0. These numeric states are preserved without inventing gameplay labels. [Dynamics helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lb_00F9.c#L939-L992).

Stage start attempts shared generator-manager initialization with a NULL spawn descriptor and ignores the returned GObj. The callee creates and schedules a persistent manager, then publishes descriptor/data pointers. GObj-creation failure reports, frees the allocated data, and returns NULL without publishing those pointers; this wrapper does not recover. This is not an immediate target or opponent spawn, and manager teardown is not established here. [Start](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grtemblem.c#L85-L88), [manager](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grzakogenerator.c#L303-L328).

The touch-line hook always returns NULL; the shadow eligibility hook ignores all arguments and always returns true. That approval concerns this hook only, not every subsequent rendering decision. Canonical `StageData` field names independently support the existing lifecycle, touch-line and shadow name hypotheses. [Hooks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grtemblem.c#L161-L169), [field definitions](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/types.h#L157-L171).
