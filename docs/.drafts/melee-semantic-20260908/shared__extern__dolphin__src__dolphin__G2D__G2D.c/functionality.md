## G2D rendering support

This file implements sprite and tile-layer drawing around persistent world, camera, and viewport state. Canonical and rendered source agree: all rendered pages report zero substitutions and zero parse errors. The scoped baseline contains no subjects, facts, or links; no knowledge changes are proposed.

- **Sprites:** `G2DInitSprite` computes normalized texture coordinates inset by half a texel. `G2DDrawSprite` configures textured alpha blending and emits an orientation-dependent quad. Camera-relative positions receive conditional single-world-period corrections, not arbitrary-distance modulo normalization. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/G2D/G2D.c#L8-L87)
- **Tile collection:** `FillSection` walks inclusive scanline spans, reading byte tile indices only when `nBPI == 1` and unsigned halfword indices otherwise. Wrapped sampling masks coordinates; nonwrapped sampling clamps to edge tiles while retaining drawing coordinates. Material scratch halfwords track counts and offsets into the caller-provided sort buffer, whose records contain tile halfwords and signed-byte coordinates. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/G2D/G2D.c#L89-L240)
- **Layer visibility and batching:** `G2DDrawLayer` transforms viewport corners into tile coordinates and scans three sections according to camera orientation. Near-zero orientation adjustment uses an `if`/`else if`, not independent normalization of both components. Nonwrapped layers receive a separate world-relative map-offset adjustment. The source also repeatedly reads counts for materials 0–2 into otherwise unused locals. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/G2D/G2D.c#L289-L473)
- **Material rendering:** Zero-count and empty materials are skipped. Supported drawing paths emit indexed RGBA colors, direct RGB colors sourced from tile `nS`/`nT`/`nCI`, or textured quads with optional material-color modulation. Unrecognized categories have no drawing branch. Negative sort-buffer halfwords encode forward jumps; textured tile UVs do not use the sprite half-texel inset. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/G2D/G2D.c#L475-L684)
- **Camera, world, viewport:** Camera setup copies the pose and loads a look-at matrix with offsets based on 640×448 and an eye Z of −300. World initialization stores dimensions, computes half dimensions by integer right shift before float conversion, calls `GXSetZMode(0, GX_ALWAYS, 1)`, and installs a fixed orthographic projection. Viewport setup stores bounds and calls `GXSetScissor`; it does not call `GXSetViewport` or reload the camera matrix. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/G2D/G2D.c#L686-L736)
