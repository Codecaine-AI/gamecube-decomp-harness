### Allocation and queue organization

The source declares parallel priority head/tail arrays and an independent callback-stack root. Priority zero is a head-only intrusive free list using `next`; nonzero priorities are doubly linked queues using `next` and `prev`. Callback linkage uses the separate `next1` field, so pending callback membership does not itself remove active-priority membership. `__AXGetStackHead` is a read-only query and accepts zero within its asserted bounds. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXAlloc.c#L6-L158)

`AXAcquireVoice` first consumes the free list. On exhaustion, it searches priorities 1 through requested-priority minus one in ascending order, taking the first available queue tail. Equal and higher priorities are not eligible. A displaced voice with `pb.state == 1` receives `depop = 1`; its optional old callback runs before insertion at the requested head, ownership-metadata replacement, and PB defaulting. Failure returns null. The operation, including the preemption callback, is bracketed by interrupt disable/restore. Queue age means time since insertion, not necessarily playback age: even reprioritizing to the same priority moves the voice to the head. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXAlloc.c#L175-L221)

### Reclamation and cross-file lifetime

`AXFreeVoice` detaches an allocated voice, conditionally marks depop for numeric state 1, invokes selective PB defaulting, and pushes the descriptor into priority zero under one interrupt guard. It does not invoke the owner callback. Deferred service instead pops callback entries, invokes optional callbacks, and then masks only active-list removal and free-list insertion. It does not default the PB. Callback execution is not guaranteed to occur with interrupts enabled: service merely does not change interrupt state before calling it. [Explicit free](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXAlloc.c#L160-L173), [deferred service](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXAlloc.c#L17-L31)

Cross-file inspection confirms that `__AXSetPBDefault` resets selected PB/update state rather than clearing the descriptor; notably, it preserves `depop`, callback, and user context. `__AXSyncPBs` subsequently consumes and clears depop for both active and free voices. Its DSP-cycle-budget failure path calls `__AXDumpVPB`, which stops the relevant PB state and queues the descriptor for deferred callback reclamation. Thus depop can survive free/reacquisition until synchronization, and callback retirement is not necessarily natural playback completion. Numeric state tests are preserved without inventing a complete state enumeration. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXVPB.c#L576-L653)

Allocator initialization and shutdown only clear roots; neither drains callbacks nor populates the free pool. `AXInit` calls allocator initialization before VPB initialization, and `__AXVPBInit` subsequently initializes the fixed descriptor pool and pushes its records onto the free stack. [Allocator reset](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXAlloc.c#L33-L57), [initialization order](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AX.c#L6-L16), [pool population](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXVPB.c#L683-L718)

### Preconditions and exceptional branches

Unlinking assumes valid active membership. Its first branch tests `head == tail`, not whether the supplied node is the sole member; it does not independently reject an empty or corrupt list. Subsequent branches repair head, tail, or interior links without clearing the removed node's own links or priority. Tail-pop returns null for an empty head and also for the inconsistent case of a nonempty head with a distinct null tail. Primitive pushes/pops do not add synchronization or duplicate-membership protection. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXAlloc.c#L59-L158)

The unusual free-pop address-of-`next` expression is consistent with `next` being the first declared AXVPB member; this review does not claim portable null-pointer semantics or compiled layout from that expression. Source declarations also do not establish which objects occupy the compiled section targets.
