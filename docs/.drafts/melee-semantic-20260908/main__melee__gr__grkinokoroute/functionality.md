Initialization caches Yakumono parameters and creates components in order **2, 0, 1, 3**. Setup guards optional callbacks and nullable object acquisition. Existing supported role-based names and unchanged research knowledge are retained without equivalent rewrites. Outside phase 2, special fighter predicates preserve the current camera offset as target and set the timer to 60 or zero; ordinary traversal applies vertical and marker-dependent horizontal clamps. Encounter entry sets phase 2 and timer 60, resets shared status, starts the encounter, replaces maps 0 then 2 and disables ordinary generation with selected-item cleanup. The manager and retained descriptor/data survive. Phase 2 targets the stored marker plus 30 Y and relocates joint 4. Geometry disabling begins only on updates entering with timer zero and can repeat. Completion status 1 enters phase 3, restores geometry and joint 4, re-enables generation and recreates maps 2 then 0. Phase 3 resumes traversal without retriggering. **Camera correction:** a nonzero timer advances the offset by `(target - offset) / timer`, then decrements. At timer zero, the XYZ distance is tested against 10; above that threshold the function writes the XY components of `target + normalize(offset - target) * 10`. At or below 10 it makes no camera-offset write in this branch. This is a target-relative residual, not a maximum 10-unit movement step.
