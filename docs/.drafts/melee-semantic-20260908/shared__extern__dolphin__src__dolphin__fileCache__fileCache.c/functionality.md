- **Creation and ownership:** `DSAddCacheNode` allocates a node and a copied name, stores the supplied data and optional cleanup callback, initializes the reference count to zero, and inserts the node into the cache list. It does not check for duplicate names or data. If name allocation fails after node allocation succeeds, the node is not freed before the public operation returns NULL. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/fileCache/fileCache.c#L10-L40.
- **Lookup and acquisition:** `FindCacheNode` returns the first matching data pointer when given non-NULL data; otherwise it searches by name using `Strcmp`. It does not fall back to name lookup after a failed data search. `DSGetCacheObj` increments the matching node's reference count and returns its data, or returns NULL on a miss. A node containing NULL data still has its count incremented on successful name lookup. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/fileCache/fileCache.c#L56-L89.
- **Destruction:** `FreeCacheNode` invokes the optional callback with the address of the stored data pointer, then frees the name and node and clears the supplied node pointer. Without a callback, this function does not free the data itself. `DSEmptyCache` removes and destroys every node regardless of outstanding references; callers' retained data-pointer lifetimes consequently depend on the callback. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/fileCache/fileCache.c#L42-L54 and code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/fileCache/fileCache.c#L91-L101.
- **Purge and release:** `DSPurgeCache` removes exactly zero-reference nodes without consulting the purge flag. `DSReleaseCacheObj` finds by data pointer, decrements only a nonzero count, and removes a resulting zero-reference node only when the flag equals `DS_AUTO_PURGE`. Thus releasing an already-zero-reference node can destroy it; releasing NULL cannot find a node through this call. The flag setter only assigns the flag and does not immediately purge. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/fileCache/fileCache.c#L111-L146, with lookup behavior at #L56-L77.
- **Initialization:** `DSInitCache` selects `DS_AUTO_PURGE` and calls `DSInitList` using a local node and its link member. This file alone does not establish how the list helper uses those addresses. `CSHInitDisplayCache` initializes the global display cache and sets `DOCacheInitialized` to TRUE, without testing that flag first or explicitly emptying a prior cache.
