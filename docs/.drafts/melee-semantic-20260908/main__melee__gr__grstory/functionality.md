## Randall state lifetime and puff timing
Entry 2 initializes its timer to zero and caches the joint returned for model index 1. Its process updates moving collision before invoking the puff helper. The helper post-decrements the timer and returns when the prior value is nonnegative. Consequently zero is not the trigger: starting from zero, the first call only decrements, and the next can request an effect. A negative prior value and nonnull cached joint request effect 0x2C with bank argument 0, then reload `HSD_Randi(20)+10`, yielding 10–29. These are reload values, not exact inter-effect invocation counts. A null joint suppresses both effect request and reload, leaving subsequent calls to retry while arithmetic remains in range. The local module neither refreshes nor releases the cached joint in its empty fourth callback; ownership and teardown belong outside this local path.
