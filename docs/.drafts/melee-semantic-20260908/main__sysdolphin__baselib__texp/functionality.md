# Texture-expression construction, compilation and application

`texp.c` implements HSD's software expression layer for the GameCube TEV combiner. `texp.h` defines expression kinds, selector encodings, node payloads, resource accounting, descriptors and public interfaces. NULL, -1 and -2 encode zero, texture and raster leaves; allocated TEV and constant nodes share an owning list. Constructors prepend nodes, and constants retain external value addresses rather than copying their contents. Constant reuse compares address and component and asserts representation consistency.

Color and alpha configuration translate ordered selector/expression pairs into input metadata and acquire replacement dependencies before releasing displaced ones. TEV references distinguish selector 1 (color) from every other selector (alpha). Operation setters preserve bias and scale only when the unsigned operation value is at most GX_TEV_SUB. Texture and raster routing, component swaps and konst selection remain deferred metadata until lowering.

Compilation references both root outputs, simplifies, builds and schedules a DAG, assigns constant resources, simplifies in reverse order, then rebuilds and reschedules with the same resource accumulator. The two 32-entry work arrays establish capacity, not a locally enforced bound. Register helpers reuse assignments or perform ordered first-fit allocation. Scalar konst packing prefers K1–K3 alpha before K0–K3 RGB channels; regular allocation searches slots 4–7. Pass-through color prefers konst, whereas pass-through alpha prefers regular storage. Preselected konst selectors force regular allocation. General allocation loops can overwrite the shared selector; their following loops begin with i already equal to 4 and do not execute.

Descriptor emission consumes the schedule in reverse while prepending numbered descriptors. Lowering supplies defaults for undefined metadata and carries separate previous-color and previous-alpha initialization flags. Color emission is not independent of alpha: alpha operation values 8–13 can retain color computation despite c_ref being zero. Compilation forcibly frees TEV nodes but only unreferenced constants, leaving referenced constants available for later uploads.

`HSD_TExpSetReg` converts external values into local GXColor channels and uploads marked slots 0–3 as konst colors and 4–6 as regular colors. Slot 7 can be marked but is not uploaded. The local color array is not initialized; unwritten channels are not established hardware-state preservation. Scalar U32 passes through signed int, unlike RGB U32, and floating conversion happens before saturation. Setup uploads constants first, refreshes texture map/coordinate fields only for descriptors with a texture object, then configures each stage.

Ownership spans files: material construction supplies addresses of diffuse, alpha and specular storage; material recompilation destroys old descriptors and expressions before replacing them. Material release frees material/texture objects before expression teardown, whose destructors do not read retained value or texture pointers. Descriptor destruction saves successors before the size-class allocator overwrites freed storage and does not clear caller-owned pointers.

Exceptional behavior is preserved rather than normalized: the color fractional-konst helper panics for a repeated equal selector; FreeList's prepass literally tests c_ref twice and calls Unref with selectors 1 and 5; already-zero TEV nodes can recursively release dependencies again. These observations do not establish intended behavior or runtime reachability.
