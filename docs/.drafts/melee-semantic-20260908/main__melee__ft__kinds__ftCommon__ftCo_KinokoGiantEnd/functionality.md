## Super Mushroom giant-ending lifecycle

`Fighter_SuperMushroomEnd` checks `fn_800D2818`, returns 0 on rejection, otherwise selects grounded `ftCo_800D1BA0` or airborne `ftCo_800D1D10` with mode 0 and returns 1. The shared predicate excludes DamageIce and the inclusive mushroom-state range, then evaluates numeric status values 0/5 and `x2071_b4`; those numeric statuses are not assigned speculative gameplay names. [Dispatcher](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_KinokoGiantEnd.c#L18-L30), [predicate](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0D27.c#L50-L68).

Both fresh entries save the preceding motion ID, perform shared preparation, and enter their respective KinokoGiantEnd state with flags `0x91`, frame 0, speed 1 and zero blend. Shared initialization saves movement, selects an airborne continuation using the preceding motion, stores the mode in mushroom `x8`, initializes auxiliary scale animation with index 1 and the fighter's Y/X scale inputs, plays a sound, and stores cleanup in mushroom `x4`. Both entries also install cleanup as `take_dmg_cb`. The preparation helper is not air-specific: it includes capture handling, with separate branches for a missing victim and the `x221B_b5` relationship. [Entries and initialization](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_KinokoGiantEnd.c#L49-L110), [shared helpers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0D27.c#L70-L177).

The selected airborne continuation distinguishes FallAerial, FallSpecial/ItemParasolFallSpecial, a Peach-specific preceding motion `0x172`, and a default Fall path. The numeric Peach motion is left uninterpreted. Saved movement persists through the ending phase; surface conversion adjusts parts of that saved movement rather than performing fresh initialization. The scale helper lazily creates `x2184`, attaches animation, and interpolates fighter scale using the auxiliary joint's X scale. Completion is its AObj flag `0x40000000`, not a main-motion frame test. This unit does not free the auxiliary joint. [Continuation and auxiliary animation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0D27.c#L70-L151), [movement lifetime](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0D27.c#L163-L205).

Grounded and airborne animation callbacks both call `fn_800D2A3C` and invoke cleanup only on false. Their collision wrappers supply the counterpart-state transition callback. `fn_800D1C40` enters the grounded state; `fn_800D1DB0` enters the airborne state. Both use flags `0xC4C5081`, the current animation frame and speed, zero blend, and reinstall the damage callback. The wrappers themselves have no timer or local alternative transition; callback gating is delegated to collision helpers. This does not establish that deeper collision processing has no exceptional side effects. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_KinokoGiantEnd.c#L71-L140), [air gating](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_081B.c#L549-L556), [ground gating](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_081B.c#L1035-L1041).

Cleanup restores saved movement, clears giant bit `x2220_b5`, and reapplies the current X scale through the dependent-scale update helper. If mushroom `x8` is nonzero it calls `ftCommon_8007E2FC` and clears that field. Grounded cleanup calls `ft_8008A324` and returns; otherwise it invokes mushroom `x0` without a local null check. Damage-triggered cleanup uses the scale present at invocation; the body does not independently force scale to 1. [Cleanup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_KinokoGiantEnd.c#L32-L47), [scale dependencies](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0D27.c#L27-L34).

The lifecycle also participates in opposing-item cancellation. Poison Mushroom application can first invoke the active mushroom `x4` callback, then inspect resulting status. If giant status remains active, it enters the grounded or airborne giant-ending path with mode 1. Thus `x4` is an externally consumed interruption continuation, not merely a locally invoked animation-completion callback.
