## Input and transition results
Ordinary input calls ftWalkCommon_800DFC70; success calls Enter with 0.0F and then returns true, while failure returns false. The shared predicate only compares horizontal stick input times facing direction against walk_stick_threshold, inclusively. It does not mutate state, test grounded eligibility, measure gradual tilt or compare against dash speed. The Ottotto variant first applies the inclusive teeter_walk_threshold comparison, then short-circuits through the ordinary predicate. Both thresholds must pass; their numerical ordering is unproved. Failed comparisons perform no entry. Under ordinary IEEE comparisons, NaN fails these >= tests; infinities are not explicitly rejected. See code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Walk.c#L30-L52 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftwalkcommon.c#L58-L69.

Ottotto uses the extra-threshold predicate last; OttottoWait delegates its IASA to Ottotto. These caller paths do not establish eligibility invariants for every possible caller. ## Animation and physics
Anim forwards once to ftWalkCommon_800DFDDC. The helper uses saved walk.x0 when the ground-friction multiplier is below one, otherwise gr_vel. A speed-times-facing product <= 0 sets animation rate to zero; otherwise absolute speed is divided by the current walking offset's saved rate parameter. Invalid offsets have no default assignment. Zero/nonfinite divisors are unchecked; a NaN direction product does not take the <= 0 branch. See code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Walk.c#L77-L80 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftwalkcommon.c#L99-L128.

Phys forwards once to ftWalkCommon_800E0060. Shared physics adds stick-scaled acceleration and signed base acceleration; exactly zero stick chooses the negative base branch. Target velocity is stick x * walk_max_vel * saved multiplier. Zero target skips division. Taper applies only for 0 < gr_vel / target_vel < 1, excluding both endpoints. It saves target * common x440 in walk.x0, passes acceleration, target and friction to ftCommon_8007C98C, then calls ftCommon_ApplyGroundMovement. The wrapper has no local state transition. Nonfinite values are unchecked; a NaN target can enter the nonzero branch but its unordered ratio fails the taper tests. Qualitative convergence and attenuation assume normal finite positive data and suitable taper gain. See code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Walk.c#L106-L109 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftwalkcommon.c#L172-L214.

## Collision and ownership

That helper chooses ft_800827A0 when nonzero horizontal player-nudge velocity opposes facing; otherwise its inline path transfers position, stick and facing into collision data, calls mpColl_8004B4B0 and copies position back.
