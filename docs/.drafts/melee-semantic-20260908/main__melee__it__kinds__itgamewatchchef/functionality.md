## Chef projectile lifecycle

The unit implements Mr. Game & Watch's Chef projectile with two numeric item states. The fighter-side producer chooses a trajectory index from 0 through 4 while excluding its two stored previous choices, computes an emission position from the left-thumb joint, updates its trajectory history, and calls `it_802C837C`. That caller does not inspect the nullable spawn result, so its count/history updates are not contingent on successful item creation. The item constructor distinguishes the supplied, Z-flattened `prev_pos` from the parent-derived `pos`, records both parent references, and performs Chef-specific initialization only after successful creation. The initializer retains the trajectory index without local bounds checking and uses it for launch velocity; subsequent callbacks reuse it for spin and falling parameters. [Caller](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftGameWatch/ftgamewatchspecialn.c#L20-L88), [construction and initialization](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itgamewatchchef.c#L22-L101).

State 0 rotates the model about X, decrements the active timer, and enters state 1 on expiry while returning false. Its physics callback delegates indexed falling parameters to the common helper; that helper uses a sign-sensitive speed threshold rather than clamping velocity exactly to a terminal value. Collision processing is skipped entirely when X velocity is zero. Otherwise, mask `0xC` multiplies X velocity by `-attrs->x4`, and the independent mask `3` test enters state 1. Both branches can execute in the same call, with the terminal transition clearing the preceding rebound. Neither attenuation nor a particular coefficient range is established by this source. [State 0](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itgamewatchchef.c#L75-L130), [falling helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L176-L204).

State-1 entry clears X/Y velocity, initializes the terminal lifetime, and selects state 1. Its animation callback decrements the timer, clamps nonpositive values to zero and returns true before performing any visibility update. Otherwise, bit 1 of the integer-converted timer selects show/hide behavior. Its physics callback is empty, and collision delegates to state 0: normally the zero-X guard makes this inert, but externally restored horizontal motion can cause collision processing and terminal-timer reinitialization. [Terminal state](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itgamewatchchef.c#L120-L154).

Damage dealt, clank and direct shield hit enter the terminal phase without immediately returning a destruction request. Absorption additionally zeros the terminal timer, preparing removal on the next state-1 animation update; implementation of this callback does not establish normal gameplay absorbability. Shield bounce delegates its result to the common shield helper. Reflection delegates to an inline that applies common reflection processing, updates Y rotation from facing direction and returns false. The unknown-event adapter forwards both object pointers unchanged; its precise event trigger is not established locally.
