## Home-Run Stadium runtime
Registers Gr_Kind_Homerun with eleven component callback sets. Startup computes locale-sensitive course calibration, creates map 0 and controller 10, requests the authored Bat, and extends right camera/blast-zone ranges. The start hook separately creates the shared generator manager with a NULL descriptor.

The controller owns a 64-slot streamed-parts array, 16 rear pieces, four repeating background objects and a dedicated SIS camera. Its process returns early without P1, disables available player camera subjects, updates distance from Sandbag X, and combines a qualifying collision latch with Y < 4 to set shared bit 7. The latch is reset only after the P1 guard. It lazily creates the zero label, adjusts at most one part at each window edge, wraps backgrounds around camera interest and refreshes collision.

Course construction cycles ordinary/marker pairs 4/5, 1/2, 6/7 and 8/9. It retains a logical index, narrowed signed graduation and placement. Marker variants initialize an indexed JObj anchor and empty text cache, create/position decimal labels once and remove them through callback3. Generic Ground teardown invokes that callback before continuing destruction. Controller cleanup is empty: marker-label ownership must not be generalized to controller arrays, camera or zero label.

Calibration uses JP versus non-JP values, whereas live-distance conversion tests saved US language separately. Distance is clamped at zero and published to stage_info.x6E0; the mode consumer performs record comparisons and localized digit display. The text camera copies available gameplay-camera settings but still attempts activation when the main camera is absent. Shadow eligibility is a strict reference-height comparison. The pause-camera getter supplies five times stage Y scale, with the common accessor's 1.0 fallback.

Most baseline names and explanations fit and are explicitly retained. Corrections address BobOmbRain/Bat confusion, non-returning terminology, conditional latch lifetime, text-helper ownership and the Bat-dispatch veto. Source literals and declarations do not prove compiled section inventories. Header rendering has four shadowed bindings and no parse errors; names remain hypotheses.
