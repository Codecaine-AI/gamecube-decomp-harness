# Joint Rotation and Planar IK

Four routines reconstruct a hierarchy-dependent joint matrix, adjust bounded Z rotation, compose an external-axis rotation and solve a two-segment planar IK adjustment. The file comment mentions planting fighter legs, but consumer setup has not been independently reviewed.

The hierarchy helper preserves subject matrix-column magnitudes while removing ordinary ancestor scale. It does not guarantee an orthonormal result. Subject columns invert magnitude above 1e-10; ancestor columns use 1e-5. Smaller magnitudes are multiplied as-is. The axis-rotation helper transposes that result and builds the incremental rotation from the negative input angle.

The IK solver modifies projected positions and measured lengths before changing both JObjs. Its initial len0 sine adjustment is overwritten by the measured pos0-to-pos1 length. For S=10*(len0+len1)/11 and requested distance d>S, it uses effective distance 11*S/10-S^11/(10*d^10). It then computes clamped law-of-cosines terms and modifies the second angle near full extension.

Zero denominators are unchecked, cosine comparisons do not reject NaN, and sqrtf_store returns nonpositive inputs unchanged. Bounded Z adjustment tests whether the computed f32 sum of squared direction components equals zero, which can include underflow from tiny nonzero components, but dir.z otherwise does not enter its atan2 expression. The limit ordering is unchecked. The lower clamp runs after the upper clamp and can exceed max_angle when -min_angle > max_angle.
