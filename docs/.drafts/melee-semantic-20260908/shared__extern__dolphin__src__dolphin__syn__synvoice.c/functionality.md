## Voice lifecycle support

The file defines a 64-entry `__SYNVoice` array and three lifecycle helpers. Canonical and rendered names agree; the rendered view contains no substitutions or parse errors. Existing function names fit the implementation. There are no baseline subjects, facts, or links to correct or retain.

- `__SYNClearVoiceReferences` obtains the synth from the AX voice's `userContext` and selects the software voice by AX index. It asserts the input, synth, and index bound, releases the mixer channel, clears a nonzero key-group entry, and clears the per-channel/key mapping only if that mapping still points to this voice. It then clears `voice->synth` and decrements the synth note count. It does not call `AXFreeVoice`. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synvoice.c#L9-L34.
- `__SYNSetVoiceToRelease` asserts the voice, assigns numeric state 3 to both envelope state fields, and applies the supplied AX priority. The name supports a release interpretation, but this file does not define the complete envelope state machines. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synvoice.c#L36-L42.
- `__SYNServiceVoice` indexes the global array without a local bounds check and does nothing for a voice with no synth. When `type == 0` and AX parameter-block `state == 0`, it clears the nonzero key-group reference and conditionally clears the matching per-key reference, then assigns volume-envelope state 4. It always runs the volume envelope before testing whether its resulting state is 4. That retirement path clears the key-group reference, detaches the synth, releases the mixer channel, frees the AX voice, decrements notes, and returns. Otherwise it runs LFO, pitch envelope, mix update, and source update in that order. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synvoice.c#L44-L79.

### Lifetime and interpretation boundaries
The general state-4 retirement branch does not itself clear the per-key voice mapping; that clearing occurs in the earlier special branch and in the separate clear-reference helper.
