## Jigglypuff initialization and framework integration

The translation unit defines 32 motion-state descriptors, covering five aerial jumps, the multi-phase neutral special, ground/air side special, and facing-dependent ground/air up and down specials. Every descriptor uses the common camera updater. State IDs, submotion IDs and flag values remain distinct; notably, the airborne neutral-special turn entry uses `ftPr_MF_SpecialN`. Resource declarations include fighter and animation archives, demo strings, five costume records, four alternate-costume hat names plus a null default entry, two numeric arrays and a collision box. These source declarations do not establish compiled section boundaries. [Dispatch and resources](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPurin/ftpurin.c#L29-L439).

### Costume accessory lifetime

`ftPr_Init_8013C2F8` clears indices 0–4 of a backing array declared with six elements. Setup lazily caches archive-owned joint descriptors by costume ID, but allocates fresh per-fighter part storage and loads a fresh JObj hierarchy. The default costume only receives a null accessory pointer; setup is not a demonstrated safe replacement operation for an already-live accessory. Teardown is guarded by the JObj pointer and removes the hierarchy, frees the associated allocation, and clears both ownership pointers; it does not clear the shared descriptor cache. Generic unload ordering and archive-cache invalidation remain unresolved. [Construction and destruction](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPurin/ftpurin.c#L424-L506).

Rendering requires both an accessory and `x2225_b2`. It copies the matrix directly indexed by `FtPart_LLegJA`, sets three named matrix flags, requests dirty handling and submits the hierarchy with the supplied view matrix and converted draw-pass argument. The generic part name is not independent proof of anatomical attachment. Visibility dispatch selects complementary operations on accessory visibility metadata; shared helpers additionally test lookup presence and cached cleared state. The selector callback returns the accessory when present, otherwise the input GObj cast to `HSD_JObj*`—not NULL or the fighter's root joint. [Accessory consumers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPurin/ftpurin.c#L508-L545), [visibility helpers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftparts.c#L629-L671).

### Framework callbacks

Load copies the typed extension attributes into fighter-owned backup storage, selects that storage as active, enables multijump, aliases the active pointer in `x2D0`, then initializes the accessory. Attribute reload copies into the existing active block. Death requests pending model-group-0 selection 0; the shared commit routine applies pending selections separately. [Load](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPurin/ftpurin.c#L547-L554), [attribute macros](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/inlines.h#L21-L41), [deferred model selection](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftparts.c#L555-L577).

Pickup suppresses all work for heavy items. For non-heavy items, numeric hold kinds 3 and 4 select saved slot-0 variants 0 and 1; kinds 1, 2 and default leave the saved choice unchanged. A separate flag requests application. Unlike visible/invisible callbacks, pickup has no local null-item guard. Visibility callbacks require a present non-heavy item. The animation subsystem distinguishes saved and active indices: application requires a saved index other than -1; removal requires an active index other than -1 and restores either the current animation or the fallback pose. Drop always clears the saved choice and conditionally removes the active animation. [Item callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPurin/ftpurin.c#L556-L603), [animation lifetime](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftanim.c#L1257-L1368), [drop helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/inlines.h#L186-L193).

Knockback entry/exit are unconditional adapters. Their fixed argument 1 is an integer selector, not a boolean enable: shared helpers call `ftAnim_800704F0` for selectors 1 and 0 with 3.0f on entry and 0.0f on exit. [Helpers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/inlines.h#L195-L205).

### SpecialHi effect

`ftPr_Init_8013C94C` spawns effect 1238 at `FtPart_WaistN` only when `x2219_b0` is clear, then sets the latch. Both branches install effect pause/resume callbacks and clear `accessory4_cb`. SpecialHi entry and ground/air transitions schedule this callback, so self-retirement does not imply it can never be scheduled again. The neighboring sleep-element override is itself conditional on mode/stadium-derived state and hitbox guards. Exact visual asset contents and the broader latch-reset lifecycle are not established here.
