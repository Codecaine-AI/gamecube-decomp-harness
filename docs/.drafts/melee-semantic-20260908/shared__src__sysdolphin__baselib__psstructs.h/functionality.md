# psstructs.h semantic review

This shared header declares particle-system data and interfaces, not executable implementations. Texture/form groups and command-list records describe resource metadata, initial physical parameters, and one-element trailing tables/command storage (code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/psstructs.h#L35-L84). Particle-kind constants are explicit bit expressions; application status names declare ONCE=1 and STILL=2 without defining transitions or whether other values occur (code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/psstructs.h#L16-L33; code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/psstructs.h#L86-L126).

HSD_Particle contains linked-list, command cursor, motion, color/alpha target and counter fields, plus generator/application-SRT references and user callbacks. HSD_psAppSRT declares transforms, a generator reference, usage/status fields, unresolved numeric fields, and a free callback. HSD_PSUserFunc declares create/delete and user-data hooks; declarations do not establish callback return conventions or release ordering (code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/psstructs.h#L91-L196). HSD_Generator contains joint/resource references, physical and lifetime fields, child count, application-SRT/user-function pointers, and a union of disc, line, tornado, rectangle, cone and sphere auxiliary records; no numeric type-to-union mapping is established here (code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/psstructs.h#L198-L277).

The remaining declarations expose fog and display helpers, bank/particle initialization, generation variants, particle/family/child removal, point-joint registration, offsets, family pause/restart and callback configuration. PS_TEXDIRECTION and PS_APPSRT are defined locally; fog prototypes are conditional on _NFUNCPROTO being absent. Static-inline declarations here have no bodies. Null handling, allocation failures, special lifetime values, family selection and cross-file ownership cannot be inferred from these signatures (code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/psstructs.h#L279-L358). Size/offset comments are source annotations, not independently verified compiled layout.

Both rendered pages have zero substitutions and zero reported parse errors. Names remain canonical; the renderer symbol inventory spuriously associates the nested callback name in psSetCallback with a Donkey callback identity. This is not evidence of a relationship or a rename. The actual declaration takes a pointer to a particle callback pointer (code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/psstructs.h#L354-L356). Frozen subject and link enumerations are empty; no baseline facts require disposition and no supported semantic correction warrants a proposal.
