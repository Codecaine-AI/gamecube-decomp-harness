# Naming Review

Retain hsd_803B3344 and hsd_803B3398 as canonical names. No inherited name hypotheses and no proposed names. Their behavior is documented as a byte writer and block writer without renaming source symbols.

| Subject | Canonical Parameter Meaning |
|---|---|
| hsd_803B3344#r3 | byte, u8 emitted at cursor |
| hsd_803B3398#r3 | src, source block read by memcpy |
| hsd_803B3398#r4 | size, byte count tested and copied |

All three parameter subjects lacked facts. extab and extabindex retain their object-section identities. The owned header declares the two exports only. Output globals, recovery context and JPEG types belong to foreign files and receive no new type or name claims.
