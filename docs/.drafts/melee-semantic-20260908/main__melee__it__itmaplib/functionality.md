## Geometry and placement

The unit installs supplied fixed ECB bounds, restores saved bounds, initializes spawn collision state, and prepares release collision histories. Bounds remain unscaled in `Item.xC1C`; ordinary installation supplies scaled extents to CollData. Collision facing becomes −1 only when item facing equals −1.0 exactly. `xC0C` is a mutable saved snapshot, not necessarily immutable canonical geometry. Spawn handling distinguishes history-only initialization, airborne collision reconciliation, and a downward placement query. The downward query changes position only on success and does not independently assign ground state or floor identity.

`it_802759DC` reconciles reference-relative placement using a connected-floor fast path or an ECB-based sweep. Its ReDead caller retains the fighter reference through reconciliation, clears it afterward, and subsequently consumes the resulting ground/air state. Generalizing the fallback to an arbitrary item's world-space center is unsafe: `it_8026BC90` supplies a position only for fighter references. Evidence: [placement and configuration](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itmaplib.c#L33-L294), [reference lookup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L724-L733), [ReDead lifetime](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itleadead.c#L1090-L1145).

## Contact queries and orientation

Ground marking writes only `GA_Ground`; air marking additionally clears `x1F`. Wall queries return 0/8/4, preserve outputs without contact, and give the later right-wall test precedence. Floor returns a Boolean; ceiling returns 0/2. Normal selection and surface caching instead prioritize floor over ceiling over right wall over left wall. These compact directional result bits must not be confused with raw environmental flag masks.

Surface-angle calculation signs the angle from world up using the normal's X component and item facing. Joint alignment overwrites Z/X/Y for `x17` values 0/1/other; the Z path applies an additional negative-facing multiplier. Stored-line alignment uses `xC30`, whereas current-contact alignment uses CollData normals. The floor-only wrapper selects joint zero. Missing contact does not supply a benign default: angle calculations can consume an uninitialized normal, and the cache writer can store an uninitialized index. The rendered `itGetGroundRotation` name is meaningfully narrower than the canonical all-surface implementation; `itGetSurfaceRotation` is proposed. Other supported rendered names are retained without cosmetic rewrites. Evidence: [queries and orientation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itmaplib.c#L296-L604).

## Correction, residual movement, and rebound

Overlap correction distinguishes simultaneous current wall constraints from selected previous-frame contacts. The first path reinstalls adjusted horizontal bounds at scale one; the second applies independent 1.5-unit nudges. False means a correction occurred. The rebound wrapper ignores the geometric rebound Boolean and gates sound, effect, and enabled-hitbox multiplication only on absence of overlap correction. Sound and effect suppression are separate. Neither successful reflection nor numerical attenuation is guaranteed merely because the wrapper runs. Evidence: [correction and wrapper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itmaplib.c#L606-L687), [enabled hitboxes](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/ithitbox.c#L136-L147).

The contact-relative evaluator preserves its near-zero exit, tangent construction, numeric mode-2 exception, and conditional mismatch counter. Matching directions do not unconditionally reset that counter. Activation checks nonzero mode, evaluator success, and velocity-plus-nudge magnitude or mode 2. The evaluator's mode-2 write cannot survive failed activation through this branch: it returns true and forces activation success. Failure can nevertheless leave other evaluator fields changed. An `entered_air` callback name is not proof of a `GA_Air` assignment; the Green Shell callback sets motion 9 and `x1F` without that assignment.

Residual movement adds `x88` before XY scaling and limiting, so it need not decay monotonically. Below threshold, only residual XY and the active flag are cleared; this is not necessarily a complete stop of the item. Surviving motion updates spin and contributes to the caller's displacement. Spin calculation preserves its zero-spin no-op and divides by the bottom ECB extent without a zero-divisor guard. Evidence: [evaluator and residual flow](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itmaplib.c#L698-L932), [grounded integration](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/item.c#L1364-L1397), [shell callback](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itgshell.c#L547-L580).

Wall response selects one wall, uses a three-component dot-product guard for an XY-only mirror, and always scales all velocity components on selected contact. General rebound instead accumulates every qualifying inward XY contact, separately accumulates contacted-surface motion, and commits only on success. Near cancellation invokes the original-horizontal/inverted-vertical fallback before normalization and scaling. Evidence: [response implementations](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itmaplib.c#L934-L1083), [XY mirror](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbvector.c#L257-L264).
