# Adventure Mode controller

`gmadventure.c` defines the Adventure route, encounter descriptors, reusable intro/cutscene payloads, per-encounter result bytes, and entry/exit callbacks. The header declares the callbacks and the two public tables. Route IDs are sparse and organized into blocks of eight; the state table ends with `-1`, while the encounter table ends with `0xFF`. Source declarations do not establish compiled section sizes, ordering, padding, or literal-pool contents. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L17-L635), [header](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.h#L1-L40).

## Shared setup and lifetimes

Normal intros fill player-slot, route-derived and encounter-derived payload fields and assemble an audio mask from the player, nonempty ally/opponent slots, and stage. Opponent Kirby adds `0x200004000`. Common fight entry copies descriptor settings into Adventure state, derives complementary flags from descriptor `x4`, invokes shared match construction, loads rumble settings, and conditionally installs `gm_8017C838` as `on_match_start`. The else path does not itself clear that callback. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L1203-L1273).

`gm_80490910` is indexed by encounter-descriptor position, not directly by sparse state ID. Load initializes its bytes to zero; exits write 1 or 2 according to whether `MatchExitInfo.x8` is false or true; later setup passes the byte to the shared constructor. That constructor maps these values to rules `xA` values 0, 3 and 2 respectively. These observations do not establish a stronger gameplay interpretation of `x8`. [Local flow](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L1184-L1285), [consumer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_17C0.c#L540-L580).

The route shares externally defined Classic match, result, CSS and Game Over buffers. Static cutscene payloads are only partially overwritten by each callback; their lifetime crosses state boundaries. In particular, Luigi's resolved costume is reused by the following battle. Team Kirby preparation similarly crosses intro/fight boundaries through external tables and `x0.xC.x11`; direct fight entry performs preparation when that flag is not 1. [Buffers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L12-L34), [Luigi lifetime](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L1372-L1397), [Team Kirby lifetime](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L1471-L1536).

## Conditional encounters and exceptional branches

- Mushroom Kingdom exit records the result and, after the common processor returns true, selects the Luigi cutscene when `(x4 % 60) % 10 == 2`; otherwise it selects the Mario/Peach fight. The subsequent entry substitutes Luigi only when the previous state was the Luigi cutscene. The battle's qualification flag uses integer `frame_count / 60 <= 60`, not a strict under-one-minute comparison, and has no local Luigi-only guard. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L1351-L1414).
- The small-opponent callback halves `model_scale` only for CPU slots 1–3. Escape entry installs a timeout handler and writes numeric mode `0x20`. The installed handler removes a live stock on timeout; exit separately increments recorded standing stocks on timeout or latches `x76` for non-timeout, then runs common result processing. These are distinct operations. [Local callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L1416-L1469), [installed handler](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_17E4.c#L266-L273).
- Team Kirby exit skips both Giant Kirby states only after successful common processing and integer `frame_count / 60 > 30`. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L1538-L1552).
- Star Fox selection short-circuits the random call unless Falco is unlocked. `HSD_Randi(100) <= 33` gives a nominal 34% branch, not exactly one third. The selected kind persists in `x7C`; the following fight conditionally substitutes Falco and resolves costume conflicts. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L1554-L1584), [RNG](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/random.c#L6-L21).
- State `0x41` forces rules `x20 = 1 << 7` and `xB = 4`; its exact item interpretation remains unresolved. The metal-sequence callback disables only Luigi opponent entries when Luigi is locked. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L1586-L1610).
- Bowser entry sets CPU opponent scale to 1.4 and installs `gm_8017E7FC`. That foreign callback sets `x77` from current mode, difficulty and accumulated frame count, and selects `0x5A` in both branches. Bowser's outro invokes completion only when `x77 == 0`; Giga's defeated outro invokes it unconditionally. Giga fight exit latches `x78` on stock equality before result processing, without clearing it on mismatch or requiring a successful outcome. [Local finale](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L1612-L1662), [route producer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_17E4.c#L280-L302).

## CSS, Game Over and mode initialization

CSS entry restores saved selection through the shared initializer. Exit cancellation (`pending_scene_change == 2`) requests menu and returns before selection writes; continuation commits the selection and chooses `x5 << 3`. Game Over delegates to shared processing: retry restores stocks and requests the saved state, while finalization has an additional `gm_80173754` guard before requesting menu. It must not be reduced to an unconditional menu-or-challenger dichotomy. [Local wrappers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L1287-L1333), [CSS helpers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1B03.c#L138-L178), [Game Over processor](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_17C0.c#L377-L417).

Mode initialization writes six selection defaults. Load passes prior Adventure data to a helper before zeroing it, clears encounter-result bytes, initializes supporting state, installs eleven callbacks, selects `ADVENTURE_BACK_TO_CSS`, and invokes common and Ground/Toy initialization. Completion selector `0x16` reaches Adventure-specific record processing and pending-mode scheduling in the split `gm_17C0.c` implementation. [Lifecycle](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmadventure.c#L1664-L1709), [completion](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_17C0.c#L419-L479), [Ground delegation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/ground.c#L3306-L3311).
