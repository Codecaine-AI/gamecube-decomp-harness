# Forward tilt and item alternatives

CheckInput requires newly pressed A, stickX * facing >= x98, and ABS(atan2f(stickY, ABS(stickX))) < x20_radians. Equality passes the displacement gate but fails the angle gate. With an item, held L/R or category zero enters LightThrowF; category two calls ftCo_Attack_800CCF58 with mode one and category three calls ftCo_Attack_800CDD14. Other accepted paths call decideAngle. There is no local ground-state guard; grounded usage is established by the standing input dispatcher.

## Pickup and angle selection

The helper first calls ftpickupitem_80094790. Success changes motion to LightGet or HeavyGet through its initializer and bypasses tilt entry. Thus true from CheckInput means consumed input, not necessarily a tilt.

Otherwise angle branches are ordered, with strict inequalities. Above x9C and nonzero AttackS3S record x8 selects AttackS3Hi. Above xA0 and nonzero AttackS3LwS x8 selects AttackS3HiS. Below xA8 and nonzero AttackLw3 x8 selects AttackS3Lw. Below xA4 and nonzero AttackHi3 x8 selects AttackS3LwS. Remaining cases select AttackS3S. A failed branch permits later branches; it does not immediately force straight tilt. The tested field is size_t, not a pointer. The record lookup can substitute Popo data for Nana under its internal conditions. Exact record IDs are preserved without inferring a corrected indexing scheme.

Tilt entry clears Fighter.allow_interrupt, changes motion with no flags, frame zero, speed one, blend zero and NULL final object, and calls ftAnim_8006EBA4. That helper invokes animation/action updates; no fixed interrupt frame is inferred.

## Shared lifecycle

All five AttackS3 states install these four callbacks. Anim invokes the common neutral transition on exhausted frames, retaining exceptional boss, DownSpot and Hammer paths. IASA reads Fighter.allow_interrupt and delegates to Wait's ordered checks only when true; the action command ftAction_80071950 sets that field. Phys applies speed-dependent ground friction and movement. Coll delegates to ft_80084104, which enters Fall when its shared collision test returns false. Animation or collision exits are independent of IASA gating.
