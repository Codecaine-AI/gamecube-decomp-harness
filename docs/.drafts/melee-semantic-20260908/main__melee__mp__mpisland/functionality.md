## State, construction, and conventions
The module derives linked descriptors from stage collision lines. Source-level manager roles are: next/x4 primary floor/ceiling heads; x8/xC retained-prefix boundaries; x10/x14 dynamic heads; x18/x1C secondary retained lists; x20 shared reusable-node pool. These roles do not establish physical section placement. mpIsland_8005A6F8 clears all nine pointers without traversal, freeing, or allocation and returns normally. Repeated calls are pointer-state idempotent; calling it on live lists discards manager references. mpIsland_8005A728 obtains MapCollData and runtime CollLine/CollVtx arrays, resets the manager, and clears a shared 0x600-byte visited table. The floor pass follows next_id0 while the successor MapLine hi_flags includes CollLine_Floor; the ceiling pass follows prev_id0 and CollLine_Ceiling. Traversal stops at -1, a classification boundary, or return to the starting index. A return-to-start assigns end_idx back to the starting line before terminating; therefore a closed initial chain need not record geometric extrema or a distinct last line. The visited table suppresses subsequently encountered range entries, not arbitrary malformed adjacency cycles. Negative counts, invalid indices, malformed chains, and adjacency escaping the declared range are not validated locally. ## Refresh, dynamic rebuilding, and lifecycle
mpIsland_8005AE1C consumes two list heads, vertex start/count, and activity. It computes end=start+count and skips a node only when both endpoint IDs are below start or both are at least end. Otherwise both cached endpoints receive current vertex X/Y and zero Z. This is an endpoint-span test, not a validated half-open interval intersection: zero count can select a span crossing start. Negative count and signed addition overflow are unchecked. A selected first-list node migrates to the second output only for false activity with bit 2 clear, setting the bit. A selected second-list node migrates to the first only for true activity with bit 2 set, clearing it. Other nodes remain in their partition, even if bit and nominal partition disagree. Every node is prepended, reversing traversed groups, including unaffected nodes. Nonoverlapping acyclic lists and distinct writable head locations are required. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/mp/mpisland.c#L305-L426.

mpIsland_8005B004 moves selected-joint nodes from its first list into a reusable pool and reverses the remaining list. arg4/arg5 are unused. It scans the joint's dynamic range, accepting only (flags&0x1F)==(arg3|0x10), with a 0x600 visited array. It walks matching prev_id0 and, for open backward chains, next_id0; a forward return to the starting line in that branch asserts. Adjacency is not constrained to the selected joint range, and malformed cycles excluding the starting line can fail to terminate. In the closed-cycle branch max_x starts at F32_MAX and decreases with v0 X, while min_x starts at -F32_MAX and also uses greater-than against v1 X. Finite v1 coordinates therefore leave start_idx at its initial cycle line; this is not a rightmost-extremum algorithm. NaNs do not update comparisons; -infinity can update the latter; equal values preserve the earlier choice. A pooled node is preferred to a new 0x2C allocation. Replacement fields contain boundary IDs, current XY/zero Z, selected joint ID, and status active?0:2. All replacements are prepended to the same dynamic output regardless of status. A successful iteration leaves line_idx unchanged; the next iteration's visited guard advances it. An empty dynamic range still recycles old selected-joint nodes and reverses other nodes. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/mp/mpisland.c#L428-L576.

mpIsland_8005B334 detaches prior dynamic suffixes at retained boundaries, or clears a primary head if no retained prefix exists; refreshes both retained pairs with AE1C; rebuilds selectors 1 and 2 with B004; appends both dynamic lists unconditionally; and records the new retained boundaries. Activity controls retained migrations and dynamic status, not universal membership of the published lists. mplib geometry/visibility and B11 paths often supply Enabled && !(Hidden|B11); individual line enable/disable and joint-add paths instead pass !B11, and joint removal passes false. Consequently activity is a caller-supplied policy, not an invariant identical to every constituent line's availability.
