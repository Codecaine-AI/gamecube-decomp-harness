# TKoopa semantic review

## Registration and lifecycle

This unit supplies the TKoopa Target Test controller, retaining the baseline mapping to Bowser's course. `grTKp_StageData` identifies `Gr_Kind_TKoopa`, `/GrTKp.dat`, the callback table and lifecycle/service hooks. The header exports only that descriptor. The source declares three populated callback records and a final zero record; row 2 sets bits 30 and 31. These are source-level observations, not proof of compiled section membership, adjacency or placement. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grtkoopa.c#L38-L77)

Initialization passes `grTKoopa_802216EC` to `Ground_InitTargetStage`. The inline clears `stage_info.unk8C.b4`, sets `b5`, requests objects 0, 1 and 2 in that order, then calls four common Ground setup routines. It does not inspect the factory results. The factory forms the indexed callback pointer before retrieving the GObj; it has no local index-range guard. A non-null GObj receives callback setup; a null result produces an OSReport diagnostic and is returned. [Factory](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grtkoopa.c#L81-L111) [Shared initialization](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/inlines.h#L51-L62)

The actual callback installer clears two Ground callback fields, registers the display callback, conditionally stores callback3, invokes a non-null initializer and schedules a non-null process at priority 4. It does not consume callback1 or the row flags. Accordingly, predicate table membership must not be mistaken for a demonstrated installed dispatch path. [Installer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/inlines.h#L32-L49)

Demo initialization and load are empty. Start calls `grZakoGenerator_801CAE04(NULL)` and discards its result. The constructor obtains generator data and creates a controller GObj. GObj creation failure reports the error, frees the new data and returns NULL without publishing replacement globals. Success schedules its process and publishes the null descriptor and data globally. This shared state and scheduled controller outlive the local start call; the wrapper supplies no cleanup, retry or repeated-start guard. This is not evidence that NULL directly spawns targets. [Start](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grtkoopa.c#L79-L90) [Constructor](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grzakogenerator.c#L303-L329)

## Ground-object behavior

Object 0 initializes archive-backed model/animation state using its Ground map ID and index 0. The animation helper selects the first child when present, optionally replaces joint data, resets material state, removes old animations, attaches available animation resources, requests frame zero, conditionally applies an animation flag and evaluates the hierarchy. Archive absence asserts. Objects 1 and 2 use `Ground_JObjInline1`, which additionally calls `Ground_801C2ED0` before the same animation setup. All three callback1 bodies return false; object 0's process and all three callback3 bodies are empty. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/grtkoopa.c#L113-L160) [Joint helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/inlines.h#L24-L30) [Animation helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/granime.c#L988-L1048)

Object 1's process calls the common collision refresh. Object 2 first advances the shared lb timed-effect list and then calls that refresh. The list update accumulates pre-decay scale only for entries whose x0 is 1, decays/clamps scale, decrements positive counts, increments angle counters and recycles zero-count nodes. Negative counts are not decremented or expired by this test. For total scale above 0.1, aggregate state becomes 2 if previously positive, otherwise 1; below that threshold it becomes -1 if previously positive, otherwise 0. These numeric states are preserved without inventing gameplay labels. [List update](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lb_00F9.c#L939-L992)

Collision processing requires `Ground_804D6950[map_id] == 0`. It advances a generation counter, processes matching descriptor joints, then optionally processes archive joints whose generation tag differs. Deduplication is in the archive loop, not a universal guard on repeated descriptor entries. TKoopa supplies no descriptor joints, so its archive data determines the applicable joints. Both wrappers ignore the helper's Boolean result. [Collision helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/ground.c#L1676-L1732)

## Services, names and limits

The stage predicate returns false, the touch-line hook returns NULL for every index, and the shadow-render check returns true without inspecting its arguments. Existing lifecycle and numeric object/slot names fit canonical registration and are retained. The renderer reports no parse errors, but shadows the factory binding and the supported touch-line name; its external wind-specific hypothesis is not independent proof of a visible wind mechanic. Visible identities of objects 0–2 remain unspecified. The local demo callback uses bool whereas the descriptor field uses int; the animation helper similarly declares a bool argument while using it as an index and testing it against zero. These source-type ambiguities are preserved rather than normalized.
