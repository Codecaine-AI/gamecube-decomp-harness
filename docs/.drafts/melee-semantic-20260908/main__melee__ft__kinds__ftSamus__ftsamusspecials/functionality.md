## Samus side-special state implementation

This unit implements two entry routines, four animation/IASA/physics/collision callback suites, and an effect-cleanup helper. The header declares all 19 exported functions with `void(HSD_GObj*)` signatures. The ordinary and smash-input families correspond to the baseline Missile and Super Missile interpretation; projectile creation occurs outside this unit.

### Entry and deferred firing

Ground entry divides `gr_vel` by Samus attribute `x2C` and clears `self_vel.y`. Air entry divides only `self_vel.x` by `x2C`; it does not clear vertical velocity. Both compare `fp->x673 < samus_attr->x28`: ground selects `0x15E` versus `0x15D`, and air selects `0x160` versus `0x15F`. Each branch changes motion with flags 0, frame 0, rate 1, blend 0 and NULL, then calls `ftAnim_8006EBA4`. The common local helper clears `throw_flags` and installs `ftSs_SpecialS_8012A074` as `accessory4_cb`. There is no divisor validation; attenuation is an intended tuning interpretation, not a guaranteed result for arbitrary attribute values. [Entry source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSamus/ftsamusspecials.c#L17-L53).

The installed callback lives in `ftsamusspecialn.c`. It waits for `ftCheckThrowB0`, increments `u.ss.x2238`, obtains a spawn position from part 56, applies the facing-scaled `x34` offset, and calls `it_802B62D0`. Ordinary named side-special states select false; all other states select true. It then invokes the firing-effect helper and clears `accessory4_cb`. Thus installation and consumption form a cross-file deferred lifetime, not an immediate spawn in either entry routine. The firing effect uses `x2219_b0` as its guard and installs effect hitlag callbacks. [Accessory implementation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSamus/ftsamusspecialn.c#L421-L454).

### Active-state callbacks

All four IASA bodies are empty; this proves only the absence of interruption work in those callbacks. Ground animation completion calls `ft_8008A2BC`; aerial completion calls `ftCo_Fall_Enter`. No completion call occurs while frames remain. The ground completion helper normally reaches Wait for Samus, but its common path checks DownSpot and hammer conditions first. It must not be summarized as unconditional Wait. [Local callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSamus/ftsamusspecials.c#L55-L128), [common completion](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_08A1.c#L54-L109).

Both grounded physics callbacks delegate to `ft_80084F3C`, which selects common ground friction, multiplies it when absolute ground speed exceeds walking maximum, applies friction and advances ground movement. Both aerial physics callbacks apply common gravity with a terminal-speed clamp, then pass Samus attribute `x30` to aerial friction. That friction helper writes a horizontal correction to `x74_anim_vel.x`, rather than directly rewriting `self_vel.x`. These callbacks contain no local motion-state transition. [Physics callers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSamus/ftsamusspecials.c#L77-L148), [ground delegate](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_084E.c#L42-L53), [air friction](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftcommon.c#L253-L261), [falling](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftcommon.c#L462-L473).

### Collision boundaries and ambiguity

Ordinary ground collision enters Fall when `ft_800827A0` is false. Smash ground collision instead tests `ft_80082708` with the same negated guard. These are distinct helpers, not interchangeable names. Neither callback transfers to the paired aerial Missile state.

Both aerial collision callbacks call `ft_80082B1C` only when `ft_80081D0C` is truthy. The latter synchronizes fighter/collision positions and returns a `GroundOrAir` value, including an exceptional `ft_80081A00` branch. The rendered name `ft_CheckGround` cannot establish the physical meaning of that numeric result. Once invoked, `ft_80082B1C` compares vertical velocity with `ftCo_800D0EC8`: above the threshold it calls common action completion; otherwise it enters basic landing, with hammer landing substituted when applicable. Collision therefore exits through common states rather than preserving the Missile animation across ground/air variants. ### Cleanup and evidence limits

`ftSs_SpecialS_8012A640` unconditionally calls `efLib_DestroyAll(gobj)` and resets `u.ss.x2244`. The effect library clears matching parameter references and synchronously unlinks effects owned by the supplied object. Samus's aggregate cleanup calls this helper between neutral-special and common cleanup. This is not evidence of missile-item destruction, nor does it establish that `x2244` is the firing-effect latch. `ftSs_SpecialS_RemoveGFX` remains a reasonable descriptive name hypothesis, not recovered original spelling.
