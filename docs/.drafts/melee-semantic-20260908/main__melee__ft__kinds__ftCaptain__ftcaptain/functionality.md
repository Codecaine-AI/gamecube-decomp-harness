## Item adapters
Pickup and Drop forward their incoming boolean with true,true; visibility wrappers forward true. Pickup skips heavy items. Non-heavy hold kinds 1,2,3,4 select presentation values 1,0,2,3; other kinds skip selection. Independently, a true incoming boolean invokes ftAnim_80070C48 for non-heavy items, including unrecognized kinds. Drop unconditionally selects -1 and conditionally calls ftAnim_80070CC4, without pickup's heavy guard. Visibility helpers operate only for non-heavy items. These adapters do not themselves implement item ownership transfer. Null-item handling depends on itIsHeavy. Drop's dual-use source remark is confirmed, but both active dispatch placements remain unverified. OnLoadForGanon takes Fighter* directly and performs only PUSH_ATTRS. LoadSpecialAttrs uses COPY_ATTRS to refresh the active destination without pointer rebinding; Ganon shares these loaders, not necessarily attribute values. No allocation, scaling, normalization or floating-point arithmetic is performed here. Valid typed source/destination storage is assumed without null checks, and exceptional float values are not explicitly clamped or validated.
