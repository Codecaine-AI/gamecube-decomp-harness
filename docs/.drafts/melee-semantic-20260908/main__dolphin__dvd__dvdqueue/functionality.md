## DVD waiting-command queues

The module owns four circular doubly linked sentinel lists. Clear self-links their heads without traversing commands, changing command states, delivering callbacks, or masking interrupts. Push appends to the caller-selected lane and returns 1; it performs no priority bounds or membership validation. Pop scans lanes 0–3 and removes the oldest block from the first nonempty lane, giving lower-index priority and FIFO ordering within a lane. Check returns a non-destructive Boolean occupancy result. Targeted dequeue checks only whether both recorded neighbors are non-null, splices those neighbors, and leaves the supplied block's own links intact. Membership testing traverses all four lists without internal interrupt masking. [Queue implementation](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/dvd/dvdqueue.c#L6-L129).

Pop's selection and removal are separate interrupt-masked regions: it restores the entry state before calling the helper, which independently masks interrupts and asserts nonemptiness. The helper restores interrupts before clearing the returned block's links. Thus continuous protection depends on surrounding context; the source does not justify blanket atomicity across selection and removal. Push, check and targeted dequeue restore their saved interrupt state on their normal exits.

Submission sets DVD_STATE_WAITING before enqueue and may immediately invoke stateReady. That scheduler checks occupancy and pause state before popping into executing; fatal-error completion and resume/recovery branches can consume work without ordinary hardware dispatch. Cancellation owns command-state changes and notifications, not the queue primitives. Notably, cancel-all first pops blocks, then calls cancellation: the waiting-state cancellation path ignores dequeue's result, permitting already-detached blocks to receive cancellation callbacks. [Submission](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/dvd/dvd.c#L871-L899), [scheduler](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/dvd/dvd.c#L570-L631), [cancellation](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/dvd/dvd.c#L1518-L1678).

Clear is used at initialization, reset preparation, and only selected cover-close command cases. It abandons queued reachability without repairing abandoned nodes. Reset preparation treats already-in-progress cancellation separately. [Cover-close branches](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/dvd/dvd.c#L507-L528), [reset preparation](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/dvd/dvd.c#L1765-L1779).

DVDDumpWaitingQueue reports every lane and uses a 16-entry command-name table without checking the command index. Command value 1 receives additional offset, length and address output. Dump traversal has no internal interrupt masking. [Diagnostics](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/dvd/dvdqueue.c#L131-L175).
