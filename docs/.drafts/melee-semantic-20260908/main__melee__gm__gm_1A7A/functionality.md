## Animation and lifetime
`fn_801A7A44` and `fn_801A7A68` each unconditionally forward the attached JObj root to `HSD_JObjAnimAll`. The callee accepts a null root, animates the current node before eligible descendants, suppresses child recursion for instance nodes, and invokes accumulated animation-end callbacks after traversal. These wrappers contain no local completion state. [Wrappers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A7A.c#L22-L30) · [Traversal](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/jobj.c#L531-L565)

`fn_801A7A8C` first animates its camera, then compares `curr_frame == end_frame`; this is exact equality, not a greater-than-or-equal threshold. Unequal frames cause no additional local work. Equality submits the two stored model objects for destruction, clears all GObjs on process link 3 through `mn_8022F0F0(3)`, constructs the successor scene, and finally submits its own camera GObj for destruction. **The constant 3 is not a display-mode selection.** The light created on process link 3 is covered by that list cleanup, which is broader than a single-light removal. The destructor has a current-object deferral branch, so self-destruction must not be described as necessarily immediate freeing.
