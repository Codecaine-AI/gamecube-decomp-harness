Fire Flower implements eight item states, with state indices distinct from animation selectors. Spawn initializes finite resource xD4C, ignore ID, cadence and effect latch, then enters state 1; the explicit spawn wrapper enters resting state 0 only on successful creation. Held states 2–5 share animation and inert physics, with no collision callbacks. B3 moves 2/5 to 3; B4 moves 3/4 to 5. Animation completion maps 2/5 to 2 and 3/4 to 4. States 1 and 6 share animation completion to state 1; drop and throw select 6. EnteredAir selects distinct state 7, with inert physics and guarded terrain routing to 0 or 1. Firing requires xD4C > 0, starts effect 0x473 on bone 4 when the latch is clear, consumes one unit, attempts beam creation, and rotates the ignore ID after every six eligible calls even if allocation fails. Cleanup destroys effects in all listed states except state 4 with positive resource. Collision tests xD4C != 0, not > 0. Contact adapters distinguish victim bounce, reflection and shield bounce; EvtUnk clears matching object references through the common helper.
