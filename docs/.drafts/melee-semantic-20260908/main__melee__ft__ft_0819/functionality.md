## Boundaries and exceptional floats
lb_80014638 copies x0, xC, and the item's x8 geometry; translates only x0 by the item's unk_x on both horizontal boundaries and unk_y on height; rejects increasing adjusted height and failure to straddle target height; then interpolates horizontal boundaries at target height. Equal height and horizontal edge contact are admitted. If abs(xC.height-adjusted x0.height) < 0.01f, the interpolation parameter is 1; exactly the represented threshold follows the division branch. Otherwise it uses (targetHeight-adjustedStartHeight)/(currentHeight-adjustedStartHeight). Consequently descending describes adjusted relative geometry, and stationary contact is possible. There is no finite-value or interval-order validation. Under ordinary floating comparison semantics, NaNs can bypass rejection comparisons and infinities can generate NaNs during subtraction/interpolation. The direction comparison selects +1 for equal positions, signed-zero equality, and unordered comparisons. Target-machine exceptional-float execution remains untested.
