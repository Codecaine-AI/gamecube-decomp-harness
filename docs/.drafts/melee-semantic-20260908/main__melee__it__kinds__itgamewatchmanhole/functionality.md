## Game & Watch manhole article

This unit implements the fighter-attached manhole used by Mr. Game & Watch's down tilt. Its constructor creates `It_Kind_GameWatch_Manhole`, attaches a successful result using its special attributes and the requested fighter part, and returns NULL without attachment on failure. The fighter caller supplies its left-hand joint position, left-hand part and facing direction, and tracks the returned object. Setup can hide and save an existing held item before attempting creation; the success guard controls damage/death callback installation, while pre/post-hitlag callbacks are assigned independently. ### State and presentation

The source declares one state-table entry: state index 0 selects animation ID 0, the manhole animation callback, and null physics/collision callbacks. These are separate numeric roles despite sharing zero. Pickup resets `xDAC_itcmd_var0` and hides the model unconditionally; only an owned article enters state 0 and calls the separate animation/script advancement helper. [Table](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itgamewatchmanhole.c#L15-L16), [pickup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itgamewatchmanhole.c#L66-L76).

The animation callback consumes any nonzero command before making helper calls. It reveals the model, obtains the child-joint position and requests a point-centered dynamics effect with arguments `120, 3.0f, 0.1f, 1.0471976f`. Importantly, 120 is a countdown parameter, not an effect ID: the library stores it in `unk_count0`, decrements positive counts and retires the descriptor at zero. The float arguments supply initial scale, per-update scale reduction and oscillation-angle increment. The library copies the position into its own descriptor; the effect is not tied to the lifetime of the callback's stack vector or automatically removed with the article. Allocation can fail, and this void request does not report success to the article. ### Lifetime and integration

Event processing precedes the article's lifetime check, even on a terminal update. Missing ownership is terminal; a present owner retains the article only in `ftGw_MS_AttackLw3`. The animation callback invokes the owner-notification callback and returns true, which the common item update converts into destruction. The notification itself does not directly destroy the article. Explicit removal instead guards resolved Item userdata, optionally notifies the owner, and then calls common teardown even for an ownerless live article. This userdata guard should not be interpreted as a general null-GObj guarantee. [Article lifetime/removal](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itgamewatchmanhole.c#L36-L106), [fighter predicate](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftGameWatch/ftgamewatchattacklw3.c#L128-L135), [common callback handling](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/item.c#L1280-L1290).

Fighter cleanup exits article hitlag before clearing the tracked pointer, then restores a saved held item if present. Damage cleanup calls explicit article removal and subsequently calls fighter cleanup again; this ordering must not be collapsed into a single assumed notification. Enter-hitlag sets item flag x3. Exit-hitlag conditionally sets x5 when x7 is active and clears x3.
