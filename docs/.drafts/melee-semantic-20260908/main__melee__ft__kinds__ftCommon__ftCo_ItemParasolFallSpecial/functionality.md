## ItemParasolFallSpecial

This unit supplies one motion-entry routine and four `void(Fighter_GObj*)` callbacks; the header declares all five. Complete canonical/rendered coverage is inherited from research. The lead independently inspected the proposed correction and all upstream non-retain evidence. Rendered substitutions remain hypotheses, not independent evidence.

### Entry and cross-file lifetime
`ftCo_800CF3C8` unconditionally calls `Fighter_ChangeMotionState` with the selected motion, `Ft_MF_SkipHit | Ft_MF_SkipParasol`, and arguments `0.0f, 1.0f, 0.0f, NULL`. The inferred name `ftCo_ItemParasolFallSpecial_Enter` fits this role but is not a recovered original name. [Entry](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_ItemParasolFallSpecial.c#L17-L28)

The opening routines save the previous motion in `mv.co.parasol_open.prev_msid` before changing state. Upon opening-animation completion, that saved value selects this entry only for `ftCo_MS_FallSpecial`; other predecessors select ordinary Parasol fall. This is opened descent following opening, not the retracted-Parasol phase. [Predecessor lifetime](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_ItemParasolOpen.c#L48-L85)

Motion selection has an important exception: Peach with non-null `u.pe.parasol_gobj_0` receives `ftPe_MS_ItemParasolFall`; otherwise the common `ftCo_MS_ItemParasolFallSpecial` is selected. It is not an unconditional transition to the common numeric state. [Selector](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/inlines.h#L55-L64)

### Callback behavior
- **Anim:** empty; performs no animation-completion test or transition.
- **IASA:** compares `input.lstick[0].y <= close_parasol_threshold`, then short-circuits through `ft_80087988`. When both conditions pass it calls `ftCo_800968C8`; otherwise it calls `ftCo_800CB870` through `RETURN_IF`. The jump fallback is not attempted after the first branch is selected. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_ItemParasolFallSpecial.c#L30-L42)
- The predicate accepts Parasol status **4 or 5**. Those numeric values are established, but their individual lifecycle meanings are not; the rendered `ftIsParasolOpen` name should not erase that uncertainty. [Predicate](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0877.c#L86-L93)
- The FallSpecial helper passes landing lag from `fp->x2EC` and normally initializes FallSpecial state fields. However, `x2224_b2` diverts to `ftCo_80090780` before that transition. Therefore the local call requests a FallSpecial path rather than guaranteeing its destination. [Downstream entry](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_FallSpecial.c#L22-L59)
- The aerial-jump helper can reject through `ftCo_800C5240`, dispatch multijump handling, or check ordinary aerial-jump input. Calling it does not guarantee a jump. [Jump delegation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_JumpAerial.c#L60-L123)
- **Phys:** delegates unchanged to `ftCo_ItemParasol_Phys`, which calls `ftCo_ItemParasolOpen_Phys`. Shared movement scales gravity and terminal velocity by common-data `x590`, and uses `x58C` for horizontal drift with an `x258` stick dead zone. No independent physics algorithm is defined here. [Wrapper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_ItemParasolFallSpecial.c#L44-L47), [inline delegation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/inlines.h#L66-L69), [shared physics](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_ItemParasolOpen.c#L99-L123)
- **Coll:** unconditionally passes the fighter and `ftCo_LandingFallSpecial_Enter_Basic` to `ft_8008370C`. The supplied callback chooses HammerLanding when its predicate passes; otherwise it requests LandingFallSpecial with interrupt permission false, no motion flags, frame zero, and rate one. The wrapper itself does not unconditionally land the fighter on every invocation. [Collision](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_ItemParasolFallSpecial.c#L49-L52), [landing exception](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Landing.c#L93-L101)
