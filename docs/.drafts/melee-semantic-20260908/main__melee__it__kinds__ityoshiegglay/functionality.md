## Egg Lay item lifecycle

This unit implements the temporary Egg Lay item used by native Yoshi and copied Kirby. Their callers supply different item kinds through the same constructor ([Yoshi](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftYoshi/ftyoshispecialn.c#L363-L391), [Kirby](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirbyspecialyoshi.c#L506-L558)). The constructor ignores its first GObj parameter, supplies zero parent pointers, flattens spawn-position Z, and copies velocity and facing from attributes. Only successful creation installs the private coefficient, auxiliary value, lifetime and initial state; failure is not returned to the caller ([constructor](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshiegglay.c#L26-L61)).

The three-entry table uses animation index -1 throughout. State 1 is the airborne phase, state 0 the supported phase, and state 2 the hidden terminal phase. These numeric IDs are explicit; their semantic labels are interpretations, not recovered original names. State 1 forwards configured fall acceleration and speed threshold to the shared physics helper. That helper gates acceleration by velocity sign and magnitude rather than clamping an overshoot exactly to the threshold. Landing invokes the velocity-resetting state-0 entry only after the shared collision helper's additional predicates pass. State 0 has an empty physics callback; floor loss invokes state-1 entry without locally resetting the lifetime. The supported-floor helper also contains a separate conditional Item_8026ADC0 branch ([local callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshiegglay.c#L18-L141), [fall helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L176-L204), [floor support](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itgroundcoll.c#L44-L70), [landing guards](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itgroundcoll.c#L428-L479)).

Both visible animation callbacks subtract 1.0 from the lifetime. At a nonpositive result they request sound 280088 and asynchronous effect 1231 with scale 1.0, then enter state 2 while still returning false. The address of xBC0 is an effect queue-head argument, not a position. Terminal entry resets velocity, hides the model hierarchy, replaces the timer with 40.0, calls a helper whose exact write is xD0C=2, and selects state 2. Its sole callback decrements the replacement timer and returns true at zero or below. This hidden cleanup interval is distinct from the attribute-supplied visible lifetime ([expiration paths](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshiegglay.c#L63-L167), [effect interface](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ef/efasync.h#L14-L20), [helper write](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/ithitbox.c#L149-L152)).

Damage handling subtracts xCA0 multiplied by the constructor-supplied coefficient from the current timer. It has no clamp, state guard or immediate transition and always returns false. Normal positive inputs shorten the timer; arbitrary input signs are not validated here. The exact documented damage-to-escape rate and synchronization with fighter-side release are not established by this item body ([damage callback](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshiegglay.c#L169-L176)).

The event callback forwards both objects to common reference cleanup. Matching owner, reflector, absorber, fighter and toucher references are cleared; clearing xCEC_fighterGObj also resets source player to 6. The global dispatcher separately checks a cached pre-callback owner and x13 before its destruction call, so reference detachment does not guarantee continued item lifetime ([wrapper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ityoshiegglay.c#L178-L181), [cross-file handling](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L474-L525)).
