### Allocation and lifecycle

`OSInitAlloc` places a descriptor array in the supplied arena, initializes descriptors with size -1 and empty lists, resets `__OSCurrHeap`, and returns the aligned usable lower boundary. `OSCreateHeap` rounds a range inward, selects the first inactive descriptor, and installs one free cell; descriptor exhaustion returns -1. Negative descriptor sizes denote inactive slots, while zero remains an active size under the tests used throughout this module. The fixed 24U initialization capacity check must not be mistaken for proof of the compiled descriptor size. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSAlloc.c#L355-L431)

`OSAllocFromHeap` adds a 32-byte header, rounds to 32-byte alignment, and takes the first fitting free cell. It consumes the whole cell if the remainder is below 64 bytes; otherwise it replaces the free-list cell with its tail. Successful allocations enter the allocated-list head; exhaustion returns NULL. The debug warning prints the rounded internal size. Arithmetic and signed comparisons are not an overflow-safe allocation contract. `OSFreeToHeap` recovers the header, removes the allocation, and reinserts it using address-ordered coalescing. It has no explicit heap-index bounds assertion and no NULL no-op branch. [Allocation](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSAlloc.c#L148-L212), [free](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSAlloc.c#L322-L342), [coalescing](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSAlloc.c#L81-L116).

`OSDestroyHeap` retires the descriptor without individually freeing allocations or clearing its list heads. Diagnostic size comparison is under `#if DEBUG`; accounting and current-selection reset are under `ENABLE_HEAPDESC`. Without that instrumentation, destroying the selected heap can leave a stale current index. `OSSetCurrentHeap` returns the preceding value using separate read and write operations, not a synchronized atomic exchange. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSAlloc.c#L433-L457), [setter](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSAlloc.c#L344-L353).

### Additional paths and exceptional behavior

`OSAllocFixed` rounds requested bounds outward, checks allocated lists, then removes, trims, or splits overlapping free cells across active heaps while reducing descriptor sizes. It can expand the returned bounds to absorb small fragments and writes those bounds back through the supplied addresses. It does not add a normal allocated-list cell. Its `DLOverlap` helper tests whether a cell start or end falls within the requested interval; it does not detect every containment case, notably an interval strictly inside a cell. Thus the overlap checks should not be described as a complete arbitrary-interval disjointness proof. `OSAddToHeap` rounds inward and inserts a new range using the same coalescing helper. [Predicate](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSAlloc.c#L118-L131), [fixed reservation](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSAlloc.c#L214-L320), [extension](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSAlloc.c#L459-L493).

`OSCheckHeap` checks list linkage, cell-start range, alignment, minimum sizes, free-list separation, and total accounting, with additional instrumented ownership checks. Success returns the sum of free-cell sizes minus one header per free cell; a failed check reports and returns -1. This is not a largest-contiguous-allocation query or exhaustive corruption detector. `OSReferentSize` returns block capacity excluding the header, rather than the original requested count. `OSDumpHeap` reports inactive descriptors or list contents. `OSVisitAllocated` supplies a payload pointer but the full cell size, including header, to its callback. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSAlloc.c#L495-L606)

### Cross-file lifetimes and rendering

HSD allocation/free wrappers forward `HSD_GetHeap()` and the caller's pointer or size. HSD startup consumes the post-metadata cursor before creating heaps; main-heap replacement forgets subsystem state before destroying and recreating the heap. HSD object allocation consumes `OSCheckHeap` through a `u32` local, so its -1 failure result is not explicitly handled as an error there.
