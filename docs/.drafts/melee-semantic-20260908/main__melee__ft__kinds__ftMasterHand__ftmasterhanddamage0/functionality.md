## Master Hand damage/defeat sequence

This unit implements a waist-position query and the entry/update portion of Master Hand's timed Damage reaction. The header declares all four exported functions. The common fighter dispatcher reaches the initializer through a remaining-HP-equals-zero check with additional fighter flags and damage-field guards; HP depletion alone is not the complete caller condition (code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0C8C.c#L25-L115).

### Position query
`ftMh_MS_343_80151428` looks up `FTKIND_MASTERH`, obtains the waist joint's position through `lb_8000B1CC`, writes the caller's vector and returns true. An absent fighter returns false without writing the vector. Valid output storage and a valid waist joint are assumed. `ftMh_GetWaistPosition` remains an inferred name. The Crazy Hand counterpart supports camera suitability by source-level analogy, not proof of opcode identity or a direct Master Hand camera registration (code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftMasterHand/ftmasterhanddamage0.c#L18-L27; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lb_00B0.c#L105-L140; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCrazyHand/ftcrazyhandgrabunk1b174.c#L61-L171).

### Entry and resource lifetimes
`ftMh_MS_343_80151484` clears command variable 0 and velocity, requests cleanup for four retained laser pointers, then clears those pointers. It keys off three retained audio handles without clearing their slots. If `unk0.x20` is nonzero, it passes `victim_gobj` to the capture-exit helper without a local victim-null check. It loads vertical/depth velocity from attributes `x14C`/`x154` and duration from `x15C`, enters `ftMh_MS_Damage`, initializes animation processing, starts sounds 320023 and 320024 with arguments 127 and 64, then zeros counters `x74` and `x78`. Counter reset therefore follows the state change and opening sounds, rather than preceding them (code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftMasterHand/ftmasterhanddamage0.c#L29-L67).

Laser cleanup is deferred: `it_802F046C` tolerates null and otherwise sets an item flag. Its animation consumer can reinitialize the item, clearing that flag, before checking it when the animation-completion branch is taken; immediate destruction is not established. The capture helper restores visibility, reverses facing and enters CaptureCut. The audio helper calls `AXDriverKeyOff` (code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itmasterhandlaser.c#L87-L115; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftMasterHand/ftmasterhandthrownmasterhand.c#L13-L19; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbaudio_ax.c#L201-L205).

### Animation callbacks
Both callbacks consume each nonzero command variable 0 once. They increment `x74`, emitting 530002 while it is within attribute limit `x144`; only after exceeding that limit do they increment `x78` and emit 530003 while within `x148`. Once both limits are exceeded, events are still consumed but neither sound is emitted. Independently, positive duration plus exhausted animation requests Damage2. Each invocation then unconditionally predecrements duration and calls `ftCo_800D4F24(gobj, 0)` only if the result equals zero. A duration initially zero does not take that terminal branch on the current invocation. Animation restart and terminal handoff can both occur on an invocation beginning with duration one (code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftMasterHand/ftmasterhanddamage0.c#L69-L111).

The canonical motion table independently binds `ftMh_Damage_Anim` to Damage and `ftMh_MS_345_Anim` to Damage2. Its entries identify Entry as 343, Damage as 344 and Damage2 as 345; the initializer's historical `MS_343` spelling must not be interpreted as its destination state. This supports the inferred `ftMh_Damage2_Anim` name without circular reliance on the rendered view (code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftMasterHand/ftmasterhand.c#L68-L100).
