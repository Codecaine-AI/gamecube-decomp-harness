## State progression

The unit implements paired grounded/aerial Start, Hold, Turn, Hit and End callbacks. Fresh Start initializes releaseLag from the configured release-lag attribute, clears isRelease and x10, and initializes gravityDelay. Aerial entry additionally zeros vertical self-velocity and divides horizontal self-velocity by the momentum-preservation attribute. Start animation callbacks latch absence of B without immediately ending. At animation completion they conditionally spawn effect 1264, install effect-hitlag callbacks, clear x10, and enter Hold according to the fighter's current ground_or_air—not merely the callback's name. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftNess/ftnessspeciallw.c#L37-L146)

Hold decrements releaseLag only while positive. A latched release and nonpositive lag select the corresponding End state. Reholding B does not clear an existing request. The same invocation still decrements x10 after the transition check; an expired x10 requests sound 210081 with volume 127 and pan 64 and resets the counter to 40. This cadence is conditional on continued callbacks and no external reset, not an unconditional wall-clock guarantee. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftNess/ftnessspeciallw.c#L237-L306)

Turn updates release timing, decrements turnFrames, and uses cmd_vars[0] plus the configured threshold to guard a one-time facing reversal. It updates part-0 Y rotation every invocation. Although the canonical accessor is named ftPartGetRotZ, its implementation reads Y rotation; a quaternion primary joint selects a fallback joint, and a quaternion fallback asserts. Turn completion is turnFrames <= 0, and the shared selector can choose either grounded or aerial Hold/End. Initialization of the turn timer and command latch is not established by this owned unit. [Turn](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftNess/ftnessspeciallw.c#L448-L523) [Accessor](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftparts.c#L1051-L1062)

Hit animation callbacks wait for animation completion before resolving Hold versus End. Only the Hold continuation clears existing effects and restores the persistent magnet effect and hitlag callbacks; sound-timer processing still occurs independently. The shared selector returns false after End entry and true after Hold entry plus absorber recreation. All ten IASA callbacks are no-ops; this establishes no IASA processing in these functions, not universal immunity to interruptions elsewhere. ## Absorption and lifetimes

The OnAbsorb hook truncates absorbed damage times the healing multiplier to an integer-valued heal amount, subtracts it from damage percentage, and floors negative resulting percentage at zero while adjusting reported healing to the usable amount. It updates player percentage and healing accounting, then adopts the absorbed-hit direction. Healing and facing happen even when the reaction restart is suppressed. A new Hit transition is skipped when already in either Hit state at or before the configured frame threshold; otherwise the hook selects Hit by current situation, uses flags value 2, and recreates the absorber. The exact negated comparison is preserved rather than simplified in a way that would discard exceptional floating-point behavior. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftNess/ftnessspeciallw.c#L894-L939)

The neighboring Ness initialization unit forwards OnAbsorb to this hook and supplies x94_PSI_MAGNET_HEAL_MUL. Absorber creation sets active flags and copies bone, size and offset; it does not install an absorption callback. ftColl_8007AF10 merely clears absorb_hit.skip_update_pos, enabling later position updating rather than performing map collision itself. Sound playback stores a handle in x214C; stopping and cleanup occur in shared sound code outside this unit. ## Physics, terrain and ending

Ground physics delegates to shared friction and movement processing, including friction scaling when absolute ground speed exceeds maximum walking speed. Every aerial phase decrements gravityDelay when nonzero and applies configured falling only when the incoming value is exactly zero. The delay is inherited across phases: these physics callbacks do not re-arm it. Negative timer values are not treated as expired. Hold, Turn and Hit additionally enable absorber-position updating; Start and End do not. [Ground helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_084E.c#L42-L53)

Terrain converters select the corresponding phase in the other environment. Hold and Hit converters explicitly recreate absorption collision; Start and Turn converters do not. Air-to-ground converters additionally clamp air drift. End converters use END flags, which omit KeepGfx compared with COLL flags. End entry uses zero flags. Both End animation callbacks wait for completion, clear the effect latch and destroy effects, then invoke a common exit that selects Fall for GA_Air and a grounded routine otherwise.
