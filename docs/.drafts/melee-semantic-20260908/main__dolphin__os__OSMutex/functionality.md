## OSMutex semantic review

The unit implements Dolphin OS recursive mutexes and condition variables. First acquisition records the owner and appends the mutex to the thread's owned-mutex list; recursive acquisition increments the count. Contention records the awaited mutex, promotes the owner, asserts against a cycle back to the current thread, sleeps, clears the wait pointer after waking, and retries. Try-lock returns zero rather than sleeping when another thread owns the mutex. Final unlock removes ownership, conditionally recomputes effective priority, and wakes waiters. These transitions are implemented in [OSMutex.c lines 51–141](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSMutex.c#L51-L141).

Condition waiting saves recursive depth, fully releases ownership, brackets the mutex-waiter wakeup with scheduler disable/enable, sleeps on the condition queue, reacquires the mutex, and restores depth. Unlock and condition-wait mutations remain guarded by owner equality in addition to their assertions. Condition signaling calls the queue-wide wakeup helper; it is not a single-waiter selection operation ([lines 143–175](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSMutex.c#L143-L175)).

`__OSUnlockAllMutex` removes each owned-list head before asserting ownership, then clears owner/count and wakes its waiters. It does not itself disable interrupts or recompute the releasing thread's priority. Exit and eligible cancellation paths call it after changing execution state, under interrupt protection; cancellation's default state branch returns without cleanup. Wakeup changes every queued waiter to numeric state 1, but only unsuspended waiters enter the runnable set ([cleanup](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSMutex.c#L107-L118), [callers](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSThread.c#L452-L522), [wakeup](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/os/OSThread.c#L644-L662)). The proposed correction preserves the pre-assertion list mutation.

The read-only diagnostics check waiter endpoint/reciprocal links, numeric state 4, nondecreasing priorities starting from zero, and owner/count consistency. The aggregate validator checks owner equality and delegates each recorded mutex to the individual validator; an empty list succeeds. These are the implemented checks, not proof of every possible queue invariant: there is no comprehensive endpoint-reachability or owned-list cycle validation. The deadlock predicate detects return to the supplied thread, not arbitrary cycles elsewhere; an unrelated reachable owner cycle has no termination guard. `IsMember` separately performs a forward pointer-equality search.
