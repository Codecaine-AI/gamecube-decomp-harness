### Actor lifecycle

The actor progresses through state-table indices **2 → 0 → 1**. Entry 2 has animation identifier **-1**, not state index -1. Spawn initializes the tracked object, randomized relative offsets, approach delay, shot budget, interval, and movement-control fields. Startup animation delegates shared scale processing. Startup physics invokes a mutable shared update before conditionally entering approach state 0: even its false path calls the physics helper and decrements the startup countdown. See [actor implementation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithitodeman.c#L17-L349) and [shared startup update](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_279C.c#L1106-L1130).

Approach physics derives a target-relative destination and updates persistent X/Y steering components. Its scalar helper has strict far-gap and near-gap tests followed by a symmetric clamp; the near-gap step can overshoot, and zero difference selects subtraction when that branch applies. The approach delay adds a converted random integer to a floating base, so it need not be integer-valued. On delay expiration the actor selects facing, enters firing state 1, and zeros velocity.

Firing consumes its interval and shot budget even when the stored target is absent. Missing target suppresses recoil and the creation attempt but does not independently terminate the state. Failed allocation produces no star and skips firing audio, but does not undo the caller's count, interval, recoil, or enable writes. Attack physics applies facing-relative acceleration without a local zero clamp. See [firing and projectile construction](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithitodeman.c#L255-L382).

### Projectile and reference lifetimes

Each star has a separate state-0 table. Spawn initializes lifetime from attribute x0, clears command variable 2, enters the projectile state, starts effect 0x46C, and sets model yaw. Its animation callback decrements and stores lifetime before testing expiration and then command variable 2. Physics is empty and stage collision returns false; combat callbacks separately handle damage dealt, reflection, absorption, shield bounce, and shield contact. See [projectile callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithitodeman.c#L384-L465) and [lifetime initializer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L1414-L1421).

The spawn descriptor's offset `prev_pos` and ECB-centered `pos` are distinct outputs; the latter is independently computed from the actor and its ECB. Actor reference invalidation unconditionally clears the custom target and raises deferred termination, whereas star reference cleanup delegates matching generic relationship removal and discards its Boolean result. The cross-file cleanup assessment is retained from the handoff. See [local reference callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithitodeman.c#L84-L90), [star reference callback](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithitodeman.c#L425-L428), and [ECB position calculation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L660-L674).
