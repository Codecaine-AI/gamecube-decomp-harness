# SquatWait translation unit

## Scope and identity
The owned files implement sustained crouch entry and its animation, interrupt, physics, and collision callbacks. The header exposes six functions; the input-only entry helper `fn_800D62C4` has internal linkage through its preceding static declaration. `ftCo_800D638C` remains the canonical public symbol; `ftCo_SquatWait_Enter` is a descriptive hypothesis, not a recovered original name. The active motion-state table associates the four callbacks with the SquatWait motion and common camera callback. ## Input and entry variants
`ftCo_SquatWait_CheckInput` obtains the Fighter and tests `fp->input.lstick[0].y < -p_ftCommonData->x90`. Success calls `fn_800D62C4` before returning true; failure returns false without an entry call. This is a level test, not an edge detector or duration test. Equality fails. Under ordinary IEEE comparison semantics, a NaN in either operand fails; signed zero compares equal to zero and infinities follow strict ordering. There is no local clamping, finite-value validation, ground-state guard, or null-object guard. Downward-input terminology assumes normally configured positive x90; no local sign constraint enforces that assumption. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_SquatWait.c#L38-L48.

Both entry wrappers call the shared inline, selecting `ftCo_MS_SquatWait` with animation start 0.0F, speed 1.0F, blend 0.0F, and NULL as the final Fighter_GObj argument. `fn_800D62C4` supplies `Ft_MF_None,true`; `ftCo_800D638C` supplies `Ft_MF_SkipNametagVis,false`. Thus input entry writes x5F0 to x209A after the ordinary transition, whereas public entry avoids that clear and omits that write. The broader gameplay interpretation remains unresolved. ## Animation
`ftCo_SquatWait_Anim` forwards gobj and `fp->ft_data->x28` to `ftCo_8008A7A8`, whose second parameter is WaitStruct*. While frames remain, the helper does nothing. On completion, a NULL table or a held item on a fighter other than Mewtwo/Fox selects current-animation restart. Otherwise weighted selection draws an integer in 1..100 and accumulates weights until a bucket covers it, asserting on sentinel exhaustion. Immediate repeats are retried except for current animation IDs 2 or 31; these numbers receive no gameplay names. A table selecting only a forbidden immediate repeat can retry forever. Non--1 selected IDs install metadata, blend and command-script state, loop count and timer; the animation-start call requires x590. ID -1 is a no-op in the setter. No local table-length or animation-index bounds checks establish runtime safety or variant distribution. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_SquatWait.c#L88-L92; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftwaitanim.c#L19-L105.

## Interrupt priority and naming trap
IASA passes the same object to fifteen predicates, each wrapped in RETURN_IF: `ftCo_800D68C0`, `ftCo_Attack100_CheckInput`, AttackS4, AttackHi4, AttackLw4, AttackS3, AttackHi3, AttackLw3, Attack1, `ftCo_80091A4C`, `ftCo_800DE9D8`, Jump, `ftCo_80099F9C`, Dash, SquatRv. Named actions use their CheckInput functions. Each condition is evaluated once; the first true result returns immediately. If none succeeds, this callback adds no transition. ## Physics and collision
Physics calls `ft_80084F3C`, then `ftColl_8007AEE0`, unconditionally. The former starts with ground_friction, scales it by friction_when_above_walk_speed only when ABS(gr_vel) strictly exceeds walk_max_vel, and applies ground friction and movement. Equality uses unscaled friction. Under ordinary float comparisons, NaN velocity or speed threshold makes that greater-than test false. Friction sign and finiteness are not validated; deceleration is a normal-data interpretation, not an unconditional mathematical guarantee. The second helper clears `shield_hit.skip_update_pos`; it does not itself activate a shield. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_SquatWait.c#L113-L117; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_084E.c#L42-L53; code://c302741689bd67c361cd7faadb221df3193992c3/src/Runtime/platform.h#L198-L198; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftcoll.c#L3077-L3080.

Its query copies CollData cur_pos to last_pos, seeds cur_pos from Fighter, calls `mpColl_8004B108`, writes the resulting position back, and maps true to GA_Air and false to GA_Ground. The consumer enters Fall on GA_Ground. This literal relationship does not resolve physical map-result polarity from enum or local-variable names. ## Ownership, lifetime and evidence limits
All seven subject-function parameters are source-level Fighter_GObj* arguments. Owned code borrows and forwards the object, allocates/frees no object, stores no local callback and returns no owned resource. Dereferencing paths require valid Fighter, fighter data, common data and metadata. The shared entry retains its Fighter pointer across motion-state change; continued validity is an engine precondition, not locally checked. Callback addresses reside in the common motion-state table; scheduling and replacement are delegated. No asynchronous lifetime or ABI-placement guarantee follows from r3 locators. Source literals do not establish compiled .sdata2 size, ordering, read-only placement or relocation relationships; all four section facts remain unresolved because no compiled artifacts were assigned. Header conventions do not prove binary layout.
