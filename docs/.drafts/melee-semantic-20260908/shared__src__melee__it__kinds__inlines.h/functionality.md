## Shared item inline helpers

This header supplies spawn initialization, attachment/state wrappers, chain traversal, ray motion and visual updates, and bone-derived velocity helpers. No owned subjects, baseline facts, or baseline links were returned; no knowledge changes are proposed.

### Canonical behavior
- **Chain retraction:** traverses `prev` links past unmarked entries, then clears traversed flags while the target distance exceeds the measured distance. It returns the current/next links and distance minus target, capped only from above by `max_dist`; negative residuals are possible. It neither frees links nor directly moves their positions. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/inlines.h#L21-L58)
- **Spawn setup:** initializes selected fields rather than clearing the entire spawn structure. Ordinary initialization copies both positions; ray initialization separates common fields from position setup, with only the supplied previous position explicitly flattened. Plane variants flatten both positions and differ only in `x44_flag.b0`. Both parent fields receive the supplied parent; this does not establish ownership or lifetime management. [Ordinary spawn](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/inlines.h#L60-L72), [ray spawn](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/inlines.h#L205-L223), [plane variants](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/inlines.h#L253-L282)
- **Attachment and state wrappers:** attachment invokes two external helpers and returns the original item object; the Game & Watch wrapper additionally passes `attributes[0]` to another helper. State wrappers call `it_802762BC`, invoke `Item_80268E5C` with `ITEM_ANIM_UPDATE`, and install effect pause/resume callbacks. The specialized variant uses numeric state 0 and calls `it_80273670(gobj, 0, 0.0F)`; no universal gameplay meaning for state 0 is established here. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/inlines.h#L74-L108)
- **Rotation and angle helpers:** shell rotation adds a rate times absolute horizontal velocity to the child joint's Y rotation after an external call. The two angle helpers wrap into the inclusive ±π range using opposite loop order, rather than saturating. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/inlines.h#L110-L137)
- **Ray update:** computes XY velocity from speed and angle, clears Z velocity, chooses negative facing when horizontal velocity is zero, updates joint orientation, and grows Z scale. The upper cap precedes the tiny-scale replacement, so replacement with `1e-3F` can exceed a smaller cap. The divisor is not checked here. The return value is delegated to `it_80273130`; the rendered lifetime-timer name is not independent evidence of that callee's implementation. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/inlines.h#L139-L175)
- **Ray bounce/reflection:** bounce mirrors velocity, resets stored scale, derives and wraps the angle, and returns false without immediately updating joint scale. Reflection resets both stored and joint scale and adds π to the angle, but does not directly update velocity. Both use strict angle bounds that leave an exact τ unchanged. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/inlines.h#L177-L203)
- **Bone velocity and reflection orientation:** a non-null bone supplies translation deltas, mapping Z to facing-adjusted X velocity, Y to Y, and X to Z. The helper saves translation through the caller's history pointer before zeroing the joint translation; a null joint leaves all fields untouched. The reflection wrapper calls `it_80273030`, then sets Y rotation from facing and returns false. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/inlines.h#L225-L251)
