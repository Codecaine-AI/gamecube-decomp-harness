# Guard

Pinned revision `c302741689bd67c361cd7faadb221df3193992c3`. All 1,089 C lines and 47 header lines were read canonically and through rendered EOF. The unit implements common GuardOn, Guard, GuardOff, GuardSetOff and GuardReflect plus character dispatch, shield geometry and input helpers.

## State and Data Flow

Held L/R predicate 91A2C has no writes. Input entry checks distinguish newly pressed timed L/R reflection from ordinary held-shield entry with nonzero health. Dash entry writes x20 only after success; Run sets x24. Ordinary startup creates shield collision, initializes analog strength and presentation, then advances into Guard. Shield release latches xC. GuardOff can accept input transitions before its animation expires. Its Attack100-named check dispatches up special.

Shield health breaks strictly below zero after active-shield depletion, then clamps to zero and enters ShieldBreakFly. Shield impact enters GuardSetOff or Yoshi GuardDamage. Generic stun rate depends on impact and analog amount. Unsuppressed recoil uses specialn_facing_dir, the stored impact direction. Friction queues ground acceleration for later integration. Every-hitlag SDI requires allow_sdi, ground, stick threshold and timer; post-hitlag displacement requires ground and threshold but not those extra guards.

Reflection has separate fresh-entry and existing-startup conversion paths. Conversion preserves frame and GFX; fresh entry starts frame zero. Counters expire below zero. GuardReflect IASA has eight checks, verified against the canonical body; its inline release check can write even when no transition succeeds. Fixed two-frame timing is not established by the reviewed assets.

Presentation smooths facing-relative shield angle and magnitude. Scale is affine in health and analog amount for ordinary fighters, fixed at initial size for Yoshi. Yoshi's separate presentation depends on health. Palette-indexed RGB tints effects. Shield geometry is exposed to attached Link arrows; Link and Young Link passive shield callbacks reuse the impact-response scalar. See [dependency text](supplemental-canonical.json).
