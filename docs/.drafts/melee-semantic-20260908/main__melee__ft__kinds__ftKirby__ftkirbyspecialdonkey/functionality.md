## Kirby copied Donkey neutral special

This translation unit implements paired grounded/aerial startup, charging-loop, cancellation, ordinary-release and fully-charged-release callbacks, two entry routines, and charge/effect cleanup. The header also declares foreign Kirby copy families; those declarations do not establish their implementations or validate their rendered names.

### Entry and charge lifetime
`ftKb_SpecialNDk_800FF8EC` and `ftKb_SpecialNDk_800FFA10` compare persistent `u.kb.xBC` with `specialn_dk_swings_to_full_charge` using **equality**, not >=. Equality selects Full, transfers charge into move-local `specialn.xC`, clears persistent charge, and initializes effect stage `x8` to 1. Otherwise startup is selected, local release charge is zeroed, and persistent charge survives. Both entries reset command variables, cancel/impulse latches and damage-cache sentinels. Only grounded entry explicitly calls `ftCommon_8007D7FC` and zeroes vertical velocity. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirbyspecialdonkey.c#L35-L103.

Startup animation completion enters the corresponding Loop. Loop animation increments persistent charge only at exact animation frame zero; reaching or exceeding the attribute threshold clamps the count, requests color animation 58, clears hitlag callbacks, and exits through grounded common handling or aerial Fall. Cancellation completion also clears hitlag callbacks and exits, but does not itself consume stored charge. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirbyspecialdonkey.c#L113-L151 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirbyspecialdonkey.c#L262-L302.

### Input and exceptional sequencing
Loop IASA reads `input.pressed_buttons`, not held input. B enters ordinary release, transfers persistent charge into `xC`, clears the persistent store, restores callbacks and initializes animation processing. L/R independently latches `x0`; frame zero plus that latch enters Cancel. These are sequential independent tests, so the callback does not guarantee mutually exclusive release/cancel processing. Grounded processing is additionally gated by `!ftCo_8009917C(gobj)`; the aerial version has no equivalent outer guard. All other IASA callbacks are empty. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirbyspecialdonkey.c#L394-L456.

### Release behavior
Release effects use a 0→1→2 latch, with effect 1194 selected in air and 1193 otherwise. Full entry already initializes the latch to 1, so that path need not wait for command variable 0. Ordinary release caches each of two hitbox base damages as signed integers using -1 sentinels, then applies cached base plus `xC * specialn_dk_damage_increase_per_swing`. **Hitbox 0's enabled state gates both hitbox updates**; hitbox 1 is not independently tested. Full-release callbacks do not perform this damage scaling. Grounded releases separately use a one-shot hitbox-activation latch to assign charge-scaled facing-relative `gr_vel`; aerial releases do not apply that impulse. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirbyspecialdonkey.c#L153-L260 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirbyspecialdonkey.c#L304-L392.

Release completion clears stored charge and pre/post-hitlag callbacks. Aerial completion enters ordinary Fall when `specialn_dk_freefall_toggle == 0.0F`; otherwise it passes that attribute to `ftCo_80096900`. The zero branch must not be erased by an unconditional helplessness description. Grounded completion delegates to `ft_8008A2BC`, whose common path has exceptional DownSpot and hammer handling before ordinary Wait; it is not simply an unconditional Wait call. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_08A1.c#L53-L98.

### Physics, collision and callback ownership
All grounded physics callbacks delegate to `ft_80084F3C`, which conditionally scales friction above maximum walking speed, applies ground friction, then ground movement. All aerial callbacks delegate to `ft_80084EEC`, which applies common falling and aerial friction. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirbyspecialdonkey.c#L458-L507 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_084E.c#L33-L53.

Collision callbacks preserve the move phase across ground/air transitions. Startup/loop/cancel use common collision flags; ordinary/full release use `ftDk_MF_SpecialN_Coll`. Preserve the literal predicate forms: grounded callbacks compare their query result with GA_Ground; aerial startup/loop/cancel compare with GA_Air, while aerial releases use !=GA_Ground. Enum names here must not be mistaken for an independently proven current fighter state. The local `ftKb_DkSpecialNStart_Coll_inline` only installs death, damage and effect-hitlag callbacks; it does not query or reconcile collision state. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirbyspecialdonkey.c#L105-L111 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirbyspecialdonkey.c#L509-L607.

`ftKb_SpecialNPr_80100DE0` clears persistent charge and calls `efLib_DestroyAll`. Installed Kirby init callbacks reach two copy-kind dispatchers, both of which select this helper for Donkey. Copy-state initialization also clears xBC, extending its lifetime beyond this TU. Effect destruction clears matching parameter references and unlinks owner-associated effects. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirbyspecialdonkey.c#L609-L614; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirby.c#L2580-L2601; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftKirby/ftkirby.c#L3903-L4032; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ef/eflib.c#L244-L283.

### Evidence limits
Rendered names were reviewed as hypotheses, not proof. The conditional `S32_TO_F32` ordering reference does not prove a compiled .sdata2 size, layout or exact literal inventory. No compiled artifacts were supplied. The header's cancel-animation declarations use HSD_GObj while definitions use Fighter_GObj; this spelling difference is preserved rather than treated as a proven ABI mismatch.
