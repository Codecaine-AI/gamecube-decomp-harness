## DEMOPad.c

Provides four-channel demo controller initialization and polling, retaining previous copied input to derive transitions and movement deltas.

- **DEMOPadCopy** converts stick axes into direction bits using strict thresholds below -48 and above +48; exactly ±48 does not activate a direction. Main-stick X negative/positive maps to 0x4000/0x8000, Y to 0x2000/0x1000; substick X maps to 0x400/0x800 and Y to 0x200/0x100. It computes newly active and released direction/button bits against the previous stored state, computes four axis deltas, then copies the complete PADStatus. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/demo/DEMOPad.c#L27-L65.
- **DEMOPadRead** calls PADRead and PADClamp before processing four channels. It recomputes DemoNumValidPads, counting numeric errors 0 and -3. Error -1 contributes the channel's high-order mask bit to a combined PADReset request. Only -3 suppresses DEMOPadCopy: the entire previous DemoPad entry, including previously computed transition flags and deltas, remains unchanged for that channel. All other error values are copied, not merely successful samples. Consequently, subsequent transitions compare against the last copied sample rather than necessarily the previous polling call. Reset occurs after processing all channels and only for a nonzero request. Numeric error values are preserved here without assigning externally defined error names. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/demo/DEMOPad.c#L8-L20 and code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/demo/DEMOPad.c#L67-L88.
- **DEMOPadInit** calls PADInit and explicitly zeros the listed status, transition, direction, and delta fields for all four DemoPad entries. It does not explicitly reset DemoNumValidPads or the private raw Pad array, so it should not be described as clearing all module state on every initialization. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/demo/DEMOPad.c#L90-L115.
