# granime Functionality

Full canonical and rendered review: 1157 C lines and 32 header lines. 37 function targets, five section targets and all 172 subjects accounted for. Two C parse errors are recorded; canonical source remains authoritative.

## Mechanisms

Attachment helpers replace selected AObjs only when descriptors exist. They do not roll back after allocation failure. Recursive attachment uses parallel nullable descriptor trees and stops child descent at flag 0x1000. The separate 8138 path removes existing animations before loading available archive arrays.

Traversal selects JObj, DObj, MObj, TObj, one PObj per DObj, and RObj attachments using distinct masks. Its concrete callback signatures differ from the inherited twelve-format abstraction. In particular tag0 calls an argument-free Event even when wrapper callbacks require an AObj. No source repair or portable runtime success claim is made.

Frame bounds and the longjmp search context are global scratch, so nested/reentrant use is not independently isolated. The two completion helpers test different bits and must not share a promoted name. Descriptor lookup 8578 follows next from its recursive return value, not the original parent.
