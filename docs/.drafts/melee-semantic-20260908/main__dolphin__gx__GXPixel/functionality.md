### Fog and range adjustment

`GXSetFog` derives A/B/C from fog bounds and clipping planes, normalizes B, packs coefficients into registers 0xEE–0xF1, and writes RGB to 0xF2. When either depth interval collapses, it uses A=0, B=0.5 and C=0 but still emits the requested type and RGB color. Color alpha is not consumed. The source retains its literal `8.388638e6f`, unsigned exponent arithmetic and explicit shifts; this review does not substitute a presumed hardware constant or claim defined behavior for every nonfinite or otherwise invalid input. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXPixel.c#L8-L95).

`GXInitFogAdjTable` is CPU-only: it selects projection formulas using `projmtx[3][3] == 0`, computes ten horizontal distance ratios, scales by 256 and stores the low 12 bits. The source asserts a non-null table and width <=640, but does not assert positive width or nonzero matrix denominators. `GXSetFogRangeAdj` reads and emits five pairs only when enabled; it always emits the center-control word, with center biased by 342. Disabling therefore accepts a null table and leaves the previously programmed coefficient words untouched. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXPixel.c#L97-L152).

HSD builds a temporary stack table from stored or active projection data and immediately passes it to the consuming setter; GX retains no table pointer. HSD clamps its derived center to 0–640. Its null-fog branch sets fog and returns before touching range adjustment, unlike the non-null fog/no-adjustment branch, which explicitly disables adjustment. [Caller](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/fog.c#L19-L84).

### Pixel-output state

Blend mode, color writes, alpha writes and dithering share `cmode0`; destination alpha and component-format selection share `cmode1`. Depth comparison enable/function/write enable use `zmode`, while comparison location and framebuffer formats share `peCtrl`. The simple setters emit their updated shadow words without unchanged-value suppression. Blend factors and logic operation are encoded even when the chosen mode does not use them. [Setters](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXPixel.c#L154-L246).

`GXSetPixelFmt` maps eight API values through `{0,1,2,3,4,4,4,5}`. It emits `peCtrl` only when the complete encoded word changes; that same condition recomputes `genMode` bit 9 and sets dirty mask 0x4, even if the AA value itself did not change. Formats mapping to 4 independently emit the component selector in `cmode1`, including when `peCtrl` is unchanged. Every path clears `bpSent`, including a path emitting no register. Thus `bpSent=0` must not be interpreted as proof that commands were or were not issued. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXPixel.c#L203-L229).

HSD wrappers separately normalize Boolean inputs and suppress redundant writes using their own caches; render-mode invalidation resets those caches. Direct GX calls do not update those HSD caches. The rectangle-clear path directly configures independent color, alpha and depth controls, draws, and then invalidates HSD state. GX startup establishes the documented defaults, and the refraction setup explicitly disables dithering. [HSD cache](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/state.c#L356-L444), [clear path](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/displayfunc.c#L557-L596), [startup](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXInit.c#L338-L350), [refraction](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbrefract.c#L642-L657).

### Field output and evidence boundaries

`GXSetFieldMask` constructs a fresh register 0x44 word with even and odd controls in bits 0 and 1. `GXSetFieldMode` writes the half-aspect flag into `lpSize` bit 22, emits it, calls the texture-state flush helper, emits `field_mode | 0x68000000`, and calls the helper again. Unlike a one-bit field insertion, the latter OR does not normalize arbitrary noncanonical Boolean values. Startup supplies `field_rendering` as the first argument and the VI/XFB height comparison as the second. The helper emits `bpMask` and clears `bpSent`; this is not evidence of a GPU-completion wait. [Field APIs](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXPixel.c#L248-L272), [argument provenance](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXInit.c#L348-L350), [helper](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXBump.c#L374-L378).

The visible CHECK_GXBEGIN/assertion calls establish source-level preconditions, not independently verified release-build enforcement. Immediate register emission does not establish synchronous GPU completion. Source proves the local `p2f` declaration and fog arithmetic, but not that the entire `.data` target equals `p2f` or that particular literals and widths occupy `.sdata2`; those section claims remain unresolved without compiled evidence.
