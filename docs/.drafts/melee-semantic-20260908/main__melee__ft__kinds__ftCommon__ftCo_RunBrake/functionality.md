## Detection and entry
CheckInput reads input.lstick[0].x, negates it only if negative, and enters RunBrake exactly when the result is strictly less than x58_someLStickXThreshold. It is a level test, not an edge detector: no previous input, ground state or running state is checked locally. Equality fails. For ordinary finite input it treats both directions symmetrically. Under ordinary IEEE comparisons, signed zeros compare equally; a NaN input or threshold fails the guard; infinite input cannot pass a finite threshold. Nonpositive thresholds admit no ordinary magnitude. Enter clears cmd_vars[0] and [1] before Fighter_ChangeMotionState(gobj, ftCo_MS_RunBrake, Ft_MF_None, 0.0F, 1.0F, 0.0F, NULL), then resets runbrake.x0 and copies max_run_brake_frames without validation. Sound ft_PlaySFX(fp, 0x119, 0x7F, 0x40) occurs only if x197C is non-null. The field's semantic identity and the sound's asset identity remain unknown. ## Animation and duration
With cmd_vars[1] nonzero, x0 false selects the freeze branch: ABS(gr_vel) >= x42C sets rate zero and x0 true. Subsequent callbacks with x0 true resume at rate one when ABS(gr_vel) <= x42C and clear cmd_vars[1], but do not reset x0. At equality, freezing and resuming therefore require separate callbacks. A later reassertion of command variable 1 uses the already-true branch rather than starting a new freeze cycle. Without the command, neither speed comparison changes animation. NaN velocity or threshold makes both ordered comparisons false; negative or infinite tuning values are not sanitized.
The independent floating timer is decremented only when truthy, by 1.0F, and a negative result is clamped to zero. Zero skips subtraction; positive fractions at most one expire on that callback; negative finite values and negative infinity clamp to zero. NaN stays truthy and un-clamped, positive infinity does not count down, and sufficiently large finite floats may not change when one is subtracted. Thus a universal finite-duration guarantee is unsupported. After maintenance, ft_8008A2BC is called unless both ftAnim_IsFramesRemaining and the timer are truthy. The animation predicate is evaluated first; timer truth is short-circuited on predicate failure. Source: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_RunBrake.c#L49-L78.

## Physics and collision
Phys unconditionally passes run_dash_turn_friction_multiplier * co_attrs.ground_friction to ftCommon_ApplyFrictionGround, then calls ftCommon_ApplyGroundMovement. The friction helper writes xE4_ground_accel_1, not gr_vel directly: when |friction| > |gr_vel| it uses -gr_vel, otherwise it negates friction for positive gr_vel. Ground movement optionally scales acceleration by a surface multiplier below one and projects acceleration and existing gr_vel along the floor normal into x74_anim_vel and self_vel. Deceleration is the normal nonnegative-friction interpretation, not a guarantee for negative or NaN tuning. No validation occurs in this TU.
