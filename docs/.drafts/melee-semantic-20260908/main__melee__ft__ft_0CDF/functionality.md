## Initial entry
`ftCo_800CDF5C` clears all throw flags, tests current item status, and selects grounded loaded or empty L-Gun motion. `ftCo_800CE010` performs the aerial equivalent. Both use flags 0, frame 0, speed 1, final float 0, and NULL; call `ftAnim_8006EBA4`; install `ftCo_800CE1D4` as `accessory4_cb`; and notify a still-present item through `it_8028E938`. The aerial entry also clamps air drift. Neither entry locally changes ground_or_air. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0CDF.c#L14-L53.

The grounded dispatcher attempts pickup first and dispatches It_Kind_L_Gun only if pickup returns false; the aerial dispatcher directly selects its L-Gun entry. The ammunition predicate dereferences its argument without a NULL guard and treats L-Gun ammunition <=0, including negative ammunition, as empty. Other kinds may return false independently of ammunition. Thus the later NULL checks do not make initial entry safe without an item. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0CDD.c#L13-L53 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L300-L320.

Item notification sets a timer to 40 and enters item state 3. Its active callback predecrements the timer and returns to state 2 at <=0; pickup also enters state 2. This does not establish fighter duration or firing cadence. Capacity comes from ItLGunAttr.max_ammo. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itlgun.c#L31-L51 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itlgun.c#L118-L146.

## Terrain transitions
`ftCo_800CE0CC` invokes grounded setup, maps exactly LGunShootAir to LGunShoot and every other source motion to LGunShootEmpty, forwards current frame and speed with mask 0x0C4C5080, and reinstalls the accessory callback. `ftCo_800CE14C` invokes airborne setup, maps exactly LGunShoot to LGunShootAir and every other motion to LGunShootAirEmpty, forwards the same timing and mask, clamps drift, and reinstalls the callback. Neither locally rechecks ammunition, clears throw flags, calls the entry animation initializer, or restarts the item timer. Matching loaded/empty preservation assumes intended-family input; the else branches are broader. Exact mask decomposition and unconditional pending-event preservation remain deferred. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0CDF.c#L56-L98.

## Deferred event and lifetime
With no item, `ftCo_800CE1D4` leaves a pending bit unchanged. With an item and clear bit, it does nothing. With an item and set bit, it clears the bit before work, obtains the configured item offset, transforms it through the configured fighter joint, and rechecks ammunition. Offset transformation divides by fighter y scale when it is not exactly 1, with no zero-scale guard. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0CDF.c#L106-L143 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0CDD.c#L79-L97.

The nonempty branch requests item firing at the unflattened transformed position, then sets z=0 for effect 1073. Sound 228 is selected only for facing exactly +1; every other value selects 229. Empty feedback uses effect 1029 at the unflattened position and sound 230. All sound calls use remaining arguments 127 and 64. The item firing helper decrements positive ammunition and forwards the item's owner, position, and direction to it_80298168. No return is checked, and no local failure path restores ammunition or the event. One consumed bit means one request sequence, not guaranteed allocation or one projectile per script command. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itlgun.c#L53-L69.

The callback is a persistent Fighter field, not a captured item pointer, and reads the current item on each invocation. Motion setup clears accessory4_cb, explaining reinstallation; firing does not unregister it. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/fighter.c#L1370-L1389. Inherited research also records hitlag-gated scheduling and a generic script producer of throw_flags_b0, without establishing actual L-Gun event frames. Automatic position vectors, downstream retention, allocation success, ownership, cleanup, and exact audiovisual asset identities remain explicit cross-file follow-ups.

Both Anim wrappers call ftCo_800CDE18, which checks remaining animation and invokes completion handling only when none remains; it does not advance animation. Both IASA bodies are empty, proving only no local IASA cancel logic. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_084E.c#L42-L53 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_081B.c#L1363-L1375.

## Boundaries and conventions
Valid fighter/user_data and appropriate item/collision context are assumed. The event callback tolerates no item but does not validate a non-NULL item's kind. Arbitrary transition motions take broad empty-state else paths. Timing, scale, offset, and facing values are not locally normalized: zero or nonfinite scale can invalidate transformed positions; NaN or nonunit facing does not select sound 228 unless exactly +1. Inherited clamp analysis is conditional on ordinary finite nonnegative bounds, not a universal guarantee for invalid bounds. Source comparisons do not establish compiler floating-point mode or reachable asset values.

No owned function acquires or releases Fighter or item ownership. The #r3 parameter identities do not prove compiled register assignments. MUST_MATCH only brackets the accessory function with push/dont_inline/pop pragmas; unused f0 and padding do not prove runtime behavior or stack layout. No compiled section, ABI, object-layout, instruction-size, or pool claim is promoted.
