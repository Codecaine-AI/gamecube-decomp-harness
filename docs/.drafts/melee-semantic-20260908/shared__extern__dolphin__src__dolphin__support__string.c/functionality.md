- `Strcat(str1, str2, dst)` writes the concatenation of two NUL-terminated inputs starting at `dst`, rather than appending to an existing destination string. It returns 0 without writes if any argument is null, otherwise copies both inputs, writes a final NUL, and returns 1. No destination-capacity or overlap checks are present. - `Strcpy(dst, src)` is not standard `strcpy`: it copies a byte, advances both pointers, then tests the next source byte. For a nonempty string it omits the terminating NUL. For an initially empty string it copies the initial NUL but then reads beyond that terminator; it does not reliably stop at the empty string. It has no null or capacity checks. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/support/string.c#L32-L39.
- `Strcmp(str1, str2)` compares bytes cast to `s8`, returning +1 when the first differing byte in the first input is smaller and -1 when larger, opposite the usual strcmp sign convention. After equal bytes it advances both cursors and returns 0 if either next byte is NUL, so matching nonempty prefixes can compare equal despite differing lengths. It does not initially check for terminators: equal initial NUL bytes cause an advance and reads beyond those terminators. No null checks are present. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/support/string.c#L41-L58.
