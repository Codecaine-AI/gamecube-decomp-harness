## Entry and scale animation
Both entries save old motion before interruption/capture cleanup, enter their respective SmallStart state with flags 0x90, frame 0 and speed 1, run a shared initializer and install ftCo_800D1F6C as take_dmg_cb. Entry itself does not recheck eligibility or ground/air. Shared initialization saves and zeros movement and chooses an air continuation from old motion. FallAerial selects its entry; FallSpecial, ItemParasolFallSpecial and Peach's numeric 0x172 special case select ftCo_800968C8; other cases select Fall. The Peach number is not assigned an inferred gameplay label.

Target scale is current x34_scale.y times x684 when x34_scale.x < 1, otherwise times x680. The comparison and multiplication use different components. Animation index 0 is initialized with current y and target; sound/feedback helpers run and mushroom x4 receives the finalizer. The auxiliary x2184 joint is allocated only if absent. Start and target are stored in walk-named move-state fields. Updates advance the auxiliary animation and apply `(fast - mid) * joint_scale_x + mid`; a 0x40000000 animation flag returns false, causing either owned Anim callback to finalize. Ordinary fighter-animation completion is not the predicate. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_KinokoSmallStart.c#L79-L168 and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0D27.c#L70-L177.

## Finalization and external consumers
The finalizer restores saved movement, sets b6, loads x688 into x2008, commits the terminal scale, then unconditionally resets movement. The reset zeros the fields just restored; saved velocities are not preserved into outgoing dispatch. Ground calls ft_8008A324 and returns; otherwise mushroom x0 is invoked without a null guard. Completion is shared by Anim completion, installed damage/interruption callbacks and active-application x4, with no local once-only guard. Scale commitment also calls parameter, camera and collision-size helpers.
