## ItemScrew fighter-state implementation

This unit defines two entry routines and paired Anim, IASA, Phys and Coll callbacks. Its header consistently declares all ten functions. Grounded terminology denotes a ground-origin jump, not grounded movement: both entries call ftCommon_8007D5D4, which sets GA_Air.

### Entry and data lifetimes

ftCo_ItemScrew_Enter performs airborne setup, selects ftCo_MS_ItemScrew with flags 0 and floating arguments 0.0F, 1.0F, 0.0F, calls ftCo_800CB110(gobj, false, p_ftCommonData->x800), and sets x2227_b0. KneeBend selects this entry when its startup threshold is reached or its animation is exhausted, provided ft_800D2D0C succeeds. The shared jump initializer clears mv.co.jump.x4, calculates multiplier-scaled launch velocity with short-hop/full-jump alternatives and horizontal clamping, resets the stick timer to 0xFE, and suppresses its optional sounds because the Boolean argument is false. ### Updates and exits

Animation exhaustion enters Fall for ItemScrew and FallAerial for ItemScrewAir; while frames remain, these callbacks do nothing locally. IASA delegates to Jump_IASA or JumpAerial_IASA respectively. Their ordered early-return chains differ: the former gates checks with mv.co.jump.x4, the latter with cmd_vars[0]. The owned entry does not locally initialize the aerial cmd_vars[0]. Ground-origin physics uses Jump_Phys_Inner, which sets a false x4 true and skips movement on that update; subsequent updates invoke ft_80084DB0. Air physics invokes ft_80084DB0 immediately. [Owned callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_ItemScrew.c#L31-L84), [Jump gates](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Jump.c#L174-L201), [aerial gates](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_JumpAerial.c#L288-L303).

Both collision callbacks pass ftCo_80096CC8 and ft_80082B1C to ft_800831CC. Shared collision code synchronizes Fighter/CollData positions, chooses an alternate query when ledgeCooldown or x2224_b2 is set, otherwise supplies facing direction, copies the resulting position back, and can reject contact through ft_80081A00. Accepted contact invokes the response; otherwise wall-jump is checked before ledge grab. The floor predicate rejects line -1 and accepts platforms only when stick y is strictly greater than x25C. The response calls ft_8008A2BC when self_vel.y is strictly greater than ftCo_800D0EC8(fp), otherwise basic landing; this is not simply a positive-upward-motion test.
