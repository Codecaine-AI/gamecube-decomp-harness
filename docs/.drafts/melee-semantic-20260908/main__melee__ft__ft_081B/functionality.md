## Fighter environmental collision adapters
Initializes CollData, clears ECB lock, retains character-selected joint references and installs scaled ECB/ledge dimensions and weight. Scale refresh preserves bindings and distinguishes supplied scale from current model scale. Runtime wrappers advance collision-position history, submit current fighter position to airborne or grounded map queries, then copy correction back. The placement probe instead constructs a +/-10 Y sweep and copies back only on success.

Airborne variants distinguish ECB load flags from collision modes: ordinary floor acceptance, stay-airborne floor-mask notification, callback-filtered floors and optional ledge discovery. SDI takes priority in the damage-style variants; temporary ledge-height enlargement is restored. Returned floor contact is not a ledge-grab result. ft_80081A00 may itself invoke an item response; a veto suppresses later floor dispatch, not all state changes or wrapper wall/cliff fallbacks. Callback-aware map passes install the floor predicate and fighter in global context without restoring the previous pair in the visible helper.

Accepted floor responses select a caller event or velocity-dependent neutral/basic landing. Neutral dispatch includes boss, DownSpot and hammer exceptions. Fallback order is wall jump then cliff, with cliff-only and additional ceiling-stop variants. Grounded queries return support; misleading GroundOrAir labels are preserved as exact enum/zero tests rather than physical-state meanings. Support-loss adapters select Fall, caller continuation, teeter or backward MissFoot.

Explicit-box orientation returns the original input unless facing is negative, when scratch receives reflected horizontal extrema. The map consumer copies descriptor fields into desired_ecb synchronously. ECB snapshots can outlive the call in action-owned storage; CollData transfer is selected-field source-to-destination copying, not full rebinding. Ledge occupancy returns a borrowed first-match fighter; zero facing matches neither side.

Other utilities query recorded floor validity, override surface friction to1 for Popo/Nana, decode three surface-feedback families, export ECB bounds, test directional walls between ECB-centered fighter points and compose fast-fall/gravity/aerial drift. Surface selectors have no default outside0..2; failure leaves outputs untouched, and valid-floor success may still return missing-override sentinels. Equal-X wall endpoints use the left-wall query. Aerial drift writes a movement correction rather than directly updating position.

Rendered names are hypotheses. Ground-check names collide across distinct modes; pointer-return header declarations can remain unsubstituted despite renamed definitions. The dox contains stale signatures and declarations from the neighboring physics unit. No compiled section or layout conclusion is made.
