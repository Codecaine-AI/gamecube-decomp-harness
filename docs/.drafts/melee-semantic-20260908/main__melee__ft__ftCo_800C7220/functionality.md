## Animation semantics and optional behavior
The zero blend argument is a default-selection sentinel, not proof of no blending. When animation data and x590 are present, zero selects (*unk_byte_ptr)[0]; -1 would select zero, but is not passed here. NULL arg3 selects the fighter's own animation metadata. Speed is initially stored as 1 in frame_speed_mul and x8A0_unk, while cur_anim_frame is initially anim_start-speed, or -1 here. Animation setup and updates subsequently affect the result; a final frame of zero is not an unconditional postcondition. The animation-id -1 branch clears animation metadata and blend/frame fields instead. The transition also performs broad state cleanup under zero preservation flags, clears x2219_b1/b2, and replaces motion callbacks. Thus the wrappers' final flag writes occur after transition cleanup.
