## Donkey Kong SpecialLw

This unit implements the Start, Loop, End0 and End1 callback families for Donkey Kong's Hand Slap. The header declares the public entry, state callbacks and two effect routines; the transition and bookkeeping helpers remain internal.

### State progression and input

`ftDk_SpecialLw_Enter` clears `mv.dk.speciallw.x0`, enters SpecialLwStart with flags/frame/rate/blend arguments `0/0/1/0` and a NULL final argument, then calls `ftAnim_8006EBA4`. Startup animation exhaustion calls `doAnim`. During Loop, IASA tests `input.pressed_buttons & 512` and sets the repeat latch to 1 without immediately changing state. At animation exhaustion, Loop consumes and clears a set latch before restarting; otherwise `doTransition` enters End0. Start, End0 and End1 IASA bodies are empty, establishing no callback-local input handling rather than global immunity to interruption. ### Callback and effect lifetimes

`doAnim` installs `callback` into `x21EC`, clears throw flags and changes to Loop. Motion change invokes and clears `x21EC`: this is a transition-time bookkeeping hook, not a persistent per-frame callback. The hook calls attack-record processing before refreshing the stale attack instance. Motion change also clears accessory and hitlag callback slots; afterward the local initializer configures effect hitlag handling and installs `ftDk_Init_8010DB3C` into `accessory4_cb`. That external routine conditionally positions four hitboxes using floor queries, with fighter-position fallback and a +2 vertical offset.
