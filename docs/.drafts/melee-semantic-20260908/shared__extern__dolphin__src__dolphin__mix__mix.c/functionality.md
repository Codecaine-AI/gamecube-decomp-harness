## MIX semantic review

This file implements control-side mixing for 64 channels indexed by AXVPB index. Lookup tables convert volume parameters to gains and pan positions to complementary attenuation values. Volume conversion returns zero at or below -0x388 and saturates at 0xFF64 at or above 0x3C; pan lookup asserts a 0–127 range. Reset sets mode 0x50000000, auxiliary levels to -0x3C0, and cached current gains to zero. Notably, reset derives front/back attenuation using position 0 while storing span 127; normal pan recomputation uses the stored span. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/mix/mix.c#L406-L480)

MIXInitChannel binds an AXVPB, retains mode bits 0–2, computes input and main/auxiliary gains, and writes initial gains with zero deltas under interrupt protection. Mode masks 0x1 and 0x2 select pre-fader auxiliary A/B behavior; mask 0x4 mutes the input gain. Initialization passes pan/span directly to the asserting lookup helpers rather than clamping them. Release only clears the channel's AXVPB pointer; reset does not clear that pointer, and MIXQuit is empty. This file does not establish external voice ownership or destruction guarantees. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/mix/mix.c#L439-L575)

Input and mute setters mark 0x10000000; auxiliary, fader and pan changes mark 0x40000000. Pan/span setters and adjusters clamp to 0–127, while getters return stored controls. MIXUpdateSettings skips unbound channels, promotes previous targets under bits 0x20000000/0x80000000, computes requested targets, and writes gain deltas as target-minus-current divided by 160. It rebuilds mixer control bits from current auxiliary/surround gains and nonzero mix deltas, then marks AX synchronization. Unlike the mix-request bit, the input-request bit is not cleared in this routine. Main surround gain also differs between initialization and update: only the update formula subtracts 0x3C. These differences are preserved rather than normalized into an idealized mixer description. DVD stream control clamps the requested attenuation to [-49,0] and moves the current value one unit toward it per update, writing both AI stream volumes only when it changes. Canonical source directly indexes the 50-entry table with that signed current value, so a negative request from the initialized zero state leads to a negative index. No corrective offset or safe runtime interpretation is assumed.
