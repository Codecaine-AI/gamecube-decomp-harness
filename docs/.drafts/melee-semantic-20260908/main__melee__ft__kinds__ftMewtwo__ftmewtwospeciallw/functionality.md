## Mewtwo Disable: fighter-side lifecycle

This unit implements grounded `SpecialLw` and aerial `SpecialAirLw` for Mewtwo's down special, Disable. The header declares all 15 public routines; the source also contains the private callback-restoration helper. [Declarations](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftMewtwo/ftmewtwospeciallw.h#L1-L22).

### Entry and deferred creation
Both entries clear `throw_flags`, `cmd_vars[0]`, and the tracked `x222C_disableGObj` pointer, select their respective symbolic motion state with arguments `0, 0.0f, 1.0f, 0.0f, NULL`, call `ftAnim_8006EBA4`, and install `ftMt_SpecialLw_CreateDisable` in `accessory4_cb`. Aerial entry additionally zeroes vertical self-velocity. Clearing the pointer is not destruction of a previously referenced item. [Entry routines](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftMewtwo/ftmewtwospeciallw.c#L48-L87).

Creation does nothing when `cmd_vars[0]` is zero. Otherwise it obtains a position using `lb_8000B1CC` on `FtPart_L3rdNb`, adds the facing-scaled X offset and Y offset, calls the Disable item spawner, and stores its result. A non-null result enables death/damage callbacks. The command variable is reset even if spawning fails. There is no existing-object guard before overwriting the tracked handle: this establishes one storage slot, not a proven global single-projectile invariant. [Creation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftMewtwo/ftmewtwospeciallw.c#L209-L233), [callback guard](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftMewtwo/ftmewtwospeciallw.c#L149-L156).

### Animation, physics, and terrain transitions
Both animation callbacks remain inert while frames remain. On completion they conditionally destroy and clear the tracked item, then invoke `ft_8008A2BC` for grounded completion or `ftCo_Fall_Enter` for aerial completion regardless of whether an item existed. Both IASA callbacks are empty; this does not imply immunity to engine-level interruption. [Animation and IASA](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftMewtwo/ftmewtwospeciallw.c#L89-L128).

Ground physics delegates to `ft_80084F3C`. Its canonical implementation applies ground friction, multiplying it by `friction_when_above_walk_speed` only when absolute ground velocity strictly exceeds maximum walking velocity, then updates ground movement. Aerial physics passes Disable-specific gravity and terminal velocity to `ftCommon_Fall`, followed by common aerial friction. The duplicated `fp = fp = GET_FIGHTER(gobj)` spelling is present in canonical source, not introduced by rendering. [Physics callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftMewtwo/ftmewtwospeciallw.c#L130-L147), [ground helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_084E.c#L42-L53).

Collision wrappers supply the corresponding terrain-transition callbacks to `ft_8008403C` and `ft_80082C74`. Ground-to-air calls `ftCommon_8007D5D4`, zeroes vertical velocity, changes to `ftMt_MS_SpecialAirLw` at the current animation frame, restores creation and guarded interruption callbacks, and clamps aerial drift. Air-to-ground delegates to `ftCommon_AirToGroundStateChange` with `ftMt_MS_SpecialLw`, then restores the same callbacks. Both use the explicit collision-preservation flag expression; unknown flag components remain unknown, and no numeric motion-state mapping is inferred. ### Cross-file ownership and cleanup
`ClearDisableGObj` only nulls the fighter-side reference, despite its stale stall-flag comment. `RemoveDisable` checks that reference, destroys the item when present, and clears the field. Both Mewtwo death and damage hooks call removal. On item destruction, the item checks its stored owner before calling fighter-side clear, then nulls its own owner field. Item spawning can return null; successful creation records ownership and initializes item behavior. The item also has an owner-reference invalidation event, so reciprocal ownership must not be assumed permanent.
