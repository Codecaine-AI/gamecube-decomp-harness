# Naming Decisions

Retain ftCo_Shouldered_Enter and ftCo_Shouldered_ApplyDamage as hypotheses for C5A4 and C744. Neither is a recovered canonical name; the prior frozen-KB and canonical-source searches found no competing owner. C744 has internal linkage from the static forward declaration at line26, despite the definition omitting static. It has no owned header declaration. The static source-only helper is inlineA0, whose carrier-ground-state role is documented without creating a target or alias.

Canonical Anim, IASA, Phys and Coll names remain unchanged. The source entity and .sdata2 identity remain unchanged. All nine parameters were reviewed: r3 receives Fighter_GObj*, r4 selects FtMotionId in definitions but is declared unnamed int in the header. Callback gobj arguments are unused in the three empty bodies. Rendered function substitutions are reading aids only; exact per-page mappings and fact metadata remain in coverage.json and the saved pages.
