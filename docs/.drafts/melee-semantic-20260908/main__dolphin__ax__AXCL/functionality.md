## AXCL semantic review

AXCL constructs CPU-side command streams for the audio DSP using two `u16[384]` buffers. Initialization asserts 32-byte alignment of both starts and selects mode 0, position 0, and the first write buffer; it does not explicitly reset the cycle estimate or clear command storage. The address getter captures the selected buffer address, toggles the position modulo two, redirects the writer, and returns the captured address. These sequential updates do not establish atomicity.

`__AXNextFrame` appends halfwords through the existing cursor without resetting it or checking capacity. Addresses are serialized high halfword first. It starts the cycle estimate at `0x1A9`, emits studio command 0 and adds `0x2E44`. Mode 0 emits command 7 and adds `0x546`; modes 1 and 4 emit `0x11` and add `0x5E6`; modes 2 and 3 omit this group. Other values reach an assertion. Voice commands 2 and 3 follow. Nonzero auxiliary input addresses enable five-word input/output groups: Aux A uses opcode 4; Aux B uses `0x10` in mode 4 and 5 otherwise. Each enabled group adds `0xDED`. Normal completion emits `0xE` with both caller buffers, adds `0x2710`, emits `0xF`, adds 2, and flushes exactly `0x300` bytes beginning at the entry cursor—not merely the emitted byte count. [Canonical builder](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXCL.c#L19-L119).

AXOut synchronizes voice parameters using the previously constructed list's cycle estimate, obtains and mails that list to the DSP, processes auxiliary/user callbacks, then builds the following list in the alternate command buffer. Output sample buffers have their own alternating index; DMA is configured after that index advances. Initialization primes a command list before starting DMA. [Pipeline](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXOut.c#L25-L61), [priming](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXOut.c#L152-L175). The cycle accessor is observational; AXVPB combines its result with overhead, lost cycles and voice costs, servicing budgeted voices only while the total is strictly below the maximum. [Budget consumer](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXVPB.c#L590-L637).

`AXSetMode` stores changed values without validation and clears the 256-byte HRTF-history array only when changing to numeric mode 1. Repeating mode 1 does not clear it. `AXGetMode` directly returns the mode. `__AXClQuit` has only a debug report and does not reset state. Numeric modes are preserved without assigning unproved semantic enum names. [Mode/lifecycle helpers](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/ax/AXCL.c#L121-L141).
