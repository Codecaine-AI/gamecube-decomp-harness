## Runtime arithmetic and conversions

This unit implements compiler-support operations using PowerPC register pairs rather than game-specific state. The nominal `ASM void(void)` declarations hide semantic inputs and results carried directly in registers. Division and remainder consume high:low pairs r3:r4 and r5:r6; shifts consume r3:r4 and a count in r5.

- `__div2u` and `__mod2u` use leading-zero alignment and carry-based shift/subtract loops. A narrower dividend returns zero for division and the unchanged dividend for remainder. Signed counterparts first obtain magnitudes: division restores the XOR of operand signs, while remainder restores only the dividend sign. There is no explicit divide-by-zero or signed-overflow guard. Ordinary arithmetic descriptions should not be read as guarantees for those exceptional inputs. See code://c302741689bd67c361cd7faadb221df3193992c3/src/Runtime/runtime.c#L40-L389.
- `__shl2i`, `__shr2u`, and `__shr2i` implement cross-word left, logical-right, and arithmetic-right shifts for normal counts 0–63. Raw PowerPC variable shifts do not establish a general saturation rule for arbitrary counts. See code://c302741689bd67c361cd7faadb221df3193992c3/src/Runtime/runtime.c#L394-L437.
- `__cvt_fp2unsigned` loads binary64 constants 0, 2^32, and 2^31. Ordered negative inputs return zero; inputs at or above 2^32 return UINT32_MAX. In-range conversion uses truncating signed `fctiwz`, subtracting and restoring 2^31 for the upper unsigned half. Unordered inputs follow a different comparison path and should not be described merely as ordinary saturation. The non-Metrowerks alternative is a C cast, not an equivalent explicit saturation implementation. See code://c302741689bd67c361cd7faadb221df3193992c3/src/Runtime/runtime.c#L3-L38.
- `__cvt_sll_dbl` and `__cvt_sll_flt` extract sign and magnitude, handle zero separately, normalize, and construct a binary64 representation with a nearest-even intermediate rounding decision. The float helper subsequently executes `frsp`; this is not evidence of a single direct integer-to-float rounding step. Stack scratch storage is released before return. See code://c302741689bd67c361cd7faadb221df3193992c3/src/Runtime/runtime.c#L439-L542.
- Despite its `u64` declaration, `__cvt_dbl_usll` implements signed-range truncation and sign-selected saturation. Exponents below 1023 return zero; exponent-minus-1075 selects right or left alignment; values requiring left shifts greater than 10 return 0x7FFFFFFFFFFFFFFF or 0x8000000000000000 according to the source sign bit. The same exponent branch also handles infinities and NaNs without separate classification. See code://c302741689bd67c361cd7faadb221df3193992c3/src/Runtime/runtime.c#L544-L607.

The header declares additional unsigned conversion helpers whose definitions are not present in this owned C file. No implementation or cross-file lifetime is inferred from those declarations. The two baseline r3 entities have no facts; r3 is an output/work register in the corresponding bodies, not the incoming double parameter. See code://c302741689bd67c361cd7faadb221df3193992c3/src/Runtime/runtime.h#L6-L19.
