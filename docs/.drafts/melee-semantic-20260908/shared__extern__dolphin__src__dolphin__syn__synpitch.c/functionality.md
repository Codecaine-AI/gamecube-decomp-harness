## Synthesizer pitch and sample-rate conversion

`__SYNSetupPitch` establishes the voice's base sample-rate ratio as `sampleRate / 32000.0f`, calculates note displacement from the region's unity note in cents, adds fine tuning, and shifts the result left by 16. `__SYNGetRelativePitch` combines that base pitch with LFO, pitch-envelope, and channel pitch-wheel contributions, divides by 65536, and converts whole cents to a multiplicative pitch ratio. Positive offsets use octave, semitone, and cent tables; negative offsets adjust a nonzero negative cent remainder into a positive cent index paired with a downward semitone index. Zero returns 1.0. The table values and original names fit these roles. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synpitch.c#L7-L96)

`__SYNSetupSrc` multiplies the base sample-rate ratio by relative pitch, caps a floating-point result above 4.0 before conversion to a 16.16-style unsigned value, sets `srcSelect` to numeric value 1, writes the ratio as two successive halfwords, and clears five subsequent halfwords. It clears synchronization bit `0x80000` and sets `0x40001`. These are source-level writes, not a claim about compiled layout or the symbolic meaning of the selector. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synpitch.c#L98-L128)

`__SYNUpdateSrc` instead converts the scaled ratio to `u32` before capping it at `0x40000`, stores through a `u32*` at `ratioHi`, and sets synchronization bit `0x80000`. Unlike setup, it does not reset the remaining SRC state or selector. The clamp ordering is materially different for exceptional conversion inputs and should not be described as universally equivalent. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synpitch.c#L130-L139)
