## Popo side special

This translation unit implements the grounded and aerial S1/S2 variants of Popo's side special, mapped in the frozen baseline to Squall Hammer. S1 and S2 are alternative partner configurations, not successive phases. Entry resets command variables and move-local state, initializes x4 to 10 and x14 from attribute x68, and calls Nana's initializer before selecting the matching motion and storing or clearing x1A5C. Ground entry sets vertical velocity to zero and horizontal/ground velocity from x28; aerial entry selects x20 or x24 vertical velocity and uses x2C horizontally. Animation initialization precedes the effect-reference reset. [Entry](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPopo/ftpopospecials.c#L105-L201)

### Input and movement

Ground IASA writes stick X scaled by x30 into x1C when its magnitude reaches the inclusive x40 threshold; air uses x34. S2 delegates to the corresponding S1 input callback. Physics honors directed steering only when command variable 0 is zero and x1C is nonzero. Ground physics otherwise applies friction; directed ground movement also adds a floor-normal contribution scaled by x6C. [Input and ground physics](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPopo/ftpopospecials.c#L303-L452)

All four physics callbacks increment the boost-spacing counter x14 and queue B from **pressed_buttons**, gated by command variable 2. A nonzero queue is consumed only when x14 exceeds x68: one vertical increment is applied and the entire queue and spacing counter are cleared. Ground consumption enters the matching aerial variant at the current frame. S1 uses x60 and S2 uses x64. The independent x18 counter advances each tick; aerial physics uses variant-specific gravity and terminal velocity while x18 is below x5C, then calls basic falling physics. No relative attribute magnitudes are established here. [Aerial physics](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPopo/ftpopospecials.c#L454-L510)

### Collision and presentation

The static ftCollisionBox initializer is {12, 0, -6, 6, 6, 6}. Ground and air callbacks pass it to their respective collision helpers, preserve the S1/S2 variant across terrain transitions, and write contact state xC. Positive horizontal velocity selects LeftWallMask and negative velocity selects RightWallMask. Below x48, rebound assigns the opposite signed x48; otherwise it multiplies velocity by -x44. The latter branch does not establish a universal minimum resulting speed. Landing zeros vertical animation/self velocity and clamps ground speed. [Collision family](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPopo/ftpopospecials.c#L512-L687)

Both aerial callbacks compare the ceiling-mask result to **1**, not to nonzero. The mask is 0x2000 | 0x4000, so that branch cannot succeed as written. This is preserved rather than normalized into an ordinary ceiling response. [Mask definition](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/mp/forward.h#L97-L99)

Model slope alignment requires both command variable 3 and xC. The effect helper reveals its selected subtree only in grounded S1/S2 and otherwise hides it; enabled floor alignment sets root Z rotation to negative atan2 of the floor normal. A null x8 is a no-op. With nonnull x8, a failed presence/nested-GObj check clears the reference, presence flag and hitlag callbacks. Model hierarchy pointers are traversed without explicit validation. Each collision callback subsequently reinstalls the shared damage/death and effect-hitlag callbacks, so local invalidation is not the final callback state of the caller. [Effect helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPopo/ftpopospecials.c#L54-L111)

### Partner lifetime and termination

Nana eligibility rejects numeric x2071 states 1 through 13 and requires a strict squared-distance comparison against an integer-cast scaled threshold. Successful initialization copies Popo's then-current position, velocity and facing and installs Nana's reciprocal reference before Popo assigns his new entry velocities. Nana uses numeric motions 359/360 here; these are not renamed solely from ordinal correspondence. [Nana initialization](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftNana/ftnanaspecials.c#L42-L154)

Popo's command-variable getter returns cmd_vars[1] through its bool signature and defaults to true for null object/Fighter input. His motion predicate has no null guard and returns false exactly for SpecialS2/SpecialAirS2. Nana uses the latter to continue frame synchronization; both predicates must be false for direct collision following. Otherwise Nana advances a trailing-offset counter capped at five and performs her own terrain query. [Nana animation consumers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftNana/ftnanaspecials.c#L166-L199), [collision consumers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftNana/ftnanaspecials.c#L270-L367)

Solo animation completion clears local callbacks/reference. Paired completion additionally resets model rotation, calls the common fighter flag helper for the linked objects and clears reciprocal references; it can trigger on Popo animation completion or Nana's state predicate. Aerial exits choose ordinary Fall when x70 is zero, otherwise call ftCommon_8007D60C followed by ftCo_80096900 with x70. The precise attribute meaning remains unrecovered. Interruption cleanup is dispatched through ftPp_Init_8011F060, installed for both damage and death2. [Termination](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPopo/ftpopospecials.c#L203-L301), [aggregate cleanup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPopo/ftpopo.c#L398-L404)
