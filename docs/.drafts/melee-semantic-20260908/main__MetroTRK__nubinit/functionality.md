## MetroTRK nub lifecycle

`nubinit.c` implements debugger bootstrap, a termination hook, welcome output, and runtime byte-order detection. The header declares all four functions and exports `gTRKBigEndian`. Inherited canonical/rendered coverage reports agreement, without function-name substitutions; the independent lead read likewise confirms unchanged names in the implementation.

- `TRKInitializeNub` initializes endianness, user output, event queue, message buffers, dispatcher, interrupt-driven UART, serial handler, and target state in order. Progress is guarded by `kNoError`; user-output initialization does not supply an assigned status. UART receives `0xE100, 1, 0, &gTRKInputPendingPtr`. The pointer setter runs before the UART status is checked, including on UART failure. Earlier initialization is not rolled back. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/MetroTRK/nubinit.c#L13-L56)
- `TRKInitializeEndian` interprets bytes `12 34 56 78` through a `u32*`. Recognized big- and little-endian representations return false and set the global accordingly. An unrecognized representation returns true while leaving the global at the true value assigned at function entry. The boolean is an error indicator, not the detected endianness or a separately established named error code. Inherited research establishes that `TRKTargetCPUType` subsequently copies the global into CPU metadata. [Producer](code://c302741689bd67c361cd7faadb221df3193992c3/src/MetroTRK/nubinit.c#L69-L90), [consumer](code://c302741689bd67c361cd7faadb221df3193992c3/src/MetroTRK/targimpl.c#L486-L496)
- `TRKNubWelcome` unconditionally passes `MetroTRK for Dolphin v0.8` to `TRK_board_display`. Inherited caller research establishes forwarding to `OSReport` and the successful-initialization guard in `TRK_main`, before the main loop. [Welcome](code://c302741689bd67c361cd7faadb221df3193992c3/src/MetroTRK/nubinit.c#L64-L67), [adapter](code://c302741689bd67c361cd7faadb221df3193992c3/src/MetroTRK/dolphin_trk_glue.c#L137-L140), [caller](code://c302741689bd67c361cd7faadb221df3193992c3/src/MetroTRK/main_TRK.c#L13-L23)
- `TRKTerminateNub` discards the serial terminator's result and returns `kNoError`. Inherited research establishes that the terminator is currently a successful no-op and that the caller invokes nub termination even after initialization failure, replacing its stored initialization result with the termination result.
