## Stage launch and boundaries
The reviewed Old Kongo controller owns timing. In occupancy state 1, a non-null retained object is subject to xCA-- >= 0: old zero still waits; a negative old value permits firing progression. State 2 initializes firing animation and hit_timer = 0, then falls through to state 3. The test hit_timer++ > 0xA uses the old value: 10 fails and 11 passes. Launch additionally requires retained fighter_gobj->p_link == 8. State advances to 4 even when that guard prevents launch, and state 4 later resets to 0. The state-1 null branch sets xC6 = 0 but has no break before case 2; consequently this code does not prove that a missing retained pointer safely cancels the entire firing path. Full retained-object safety remains unresolved. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/groldkongo.c#L390-L441.

The launch caller constructs an lbColl_80008D30_arg1 from stage attack parameters, derives an angle from pi/2 plus barrel rotation, applies at most one correction for values strictly below zero or strictly above tau, and multiplies by 57.29578f. Equality at tau is not wrapped. This establishes degrees for that caller, not a general normalization contract for arbitrary callers. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gr/groldkongo.c#L407-L429.

## Ownership and lifetime
Owned bodies allocate no persistent objects and free nothing. Object pointers are borrowed; position values are copied. Local float and hit storage are supplied synchronously to visible consumers, but complete deeper pointer-escape and temporary-hit layout safety are not established. The SmallerHitCapsule-to-HitCapsule casts do not themselves prove compiled size, alignment, alias compatibility, or initialization sufficiency.

Accessory1 is not guaranteed every frame: dispatch requires !x221F_b3, bypasses accessory1 when x2219_b5 is set, and checks the callback pointer before invoking it and copying cur_pos to joint translation. The installed death callback ignores its fighter argument and calls Ground_801C4E20, which dispatches by current stage. Old Kongo cleanup returns outside occupancy state 1 and conditionally clears its retained pointer inside state 1; complete destruction ordering and callback clearing remain unresolved.
