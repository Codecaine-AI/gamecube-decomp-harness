## Matrix construction
`HSD_JObjMakePositionMtx` forms view × joint, either directly or through full, vertical, horizontal, or Z-rotation billboard reconstruction. Other nonzero billboard-field values panic. Vertical and horizontal modes preserve the transformed Y and X axes respectively; full mode rebuilds all orientation axes. Translation and measured scale magnitudes are preserved for nondegenerate inputs, not arbitrary singular inputs. Cross-product magnitude divisions and the horizontal perspective branch's XZ-radius division are unguarded. See code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/displayfunc.c#L88-L243.

Skeleton search includes the supplied node and walks parents. Envelope correction returns NULL immediately for a skeleton-root input, otherwise asserts a skeleton was found and selects among three matrix constructions. Direct inverse status is ignored. The inverse-concat callee copies its source when its determinant test detects a near-singular matrix, so inverse-relative formulas need that qualification. The result enters rigid and weighted envelope matrix setup. See code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/displayfunc.c#L245-L276 and code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/mtx.c#L60-L157.

## Geometry dispatch and deferred lifetime
Single-node dispatch is distinct from hierarchy traversal in `jobj.c`. Geometry dispatch filters hidden and pass-ineligible joints, prepares the matrix, resolves a NULL view matrix from the current camera, and invokes virtual position/display methods. Eligible opaque work is immediate. Texture-edge and translucent work is immediate unless collection is enabled. The conditional collection branch allocates one record shared by both applicable class chains; it copies matrices and render mode but borrows the JObj pointer without acquiring a reference. See code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/displayfunc.c#L309-L367.

DObj coordination installs current-object contexts, initializes specular state only outside shadow rendering, clears polygon matrix marks, filters DObjs, dispatches their methods, and clears rather than restores the contexts. See code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/displayfunc.c#L278-L307.

The counted merge sort rewires a selected embedded link and compares `pmtx[2][3]` with `<=`. It is ascending and stable for ordered non-NaN keys; counts and offsets are trusted. Its base case includes negative counts. Sorting changes class heads and links but does not repair append pointers. Replay processes texture-edge before translucent, prefers a stored view matrix, and clears the batch afterward. Camera lookup happens even with empty chains. Both static control variables start at zero and have no enabling assignment in this TU; the guarded algorithms must not be mistaken for demonstrated active collection. See code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/displayfunc.c#L369-L477.

Clear frees matrix copies and records through the ownership chain, then resets heads, append pointers, and counts. Forget-memory ignores its range arguments and only resets bookkeeping, without dereferencing or freeing old records. Non-NULL camera activation clears the queue before installing the camera, even for the same camera; camera finalization sorts then replays. See code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/displayfunc.c#L599-L611 and code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/cobj.c#L485-L525.

## Particle dispatch
With a callback installed, marked particle descriptors invoke `(0, bank, offset, jobj)` and every visited descriptor is subsequently masked with `0x7fffffff`, clearing its trigger while retaining lower bits. Without a callback, descriptors are not rewritten. The game installs `efLib_Cb_SPtcl`, which routes bank `0x1E` separately and forwards numeric mode zero in either static path. See code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/displayfunc.c#L479-L503, code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/jobj.h#L16-L19, and code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ef/eflib.c#L994-L1003.

## Direct rendering and erasure
Direct initialization clears descriptor state and software caches, configures XYZ/F32 positions and RGBA8 colors, resets the software TEV cursor, forwards `rendermode | 0x28000000`, and selects matrix zero without loading it. The numeric augmentation is preserved without speculative bit names. See code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/displayfunc.c#L76-L86.

Erase-color configuration persists independently of drawing. Erasure is a no-op when all outputs are disabled. Otherwise it draws a quad with independent color, alpha, and depth write controls. Depth-enabled setup installs an all-0xFF Z8 replacement texture; depth-disabled setup disables texture generation, not TEX0 vertex submission. Both branches emit all four texture coordinates. Completion disables Z-texturing and invalidates HSD state rather than restoring previous GX state. Camera callers provide projection-derived bounds, not necessarily pixel coordinates. See code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/displayfunc.c#L505-L597 and code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/cobj.c#L34-L73.
