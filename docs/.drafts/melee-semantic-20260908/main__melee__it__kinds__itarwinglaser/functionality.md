## Construction and state dispatch

The six-entry table selects callbacks directly from stored type `xE38`: states **0/2** share delayed-launch horizontal behavior; **1/3** share directed-flight behavior; **4/5** have only the attached-child collision callback. The `UnkMotion` suffixes must not be interpreted as exclusive numeric state indices. [State table](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itarwinglaser.c#L36-L51), [state entry](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itarwinglaser.c#L333-L341).

`it_802E72E0` initializes both spawn-position fields from a supplied bone, with type-dependent depth, caller-provided facing and zero velocity. Successful allocation receives setup value 300. Type 0 hides its root model and independently attempts type-4 and type-5 child creation; type 2 has no children. Children preserve positive/negative absolute depth. Allocation failure returns NULL; child failure does not roll back the root. Other type values lack the handled variants' state-entry setup. [Constructor](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itarwinglaser.c#L131-L236).

`it_802E7654` computes a normalized bone-to-target vector, derives facing and model rotations, stores additional configuration in `xE48`, and enters the requested state after successful allocation with setup value 400. Crucially, canonical source initializes `spawn.prev_pos` but not `spawn.pos`, and its pointer-returning definition has **no return statement**. A nullable returned object must not be asserted as current behavior. [Directed constructor](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itarwinglaser.c#L238-L297).

## Updates and collision

Both animation callbacks snapshot `xE18` into `xE24` and call the lifetime decrement helper. The delayed family sets `xE30` only when its animation query returns zero; the directed family sets it unconditionally. Both are declared void and discard the helper's expiry result despite casts in the state table. Horizontal physics follows the retained source bone unless `xE30 == 1`, then assigns horizontal throw-speed velocity. Directed physics recomputes velocity from `xE0C` for types 1/3, scales Y/Z by an additional attribute, and adds a Corneria-specific X/Y offset; Venom adds none. [Updates](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itarwinglaser.c#L343-L448), [lifetime helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_2725.c#L458-L468).

Horizontal collision projects previous/current bone-index-4 endpoints to Z=0. A hit updates map-relative velocity, applies the returned endpoint's X displacement, emits effect `0x40E` and SFX `0x74`, and returns true. Directed collision is enabled only when **previous endpoint Z is strictly between -30 and 30**; its counter selects first-entry audio and then invokes `it_802E70BC`. That helper first checks stored `xE18` against a fresh bone sample, then falls back to four 200-unit cardinal probes, counting reverse hits only when map-line flag `0x100` is absent. The caller refreshes `xE18` immediately before invoking the helper, so this direct query must not automatically be described as a previous-frame sweep. [Collision paths](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itarwinglaser.c#L450-L510), [probe helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itarwinglaser.c#L53-L129).

## Relationships and interaction callbacks

Children continue only while their non-null parent reciprocally lists them in `xE40` or `xE44`. They copy bone-0 translation, scale and rotation while replacing Z with their stored depth. Destruction cleanup for types 0/2 clears local links and clears a child's parent pointer only when it still references that root. Child invalidation is deferred to its callback rather than implemented by direct child destruction here. The retained source-bone pointer has a separate lifetime requirement not resolved by those reciprocal checks. [Cleanup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itarwinglaser.c#L299-L331), [child callback](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itarwinglaser.c#L512-L545).

Canonical `ItemLogicTable` registration independently confirms destroyed, reflected and shield-bounced roles. It also establishes that `it_802E838C` serves **both damage-dealt and clanked**, `it_802E8418` is absorbed, and `it_802E8784` is hit-shield. The last two simply return true without inspecting the object. Reflection selects an existing owner/reflector pointer but does not transfer ownership. Types 0/2 reverse horizontal motion and reset endpoint history; types 1/3 only conditionally change facing. Shield bounce mirrors XY velocity, leaves Z unchanged, resets endpoint history and adjusts yaw only for types 0/2. Neither callback updates the directed vector `xE0C`; subsequent directed physics recomputes velocity from that unchanged vector.
