## Lifecycle and rendering

The pool descriptor is global HSD_ObjAllocData. Alloc creates a cleared shadow, camera, TObj and image descriptor with mapping(0.5,-0.5,0.5,0.5), intensity0 and256x256 dimensions. Backing pixels remain absent until SetSize. SetSize only reconfigures on absent/mismatched storage and frees old pixels before allocating; Init separately sets copy dimensions/format0x20. No local allocation-result guard follows the first pooled allocation or resize allocation.

Active is bool in the header, backed by typedef int bool in src/MSL/stdbool.h. Its truth value gates idempotence; a transition stores the integer request verbatim. Activation registers material texture independently of StartRender; material RENDER_SHADOW consumes the registry. Casters are pointer-unique prepended JObjs, referenced once; deletion unreferences before removing list nodes. Removal uses the exact ref_DEC sentinel convention and TObj virtual destroy without a local release call.

StartRender checks graph pointers and skips an empty caster list. It ignores camera activation failure, commits existing texgen count, configures no-blend PE state, fills white, then draws intensity-colored opaque/texture-edge casters inside a two-pixel inset. Only positive dimensions are enforced by SetSize, so width/height below4 are not excluded. Camera end occurs here. EndRender independently captures with clear=true, calls GXPixModeSync and GXInvalidateTexAll, then constructs texture mapping from the stored direct view. No empty-list/active/render-success guard or old-state restoration exists. Hardware completion is not inferred from the synchronization call alone.

## Projection and bounds

Perspective SetViewingRect computes vertical=max(abs(top),abs(bottom)), horizontal=max(abs(left),abs(right)); local names width/height are reversed relative to these axes. It stores aspect=horizontal/vertical and FOV=atan2f(horizontal,distance), with neither angle doubling nor radians-to-degrees conversion. CObj stores it unchanged; MTXLightPerspective later halves and converts degrees. This is observed source behavior, not a corrected fitting formula. Ortho forwards bounds; frustum scales all bounds by near/distance with positive-scale assertion.

ViewingRectInit normalizes forward and input up but does not normalize their cross-product right/corrected-up axes. Parallel/zero inputs are unguarded. AddRect rejects nonpositive center depth only in perspective mode, scales center and offsets by distance/depth, and expands extrema; non-perspective removes depth without scaling. Check verifies only strict positive width/height, not finite values or valid basis. Initial bounds are finite F32_MAX sentinels. makeMatrix stores projective texture coordinates in Mtx storage and does not refresh camera view.
