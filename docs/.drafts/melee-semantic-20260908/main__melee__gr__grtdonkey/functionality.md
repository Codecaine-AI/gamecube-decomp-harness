## Registration and initialization
`grtdonkey.c` defines the `Gr_Kind_TDonkey` stage descriptor using `/GrTDk.dat`; `grtdonkey.h` exports that descriptor. The callback array has three populated records for IDs 0, 1 and 2 followed by an all-zero fourth record. This establishes source declaration shapes, not compiled section composition or operational sentinel termination.

The initialization hook passes `grTDonkey_802202CC` to `Ground_InitTargetStage`. The shared inline clears `stage_info.unk8C.b4`, sets `b5`, requests IDs 0, 1 and 2 in order, ignores their return values, then calls four shared stage helpers. The local installer forms an unchecked ID-indexed callback address and retrieves the corresponding stage GObj. A non-NULL result receives shared setup; failure reports the filename, fixed diagnostic value `0xc3` and requested ID, then returns NULL. The common initializer continues after such a failure.

Shared setup clears Ground callbacks `x8` and `xC`, registers the display GX link, stores non-NULL `callback3`, invokes `on_init` synchronously, and schedules non-NULL `gobj_proc` at priority 4. It does not consume `callback1` or the callback flags. Consequently, table membership alone does not prove predicate installation or dispatch. ## Lifecycle and generator lifetime
Demo initialization and load are empty. The demo callback locally takes `bool`, whereas the shared descriptor field is spelled `void (*)(int)`; this review makes no ABI-size claim. The stage predicate returns false, `on_touch_line` returns NULL, and the shadow-render hook returns true regardless of its inputs. These are interface-local results, not claims that all dynamics are absent or every other rendering condition is satisfied.

The start hook requests `grZakoGenerator_801CAE04(NULL)` and ignores its nullable result. NULL is an absent spawn descriptor, not a substituted default descriptor. On successful GObj creation the callee schedules processing and stores the descriptor and prepared data in shared generator state, which outlives the local start call. On GObj creation failure it reports an error, frees the prepared data and returns NULL before those assignments. Descriptor-dependent spawning is guarded, while a separate numeric-kind branch exists; NULL therefore does not prove that all generator behavior is disabled. The reviewed noncoin removal path can access the descriptor when its item index is not -1, leaving cross-file reachability invariants for generator-owner review.
