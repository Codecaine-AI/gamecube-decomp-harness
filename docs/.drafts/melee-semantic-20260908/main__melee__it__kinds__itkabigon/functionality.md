### Effects and cross-file lifetimes

The accessory callback leaves its counter untouched while command variable 1 is zero. Otherwise it predecrements xE44 and emits effect 0x405 only on an exact-zero result, then reloads from special attribute x14. A nonpositive starting counter is not treated as immediate expiry. The effect helper makes two successive shared-PRNG calls, applies `2.0F * x18 * r - x18` separately to a local position's x and y, preserves z, and submits one spawn request. The source does not establish the effect's visual identity, validate the radius, or guarantee allocation success. [Accessory](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itkabigon.c#L119-L132), [effect helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itkabigon.c#L212-L225)

Accessory lifetime is bounded by shared state changes: `Item_80268E5C` clears on_accessory and hitlag callbacks. State-0 entry installs the accessory afterward; state-1 entry reinstalls hitlag callbacks but not the accessory. Thus the recurring ascent effect does not persist into state 1 merely because command variable 1 remains nonzero. [Shared callback reset](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/item.c#L1229-L1236)

An empty local physics callback does not disable generic position integration or boundary destruction. With b3 enabled and mask 0xE, the shared item system retains right, left, and bottom destruction checks while excluding its bit-1 high-Y check. Consequently, the animation callback's lower-boundary true return is not the actor's only possible termination route. [Generic movement and destruction](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/item.c#L1321-L1378)

Destruction unconditionally clears the global Small-quake remaining-frame counter; it neither consumes the item argument nor explicitly stops Medium quakes. The object-reference event adapter independently clears matching owner/interaction references through the common helper and discards its owner-match result.
