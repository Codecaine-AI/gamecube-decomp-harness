## Selection, completion and boundaries
The local `getAnimID` draws HSD_Randi(100)+1, starts count at zero, walks until u.i.x == -1, adds u.i.y, and returns the first entry whose cumulative count meets or exceeds the threshold. Crucially, the return expression is `(enum_t) wait_data->u.p.x`, not a pointer dereference or literally u.i.x. The source relies on union representation and pointer-to-integer conversion; portable or compiled equivalence is not established. HSD_Randi scales a 16-bit RNG result using integer arithmetic, giving a threshold of 1..100 here, not a proof of perfectly uniform independent percentages. Each retry advances shared RNG state. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftwaitanim.c#L47-L60; code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftwaitanim.h#L6-L17; code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/random.c#L3-L21.

Weights are neither normalized nor validated. With nonnegative, nonoverflowing weights, cumulative coverage reaching at least 100 suffices for every threshold; exactly 100 is unnecessary. Zero weights add no selectable interval. Totals above 100 truncate later intervals; totals below 100 can fail depending on the draw. Negative weights are accepted arithmetically without validation; signed overflow has no defined source-level recovery. An empty terminated table asserts. A missing terminator can permit an out-of-bounds traversal if no earlier entry is selected. Exhaustion invokes HSD_ASSERTREPORT with condition 0 and `wait anim data illegal!!\n`. The threshold is an extra OSReport argument but the message has no conversion to display it. The macro calls noreturn __assert, with diagnostic line 86 under MUST_MATCH and __LINE__ otherwise. Literal storage and section assignment are unproved. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftwaitanim.c#L47-L60; code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/debug.h#L11-L32.

`ftCo_8008A7A8` does no installation or selection while ftAnim_IsFramesRemaining returns true. Otherwise a null table, or any held item on a fighter other than Mewtwo and Fox, invokes the installer with the current ID and returns. This tests item presence, unlike the separate hold-kind predicate. Current ID -1 therefore skips installation. In the weighted branch, it repeats selection while the result equals the current ID unless the current ID is 2 or 31. Those are numeric repeat exceptions only; their visual meaning is unresolved. There is no retry cap: a table whose reachable selections all equal a disallowed current ID can loop forever. Selected installation is a manually duplicated equivalent of ftCo_8008A6D8, with the same ordering and resource/sentinel guards. A source comment attributes duplication to matching requirements, not different functionality. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftwaitanim.c#L39-L105.

Completion is delegated rather than derived locally from a duration. ftAnim_IsFramesRemaining scans eligible parts and checks joint or x4_jobj2 according to x8A4_animBlendFrames == 0. Both signed zeros select the first branch; NaN, infinities and other nonzero values select the alternate branch under ordinary source comparison semantics. There is no local sanitization. Deeper lb_8000B074/AObj exceptional-frame behavior is not established. Evidence: code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftanim.c#L515-L538.
