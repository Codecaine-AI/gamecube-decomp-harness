### Initialization and storage
`DEMOInit` initializes OS, DVD, VI and pad support, selects a render mode, reserves framebuffer memory, allocates a 0x40000-byte GX FIFO and initializes GX/VI. A supplied render-mode pointer is retained directly rather than copied; its storage must remain valid while used. With no supplied mode, NTSC/PAL/MPAL defaults are adjusted for overscan into static storage; other TV formats panic. Two framebuffers are aligned to 32 bytes, using a width rounded to 16 pixels and two bytes per pixel. Ordinary heap creation is bypassed for the exact console/memory predicate at line 85, which invokes `LoadMemInfo`. ### Frame lifecycle
GX setup configures viewport, scissor, display-copy dimensions, scaling and filtering; the pixel-format arguments depend on antialiasing. VI initially selects buffer 1 while buffer 2 is the copy destination, and waits an extra retrace when `viTVmode & 1` is nonzero. `__DEMOInitForEmu` is empty. Before rendering, the code optionally emits sync token 0xFEEB, chooses a field-jittered or ordinary viewport and invalidates vertex/texture caches. Normal completion optionally updates and prints externally controlled statistics, enables depth/color writes, copies and waits for drawing before swapping. Swapping unblacks only on the first swap, waits for retrace and changes the destination buffer. The first-frame flag is not reset by either initialization routine. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/demo/DEMOInit.c#L99-L180)

### TEV helpers and accessors
`DEMOSetTevColorIn` rewrites extended texture-channel inputs to `GX_CC_TEXC`; the last qualifying input in a/b/c/d order determines the texture swap selection. If none qualifies, existing swap state is untouched. `DEMOSetTevOp` handles numeric modes 0–4 with explicit color/alpha tuples, distinguishes stage zero from later stages, asserts for an invalid mode and then sets common color/alpha operations. The unusual `GX_TEVSTAGE5` initializer for an alpha argument is preserved as source evidence, not interpreted as a stage selection. Accessors return the retained render-mode pointer and current destination-buffer address. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/demo/DEMOInit.c#L182-L261)

### Bypass timeout and recovery
Enabling the workaround installs a pre-retrace callback that increments `FrameCount`; no callback restoration or disable path appears here. Bypass completion skips the normal statistics and depth/color setup, copies the display, emits token 0xB00B and polls it against a retrace-count threshold. A zero threshold permits immediate recovery if the token is not yet observed. Timeout reports a warning and calls `DEMOReInit`; buffer swapping still occurs afterward. Reinitialization allocates a temporary 0x10000-byte FIFO, captures the current CPU FIFO base/size, aborts the frame, temporarily binds the local FIFO object, calls GX initialization using the captured storage, reconfigures GX/VI and frees temporary storage. It does not reallocate framebuffers; internal GX pointer-lifetime guarantees are outside this file's evidence. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/demo/DEMOInit.c#L263-L311)

### Memory-info exceptional path
Missing `/meminfo.bin` produces reports and ordinary heap creation. When present, the arena high bound is expanded to cached physical-memory end, a heap is created, and fixed allocations reserve the old arena-high-to-simulated-end interval plus file-provided start/end ranges. Logical chunks are at most 32 bytes, DVD read lengths are rounded to 32 bytes, and only complete eight-byte entries are processed; trailing partial entries are ignored. Negative reads panic. Successful completion closes the file and dumps the heap. No file-range validation or allocation-result checks are visible here.
