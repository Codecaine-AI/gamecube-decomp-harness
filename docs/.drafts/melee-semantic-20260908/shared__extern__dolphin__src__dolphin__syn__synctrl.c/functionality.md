## synctrl.c semantic review

This file implements synthesizer MIDI controller state, program selection, note allocation/release, pitch-wheel conversion, and buffered event dispatch. All 429 canonical and rendered lines were reviewed. The renderer reported no parse errors or name substitutions. Subject and link enumerations were empty, so there is no baseline knowledge to retain or correct and no proposed mutation.

### Controllers and programs
- RPN selection is assembled as `(controller[0x65] << 8) + controller[0x64]`. RPN 0 sets pitch range to `(controller[0x26] + 100 * controller[6]) << 16`; RPNs 1–4 have unsupported assertions, and other values receive no action. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synctrl.c#L49-L77)
- Program changes select the percussive instrument table for channel 9 and the melodic table otherwise, then add the program index. Channel release and clear-all request release and remove key mappings; they do not explicitly free AX voices here. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synctrl.c#L100-L138)
- Controller writes first store the byte, then optionally update attenuation, data entry, sustain, RPN selection, note release, or reset state. Controller 0x79 chooses the preserving reset for value zero and the default reset otherwise. Both resets zero controller bytes and pitch offset, restore pitch range to 0xC80000, and reset auxiliary attenuation. The preserving reset restores volume/pan/expression; the default reset sets these to 100/64/127. Neither explicitly resets the separate RPN flag nor invokes sustain-release handling while clearing controller bytes. Reset-all also selects program zero on every channel. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synctrl.c#L140-L255)

### Note behavior and lifetime boundaries
- Pedal values below 64 release held mapped voices; note-off holds a voice only when the stored pedal value is greater than 64. Exactly 64 therefore neither flushes previously held voices through the pedal handler nor holds a newly released note. This asymmetric boundary is preserved rather than normalized to standard MIDI expectations. [Pedal handler](code://c302741689bd67c3617faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synctrl.c#L79-L98) [Note-off](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synctrl.c#L257-L273)
- Nonzero-velocity note-on releases/unmaps an existing same-key voice before attempting AX allocation. Allocation failure leaves no replacement. Successful wavetable lookup installs the new voice and increments the note count; nonzero key-group replacement explicitly detaches and frees the old group's voice and decrements the count. Wavetable lookup failure detaches and frees the newly acquired voice. Zero velocity delegates to note-off. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synctrl.c#L275-L351)
- Successful setup initializes pitch, volume, pan, LFO, envelopes, mixer, sample and SRC; channel 9 uses voice pan while other channels use controller pan. It writes AX state 1, ORs sync with 4, and sets note-on priority. Those numeric fields are not assigned stronger enum meanings here. Final release cleanup and allocation-callback behavior are cross-file responsibilities, not established by unmapping in this file. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synctrl.c#L287-L346)

### Input processing
Pitch-wheel input forms a 14-bit position centered at 8192 and scales the configured range by position/8192. Dispatch handles status nibbles 8, 9, 11, 12 and 14; other cases have no dispatched action. The buffer runner consumes fixed three-byte records, decrements the pending count to zero, and resets the input position. The public getter returns the stored controller byte. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synctrl.c#L353-L429)

The source also defines a 128-entry fractional float table; its section comment is not compiled-layout evidence. No compiled section or layout conclusions are made. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/syn/synctrl.c#L9-L33)
