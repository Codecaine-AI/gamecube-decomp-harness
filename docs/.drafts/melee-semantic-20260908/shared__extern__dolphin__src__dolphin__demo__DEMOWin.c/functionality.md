### Windows and text
Initialization resets the window-list pointers and obtains the render-mode pointer. Creation allocates a window and space-filled circular text buffer, retaining the supplied caption and refresh callback rather than copying them. Destruction unlinks and frees the window and buffer using the current heap; opening and closing only change the opened flag. Logging advances both output and view positions on newline or wrapping. Positioned output addresses visible rows; clearing a window clears only visible rows, whereas clearing its buffer clears all scrollback storage. Scroll tokens 0, 1, and 2 respectively reset to output, move backward within the ring boundary, and advance toward output. Both formatting routines use unbounded vsprintf into 128-byte local arrays; the source does not establish general formatting safety. ### Rendering and ordering
BringToFront and SendToBack manipulate priority values, not linked-list order. Refresh traverses opened windows, emits background/caption/border geometry, calls each refresh callback, then draws circular-buffer text, caption text, and an optional cursor highlight. Priority is supplied as vertex depth. The fixed-count glyph helper emits one textured 8-by-8 quad per character using character-minus-0x20 atlas indexing and fontShift. List deletion updates neighbor/end pointers but does not repair __curr_node. These are source-level observations, not compiled section or layout claims. ### Menus and recursive lifetimes
Menu construction scans items until flag 0x80000000, measures labels/title, caps displayed items, and associates the caller-owned menu with a newly allocated window. Even an empty menu receives a window before construction returns NULL. The modal loop resets selection, invokes callbacks, renders repeatedly, and wraps navigation while skipping items masked by 9. Input 3 cancels only when child_flag equals 1; input 6 exits regardless. Input 4 invokes cb_move and may enter a child; input 5 invokes cb_select and enters a child or invokes an item function. Child flag 1 propagates exit; item flag 0x10 causes exit after its function. Existing child windows have only x1/y1 relocated, while absent child windows are created and destroyed around recursion. Destruction does not null the stored handle. Navigation has no escape when every item is skipped. Menu refresh uses flag 4 for an X, flag 1 for parentheses, and flag 8 for a distinct label-only row. ### Controller input and lists
Pad reading combines buttons with strict stick thresholds beyond ±64 and trigger thresholds above 128 for four controllers. changed_button records rising bits, not all transitions. Repeat timing is shared by the entire controller bitmask: changing the mask restarts its counter. Defaults emit immediately at count 1 and subsequently at counts 17, 19, and so on; the setter accepts a zero rate without validation. Menu input consults controller zero in directional precedence order, followed by rising masks 0x100 and 0x200; numeric masks are preserved without asserting external enum definitions. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/demo/DEMOWin.c#L720-L812)

List construction likewise allocates before returning NULL for zero items and retains the caller-owned list through parent. Destruction leaves its handle unchanged. Refresh normalizes selection modulo item count, tracks the visible range, optionally highlights the cursor, and leaves flag-8 rows blank. Scrolling clamps the selection into the viewport; cursor movement wraps independently. Empty-list modulo operations and zero-sized display arithmetic are not guarded here.
