## State and invariants

There are eight regular hardware slots and one ambient slot. SetupInit resets masks and active state and reads cobj->view_mtx directly. Its first pass selects visible supported lights, retaining first ambient, then scans remaining nodes for ambient if needed. A second pass allocates spare specular IDs for combined diffuse/specular lights; it does not explicitly check active membership. Indexed loads stop at the first empty slot.

AddCurrent orders by the u8 getter, despite u16 storage. Deleting a registration clears matching active pointers but does not decrement the count, compact slots or clear masks. SetupSpecularInit trusts every pointer below the count and has no NULL or zero-vector normalization guard. SetCurrentAll registers one object; the inferred ReplaceAll wrapper registers the whole next-chain. Neither global removal nor replacement resets masks.

Raw point setup writes neutral angular and raw radial coefficients only to the primary GX object. Derived point/spot distance attenuation reaches both objects; spot cone shaping reaches the primary. Specular helper assigns spec_id even when zero; nonzero initializes shininess 50, coefficients (0,0,1,25,0,-24), transformed position/direction, dirty bit and mask.
