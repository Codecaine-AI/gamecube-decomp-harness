## Manual and automatic spawning

Unmodified pressed Down attempts the selected item above the player, not the selected Pokémon directly. The local SpawnItem is only partially filled. Common-item checks use common count; the additional CZako threshold applies to every kind below Octarock_Stone, including common kinds. The availability table gates Old_Kuri through pre-Arwing_Laser. M_Ball is Poké Ball, not Maxim Tomato. Successful creation ORs the global collision mode and emits effect420.
