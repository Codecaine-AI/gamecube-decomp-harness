# AXDriver semantic review

## Responsibilities and lifetimes
The unit manages 96 logical `HSD_SM` script records, separately from a 64-entry synth-instance lookup. Sound creation resolves a decimal bank-qualified ID, reserves a record, installs its command stream and defaults, and returns a generation-qualified logical handle. Actual synth playback is deferred to command processing. Bank/sample validation contains upper-bound checks but no general negative-ID protection. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/axdriver.c#L521-L617)

Key-off clears the driver mapping and state immediately; the master-clock callback subsequently returns inactive records to the free list. Synth-side ordinary key-off instead schedules volume processing, while flag-8 nodes release voices immediately. The diagnostic PVoice counter counts mapped synth instances, not individual AX voices; one synth instance can own two hardware voices. VVoice counts allocated logical records, including records awaiting reclamation. ## Sequencing and controls
The interpreter extracts opcode-dependent delays, commits pending operations before nonzero delays, updates the scheduled tick, and processes the command operand. Backward branches use a word displacement and a counted or sticky indefinite-loop condition. Opcode 14 requests sleep; opcode 15 invokes shared key-off retirement, not a record callback. Pending bit `0x10` has no synth action. Opcodes 20/21 change routing scale bytes without themselves marking the mix dirty. [Interpreter](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/axdriver.c#L179-L438)

Pan and volume setters delegate to synth for assigned voices and cache values before voice creation. The misleading synth name `HSD_SynthSFXSetUserVol` does not invalidate the driver's pan interpretation: its byte feeds stereo gains and ITD. Secondary pitch is expressed in cents despite the record field name `fadetime`. Pausing an assigned ordinary synth instance reaches the driver timing callback after volume-ramp completion. For a record with `x30 == -1`, initial deadline assignment takes precedence over pause compensation. [Setters](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/axdriver.c#L619-L695) [Pause completion](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/synth.c#L966-L984)

## Auxiliary effects
External per-sound send setters require the selected low override bit in `AXDriver_804D603C`; corresponding script commands require that bit clear. These bits are independent of the effect-type nibbles. The channel setter attempts updates to matching current records, ignores failures, and always saves the default after valid channel/bus checks. Its proposed name is sharpened to `HSD_AudioSFXSetAuxLevelChannel`. [Send controls](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/axdriver.c#L697-L775)

Effect replacement unregisters the selected callback, records the requested type, shuts down the old effect, copies caller settings into persistent driver-owned state, and initializes the replacement. Failure leaves the requested type recorded with a null callback; there is no rollback. The allocator is a shared byte cursor into caller-owned work memory, uses a strict post-increment capacity assertion, and has a no-op free hook. Defaults and heap sizing are separate operations. [Replacement](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/axdriver.c#L915-L1145)

## Metadata and streamed audio
The metadata loader reads one image, publishes five count/table sections, and relocates three pointer tables in place. DVD result `-1` leaves its callback-pumped wait pending; the zero-length branch returns without closing the opened file. Unload frees and nulls only the image owner, leaving derived counts and pointers unchanged. Language-selected `smash2.sem` replacement is coordinated by higher-level audio code. [Loader](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/axdriver.c#L796-L913) [Replacement caller](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbaudio_ax.c#L1897-L1949)

The separate singleton stream path converts a DVD pathname, replaces the retained synth handle, and returns true unconditionally on normal return. Pause/resume check only the `-1` sentinel, not liveness. Status queries are observational; the synth predicate can accept an unflagged node with zero attached voices.
