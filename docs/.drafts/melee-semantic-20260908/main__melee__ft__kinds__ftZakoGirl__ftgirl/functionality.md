### Item branches

Pickup and drop forward the incoming object and bool unchanged, with two additional false arguments. Invisible and visible wrappers pass the object and false. The shared pickup handler skips heavy items. For other items, hold kinds 1, 2, 3, and 4 call `ftAnim_80070FB4` with respective numeric selections 1, 0, 2, and 3; other kinds perform no selection call. Independently within that non-heavy branch, a true incoming pickup flag calls `ftAnim_80070C48`. Invisible and visible handlers also skip heavy items, otherwise calling `ftAnim_80070CC4` and `ftAnim_80070C48`, respectively. Drop has no heavy-item guard: it always calls `ftAnim_80070FB4` with selection -1, then conditionally calls `ftAnim_80070CC4` if the incoming drop flag is true. False configuration arguments therefore do not disable the entire operation. These numeric selections are preserved without assigning unverified item-category names.
