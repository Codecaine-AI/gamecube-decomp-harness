## Challenger Approaching presentation

This unit implements the Approach scene's construction, animation, delayed acknowledgement, and teardown. The header exposes only the three public lifecycle callbacks. Canonical cross-file evidence connects its payload to challenger data and places GS_APPROACH before the versus state whose successful result unlocks the challenger; this mapping does not depend on rendered proposed names. See [mode integration](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1BFA.c#L26-L120).

### Construction and entry

`gm_801ADB04` loads `NtAppro` and `ScNtcApproach_scene_data`, retaining the archive handle in `gm_80480D98.x0`. It creates camera, light, and model GObjs. The camera uses the first camera descriptor and GX priority mask `0x4801`; the light uses the descriptor's light collection; the model uses the first model descriptor, GX link `0xB`, frame-zero initialization, and `fn_801AD920` at process priority 1. No local allocation or descriptor failure checks are present. [Constructor](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmapproach.c#L91-L121).

Entry constructs the scene before initializing its private selection and counters. It interprets the opaque argument through `s8*`: byte 0 selects the challenger and byte 1 is copied into the unsigned controller-index field without validation. Accepted fighter values are `3,7,9,10,15,20,21,22,23,24,25`; every other input becomes 25. It clears all three u16 counters and requests audio index `0x48`. The audio implementation routes this index through HPS filename lookup; playback is conditional on the helper's filename checks, rather than an unconditional restart. [Entry](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmapproach.c#L133-L153), [audio helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbaudio_ax.c#L397-L435).

### Animation

`fn_801AD920` follows the root's first child and its next two siblings. Counter x8 increments when its old value is at most 300, reaches 301, then resets to zero on the next process call. Counter xA increments only below 300 and saturates there. The first subtree receives x8; the next two receive xA. Fighter values `3,7,9,10,15,20,21,22,23,24,25` map respectively to texture frames `1..11`; the switch's independent default is frame 0. Entry's fallback therefore normally selects frame 11, not frame 0. The third subtree's texture animation is requested at the selected frame, its AObj rate is set to zero, and the root hierarchy is evaluated. Although traversal uses null-aware intermediate expressions, the later texture chain is dereferenced without guards: this is not a null-safe callback. [Complete animation callback](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmapproach.c#L29-L89).

### Acknowledgement and transition

The frame callback post-increments u16 xC and tests its old value against 180. Starting from entry's zero, calls 1 through 180 short-circuit before accessing controller input; call 181 is the first eligible call. An A or Start trigger from the saved controller calls `gm_801A4B60`. The counter does not saturate: after old value 65535 it wraps to zero, and the next 180 calls again skip input. There is no automatic timeout or local acknowledgement latch. The canonical callee writes scene-loop state 1; state 2 has a separate setter and a distinct loop branch. Thus this is a scene-exit request, not a direct unlock operation or a locally selected destination. [Frame callback and initialization](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmapproach.c#L123-L153), [state setters](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L170-L178), [scene loop](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L264-L378).

### Lifetimes and teardown

The private singleton retains presentation state between callbacks. Exit ignores its argument, releases the saved archive, then stops audio and clears audio bookkeeping. It does not clear the stored pointer or explicitly destroy GObjs; framework object-teardown ordering is not established by this unit. Archive release asserts a nonnull archive and the required flag before freeing the data allocation and header, so exit is not proven safe for failed initialization or repeated calls. [Exit](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmapproach.c#L155-L159), [archive release](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbarchive.c#L147-L153), [audio stop](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbaudio_ax.c#L207-L213).

The separate `gmVsMelee_ApproachData` has cross-file payload semantics despite its owned declaration as `UNK_T[2]`. The challenger mode registers the same object for enter and exit data, and its producer copies challenger kind and human slot into `VsApproachData`. That structure declares two u8 fields, whereas the scene consumes them through signed-byte reads. This establishes the used payload prefix, not reconciliation of the conflicting declarations or the allocation's compiled size. [Owned declaration](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmapproach.c#L18-L27), [payload type](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/types.h#L1029-L1032), [registration and producer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1BFA.c#L26-L73).

### Evidence limits

Both owned files were read completely in canonical and rendered form. Rendered substitutions were treated as hypotheses, not independent proof. No compiled artifacts were supplied: exact section membership, switch lowering, numeric conversion pools, allocation sizes, alignment and padding remain unresolved. The exact silhouette/portrait asset contents and named identity of audio index 0x48 were not independently established. Historical parameter identities were enumerated without merging or normalizing them.
