# Synthesis

The Target-stage descriptor binds three active rows plus a null row to a shared target initializer. Row2 is the flagged row and invokes library update before Ground update. Empty predicates/hooks add no mechanic. Shared inline setup order is0,1,2; callback1 is not consumed. Joint/animation callee internals and Zako behavior remain external. Generic inherited aliases are collision-prone and are not promoted.
