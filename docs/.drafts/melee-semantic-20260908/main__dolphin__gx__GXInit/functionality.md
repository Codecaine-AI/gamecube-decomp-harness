## GXInit semantic review

This translation unit implements GX startup in two phases. `GXInit(base, size)` maps the PI/CP/PE/MEM register interfaces, initializes the library-owned `FifoObj` from caller-provided memory, installs that descriptor as both CPU and GP FIFO, initializes the pixel engine, and enables write gathering. It seeds software register shadows, emits baseline hardware commands, derives timing register values from `__OSBusClock`, constructs texture/TLUT regions, selects TMEM configuration 0, calls `__GXInitGX`, and returns `&FifoObj`. There is no once-only guard; this does not establish that repeated initialization is safe. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXInit.c#L74-L218)

`__GXInitGX` selects NTSC, PAL, or MPAL defaults using `VIGetTvFormat`. The exceptional branch invokes an assertion and then assigns the NTSC mode if execution continues. It establishes identity transforms, viewport/scissor, geometry and lighting defaults, one texture generator and one replace-mode TEV stage, direct TEV settings, disabled indirect stages/fog/blending, pixel/depth state, display copying, direct-poke state, and cleared performance metrics. Viewport height uses `xfbHeight`; scissor and initial copy source/destination height use `efbHeight`, followed by an `xfbHeight / efbHeight` copy scale. Pipeline dithering is enabled whereas poke dithering is disabled. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXInit.c#L220-L371)

The default texture callback ignores the texture-map argument. C4/C8/C14X2 select the four-entry CI pool; all other formats select the eight-entry ordinary pool. Each call post-increments only the relevant cursor and masks its old value to select an entry. This is rotating selection, not occupancy-aware allocation, and does not explicitly reduce the stored cursor modulo the pool size. The initializer resets both cursors and registers the callbacks. [Selection](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXInit.c#L46-L55) · [Registration](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/gx/GXInit.c#L292-L296)

The TLUT callback performs a read-only lookup for unsigned indices 0–19 and returns NULL otherwise. Initialization creates sixteen regions using raw size argument 16 and four using 64; these numbers should not be described as byte or palette-entry counts without interpreting `GXTlutSize`. `GXLoadTlut` asserts that the callback result is non-null, then issues load commands, updates the palette offset, and copies the loaded descriptor into the persistent region. There is no ordinary error-return branch protecting the subsequent dereference when assertions are absent. Static `gxData`, the initialized `gx` pointer, register-pointer globals, and `FifoObj` provide persistent source-level state. Returned region pointers refer into that shared context, not temporary initializer locals. DEBUG additionally initializes verification state and installs a reporting callback. The write-gather helpers manipulate HID2 bit `0x40000000`; the assembly query synchronizes and returns WPAR bit 0 without inversion. No additional interpretation of that bit is asserted here.
