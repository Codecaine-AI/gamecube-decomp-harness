# Ground-library semantic review

`grlib` supplies shared stage services rather than a single stage controller:

- **Particle creation:** positioned creation ensures an AppSRT, copies translation, multiplies existing scale axes by the stage scale, and clears generator-local position. Generator or required-AppSRT failure returns NULL; the latter requests generator cleanup first. Joint-based wrappers preserve the resource-argument permutation. The mode dispatcher chooses managed-list creation for zero and standalone creation for nonzero; bank `0x1E` routing belongs to its effects-library callers, not an internal bank guard.
- **Particle retirement:** ordinary removal and explicit `type |= 0x80` removal are distinct. The generator manager may defer reclamation for live children or qualifying shared AppSRT dependencies. Exact-JObj cleanup saves each successor before removal. Recursive cleanup processes the current node before respecting the instance boundary and does not visit the original root's siblings. Stage callers demonstrate retained handles and cleanup at effect-cycle or object-lifetime boundaries.
- **Position cache:** four resolver calls refresh shared static vector storage in order, ignoring resolver results. Missing positions 1–3 fall back to position 0; unresolved position 0 can leave old cache contents intact. The returned pointer permits persistent cinematic overwrites. The indexed accessor copies entries 0–3 without refreshing and asserts for other selectors. Battlefield and Green Greens apply these cached positions to stage joints.
- **Dynamics:** setup constructs a pooled JObj child chain and then copies authored parameters unconditionally. Allocation failure does not prevent the second call, so partial construction is not a safe fallback. Release recycles nodes and clears the descriptor's data pointer. Update supplies the default stage preset, with explicit collider/floor/ground options disabled; global interaction forces can still apply. Castle and Rainbow Cruise demonstrate flag-dynamics use.
- **Camera quake:** `CmQuakeKind` values Loop/Small/Medium/Large (1–4) select animations 0–3. Invalid kinds and missing model sets return NULL; allocation results are not guarded locally. Both callbacks animate the hierarchy and apply root XY translation to the camera. The finite callback captures the root AObj before animation and requests GObj removal after the camera update when that AObj is absent or has `0x40000000`. Only Loop is explicitly configured with `AOBJ_LOOP`.
- **Shared counter:** the x708 getter/setter support the Zako trophy-drop throttle. Advancement occurs only on calls passing mode and random gates, not every frame. Successful creation sets one; eligible nonzero states increment or reset at the threshold. Failed selection or creation leaves zero unchanged.
- **Stage motion:** Rainbow Cruise, Big Blue and Icicle Mountain select specialized providers. True reports provider applicability, not nonzero motion or successful state lookup. Other stages receive zero and false. Item physics conditionally refreshes the vector and adds stored displacement to position.
- **Occupancy:** a read-only, fighter-first query tests inclusive XY rectangles derived from ECB extrema and current position. The signed offset adjusts both half-extents; Z is ignored. Items are excluded specifically when their kind is `It_PKind_Random`. The definition spells its return type `bool`, whereas the header spells `int`.
