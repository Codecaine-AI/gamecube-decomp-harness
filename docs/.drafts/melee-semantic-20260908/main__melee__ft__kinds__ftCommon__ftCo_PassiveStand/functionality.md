# PassiveStand translation unit

## Scope, identity, and review reconciliation

This unit implements directional ground-recovery entry and the shared lifecycle callbacks for PassiveStandF and PassiveStandB. The complete implementation and header were independently read in canonical and rendered form. The librarian's principal corrections are corroborated: this is not the separate in-place Passive callback family; animation completion is not universally a simple grounded Wait transition; high-speed friction is multiplied, not proved stronger; and source literals do not prove a .sdata2 layout.

Canonical names remain ftCo_80098928 and ftCo_800989D4. The rendered aliases ftCo_PassiveStand_CheckInput and ftCo_PassiveStand_Enter are useful inferred names, not recovered canonical symbols. Likewise, rendered external aliases do not establish callee semantics. The earlier static declaration gives ftCo_800989D4 internal linkage. The guarded header exports the boolean gate and four void callbacks, but not the private entry helper. Address-like comments are not compiled-address evidence. ## Input gate and boundaries

ftCo_80098928(Fighter_GObj*) obtains Fighter through gobj->user_data and calls ftCo_800986B0. That prerequisite succeeds only when ftCo_800C5240 is false, fp->x680 < common x250, and fp->x684 >= common x1C. Only after success does this unit require ABS(left-stick X) >= common x254. Equality fails the x680 bound but passes the other two bounds. Configured values and timing units are not established. Accepted input selects PassiveStandF when stick X times facing_dir is >= 0, and PassiveStandB otherwise. The helper executes before true is returned; failed guards return false without local motion entry. This is a state-changing input predicate, not a pure query or an input-bit-clearing function. [Gate](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_PassiveStand.c#L22-L35), [prerequisite](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_DownAttack.c#L87-L96).

ABS is conditional negation. Under ordinary IEEE comparison semantics, NaN stick magnitude or threshold fails the magnitude guard. An accepted input whose direction product is NaN selects B because >= is false. Both signed-zero products select F; zero input can pass a zero or negative threshold. Infinities are not explicitly rejected, and infinity times zero can yield an unordered product. Facing normalization, finite input, and ordinary controller ranges are not locally validated. These are source-level observations, not compiled floating-point-mode proof. [Macro](code://c302741689bd67c361cd7faadb221df3193992c3/src/Runtime/platform.h#L198-L198), [comparisons](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_PassiveStand.c#L25-L30).

## Entry and side effects

ftCo_800989D4 first invokes ftCommon_8007D7FC only for GA_Air. It then calls Fighter_ChangeMotionState(gobj, msid, Ft_MF_None, 0, 1, 0, NULL), whose scalar parameters are animation start, speed, and blend. The private helper does not validate msid; its local caller supplies only PassiveStandF/B. Next it calls ft_800881D8 with fp->ft_data->x4C_sfx->x24,127,64; ft_PlaySFX with 3,127,64; and ftCo_SpawnEf with the TopN joint,1,1053. These are ordered subsystem requests, not a guarantee that particular audible or visible assets are produced. The recovery-sound label and precise asset meanings remain unresolved. [Entry](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_PassiveStand.c#L20-L47), [motion signature](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/fighter.h#L44-L48).

The grounding delegate includes optional knockback/reporting work and a jump-count-dependent call. It then optionally derives horizontal velocity from translation, calls a clamp helper, sets GA_Ground, copies horizontal self velocity to ground velocity, resets jump/wall-jump fields and a flag, unlocks ECB, and asserts if the ground reference is invalid. Thus successful entry assumes valid subsystem state and normally returning callees; it is not unconditional for arbitrary objects or missing floors. [Grounding](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftcommon.c#L546-L594).

## Active consumers and lifecycle

The active motion table assigns this same Anim/IASA/Phys/Coll set to PassiveStandF and PassiveStandB, using distinct submotions and common Passive flags. The separate Passive entry has separate callbacks. Directional ground-tech/tech-roll mapping is supported jointly by the facing-relative selection, the active table, and damage-collision recovery callers, not by a numeric enum or the word Stand. Damage recovery chains and the inspected DamageIce helper try ftCo_80098928 before ftCo_8009872C, then fall back to ftCo_80097D40. [Table](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftmotionstates.c#L2323-L2355), [damage callers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Damage.c#L1221-L1245), [DamageFlyRoll collision](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_Damage.c#L1288-L1305), [DamageIce helper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_DamageIce.c#L53-L58).

Anim calls ft_8008A2BC only when ftAnim_IsFramesRemaining returns false. The query scans eligible parts with flags_b1 set and flags_b0/flags_b5 clear. It tests ordinary joints when blend frames equal zero and secondary joints otherwise; NaN blend frames follow the latter branch. No qualifying true joint query yields false. No local timer is maintained. [Anim](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_PassiveStand.c#L49-L54), [animation query](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftanim.c#L515-L538).

The completion dispatcher routes Master Hand and Crazy Hand separately. Ordinary handling can enter DownSpot or ftCo_800C4ED8; otherwise it grounds an airborne fighter, optionally handles Peach's parasol, enters Wait, conditionally runs DeadUpFall-related processing, and performs shared and Link/CLink-specific postprocessing. Consequently 'applicable neutral state' is only broad dispatcher terminology, not a claim that every destination is an ordinary idle state. [Dispatcher](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_08A1.c#L53-L109).

IASA has an empty body. It ignores its pointer and performs no reads, calls, input interrupts, mutations, or timer work. This proves only local inactivity, not global uninterruptibility. Phys forwards the same object to ft_80084FA8. That delegate conditionally negates negative ground speed, scales ground friction only when the resulting speed is strictly greater than walk_max_vel, then calls ft_80085030. Equality and unordered speed comparisons do not scale friction. Without the configured multiplier, stronger braking is unproved. If x594_b0 is set, ground acceleration becomes translation Z times facing minus ground velocity; otherwise selected friction is applied. Both branches call common ground movement. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_PassiveStand.c#L56-L61), [physics delegate](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_084E.c#L55-L89).

Coll unconditionally forwards to ft_80084104. That routine calls ft_800827A0 and enters Fall if its result is false. PassiveStand adds no local collision test, timer, or custom collision callback. [Coll](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_PassiveStand.c#L63-L66), [delegate](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_081B.c#L1043-L1050).
