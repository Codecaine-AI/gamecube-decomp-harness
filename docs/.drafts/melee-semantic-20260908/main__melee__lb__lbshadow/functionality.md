# Spline Tangents and Fighter Shadows

This TU combines spline derivative helpers with fighter-facing HSD shadow management. The spline path chooses linear, Bezier, B-spline or cardinal segment derivatives without normalization. Only the linear path adjusts the control index at u==1. Valid control storage and finite input remain caller requirements.

Shadow initialization configures an orthographic camera and a 256x256 target, clears five wrapper bits and leaves bit 2 unchanged. Removal delegates to HSD_ShadowRemove without clearing the stored pointer. Activation requests combine six bits with foreign fighter predicates.

The five-entry budget counts wrappers with clear flags before the extra fighter eligibility predicate. An entry rejected later can consume one of those slots. The render routine separately clears bit 2 and does not enforce this count itself. Its offscreen branch requires an existing shadow, camera box and clear bit 3; it does not directly test HSD active status or the no-light bit.

Missing light selection fails an assertion. Only a computed light distance below 0.001 sets the degenerate-light fallback. Rectangle fitting repeats AddRect/Check at most twenty times using unchanged local rectangle inputs. It does not explicitly expand those inputs between attempts. Failure selects the named +128/-128 orthographic bounds.
