## Fighter held-item swing module

`ft_0CD3.c` implements entry routines and Anim/IASA/Phys/Coll callbacks for SwordSwing, BatSwing, ParasolSwing and HarisenSwing. The canonical definitions—not the rendered proposed names—establish these families. The dispatcher maps item kinds 12, 11, 13 and 24 to families 0, 1, 2 and 3 respectively and supplies a selected motion ID, numeric swing variant and playback rate. Sword and Bat entry pass flags 0; Parasol passes `0x400`. All three install `ft_800CD31C` as `take_dmg_cb`. Harisen additionally clears `cmd_vars[0]` and `mv.co.swing.x8`, then installs distinct dealt- and taken-damage callbacks. The inferred `_Enter` names remain descriptive hypotheses rather than recovered symbols. ### Shared action behavior

The common initializer clears `throw_flags`, changes motion at frame zero, performs animation initialization, sets continuation latch `swing.x0` to 1, stores the variant in `swing.x4`, and invokes common held-item setup. Ordinary animation callbacks delegate to a helper that acts only when no animation frames remain: it calls `ft_8008A2BC`, then `ftCommon_8007E7E4(gobj, 1)`. This is not unconditional Wait: the downstream routine has separate Master Hand and Crazy Hand branches, and ordinary neutral routing has additional early exits and character-specific behavior. [Shared entry and animation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0CD1.c#L14-L32), [neutral routing](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_08A1.c#L54-L108).

All four IASA callbacks delegate to the same checker. A sampled update with A not held clears `swing.x0`; `ftCheckThrowB3(fp)` together with a nonzero latch requests numeric variant 3. This does not prove continuous physical holding between samples or universal successful re-entry. Variant-3 motion selection returns `swing_type + 341` for `FTKIND_CAPTAIN`; other fighter kinds report an unavailable motion and assert. Dispatcher variants 0 and 1 also have an early item-pickup path before held-item validation. [IASA](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0CD1.c#L34-L43), [exceptional dispatch](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftswing.c#L48-L99).

Physics delegates to a numeric `swing.x4 != 4` branch. Other variants use the ordinary helper, including above-walk-speed friction scaling; variant 4 supplies `p_ftCommonData->x420 * ground_friction` and facing direction. The downstream helper either computes ground acceleration from translated animation displacement when `x594_b0` is set or applies friction, then advances ground movement. Thus supplying a friction coefficient does not guarantee friction is applied on every update. [Swing physics](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0CD1.c#L45-L55), [movement implementation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_084E.c#L55-L89).

Collision callbacks concern supporting-ground collision, not attack hit detection. The shared helper calls the supplied cleanup callback before entering Fall when its collision query returns zero. Ordinary families supply `ft_800CD31C`; Harisen supplies `ft_800CD604`. Cleanup's held-item null guard does not suppress the subsequent Fall transition. Successful support can still update collision positions even though this path does not change the action state. [Collision sequencing](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0CD1.c#L57-L71), [position query](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_081B.c#L406-L424), [Harisen adapter](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0CD3.c#L166-L169).

### Harisen item synchronization and lifetime

With a held item, `ft_800CD65C` applies the item-side special scale and reloads fighter timer `swing.x8` from `p_ftCommonData->x5A0`. The scale routine multiplies the Harisen-specific scale factor by the ordinary item scale; source alone does not establish that the multiplier enlarges the item. `ft_800CD604` restores ordinary scale, selects item state 6 at animation speed 1.0, then invokes common fighter item handling. It serves both taken-damage and ground-loss cleanup. Neither cleanup body explicitly clears the fighter timer. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0CD3.c#L89-L116), [scale operations](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itharisen.c#L31-L46), [state 6](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itharisen.c#L118-L123).

Harisen animation performs item work only while `item_gobj` is non-null. If the timer is positive, it subtracts 1.0 and restores ordinary scale when the result is nonpositive or the fighter animation has ended. There is no saturation or clamp: fractional positive values can become negative, and early animation completion does not zero the timer. A nonpositive timer skips this restoration branch even at animation completion.

Command 1 maps fighter selector 0 to item state 3, selectors 1/4 to state 4, and selectors 2/3 to state 5, forwarding `frame_speed_mul` as item animation speed. An unrecognized selector performs no switch operation but still clears command 1. Command 2 selects item state 6 at speed 1.0 and clears itself. Other command values are unchanged. Without an item, command consumption and countdown updates are skipped, but the common fighter animation helper still runs. Item state numbers are distinct from fighter swing variants and are not assigned unsupported gameplay names. [Full animation callback](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_0CD3.c#L118-L154), [item transitions](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itharisen.c#L97-L123).

Item-side dropping separately resets animation speed and ordinary scale before selecting state 8. This establishes an additional cleanup path, but does not prove every fighter/item callback lifetime or ownership invariant. The source's fake-match comment is not compiled evidence. [Dropped-item handling](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/itharisen.c#L137-L156).
