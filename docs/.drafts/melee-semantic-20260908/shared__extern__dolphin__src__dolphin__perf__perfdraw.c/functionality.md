## Performance overlay rendering

This file implements the Dolphin PERF graphical overlay. Initialization stores the game drawing callback, initializes an identity matrix, and establishes timing and bandwidth scales. PERFPreDraw saves projection parameters and configures an orthographic, alpha-blended, untextured overlay with depth testing/writes disabled. [Initialization and setup](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/perf/perfdraw.c#L118-L184)

DrawBWBar maps GP timestamp intervals onto a 616-unit-wide timeline. It stacks bus-request deltas and separately draws instruction/cache, XF, and rasterizer metrics. Most bars require height greater than one; the cache bar does not. XF height uses raster clocks minus input/output waits, subject to an unsigned comparison; rasterizer height uses rasBusy, despite the color variable's IDLE name. Bandwidth rendering halves both fiReq endpoints in the shared sample rather than merely scaling a local delta. The static lastx joins nearby intervals and is not reset by this file's initialization or screen-dump routines. DrawKey draws a ten-color bandwidth legend. [Metric rendering](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/perf/perfdraw.c#L186-L413)

PERFDumpScreen draws only when GameDrawInit is non-null. It reads the current externally maintained PERF frame and chooses a display span of floor(frame end / 60-Hz tick interval) + 1. It renders frame boundaries, total duration, cache-miss duration, enabled metric backgrounds, and samples. ID 0xFF directly selects metric rendering; other IDs index PERFEvents. CPU events have event-colored timing lines and optional cache overlays. Combined CPU/GP events draw GP timing and connectors only when gpTimeStampEnd is nonzero; GP-only events have no corresponding guard. Interrupted GP lines use origgpStart, and interrupted combined-event connectors use origcpuStart, while metric rendering still uses the sample's ordinary GP timestamps. Unhandled event types draw nothing. [Frame and sample dispatch](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/perf/perfdraw.c#L415-L652)

PERFPostDraw reconstructs a perspective projection from saved entries and invokes GameDrawInit unconditionally; it is not a general restoration of every modified GX setting or the saved projection type. Setters preserve arbitrary integer values, while toggles map nonzero to zero and zero to one. [Post-draw and controls](code://c302741689bd67c361cd7faadb221df3193992c3/extern/dolphin/src/dolphin/perf/perfdraw.c#L654-L723)
