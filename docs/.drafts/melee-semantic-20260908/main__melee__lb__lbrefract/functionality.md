# Refraction Texture Pipeline

Provides radial distortion-map generation, tiled IA8/RGB565/RGBA8 access callbacks, reference-count-gated projection and framebuffer-copy requests, GX indirect-texturing setup and specialized HSD DObj/PObj hooks. Resources persist with no local teardown.

The format selector supports IA8, RGB565 and RGBA8. Canonical IA4 naming and owned dox support/signature descriptions are stale. The RGB565 reader returns mask-based markers 0/7, 0/3 and 0/7; its blue mask is exactly pixel&0xF8, not an ordinary reconstructed RGB565 component. The RGB565 writer accepts unmasked u32 blue input.

Initialization allocates resources without local failure handling or old-resource cleanup. It assumes adjacent initialized data when copying the image template and loads the texture chain before final image-field assignments. Projection setup and capture are gated by exactly zero user count; draw setup is unguarded. Decrement stores a negative count before reporting assertion. Foreign GX synchronization and HSD ownership semantics remain unresolved.
