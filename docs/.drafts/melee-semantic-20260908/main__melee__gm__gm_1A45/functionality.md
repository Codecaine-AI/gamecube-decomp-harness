## Common scene runtime

This unit supplies common scene initialization, current-scene payload access, descriptor lookup, runtime-control accessors, developer input handling, and the queued-update/render loop. Canonical symbols and control flow—not rendered proposed names—ground this review.

### Initialization and cross-file lifetimes

`gm_801A4BD4` installs default input predicates, clears the separate per-update hook and numeric mask selector, supplies a nominal 1/60-second timing interval, configures GObj/SObj facilities, publishes the address of the working scheduler mask, and creates a shared process-host GObj. Only process attachment is guarded by successful host creation. It clears one diagnostic handle and one diagnostic callback, then invokes support initializers. It has no already-initialized guard. [Initializer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L214-L241)

The scene driver subsequently installs a borrowed `GameSceneInfo*`, invokes scene entry, and runs the loop. Loop entry calls `gm_801677C0`, which clears only the four flag/snapshot bytes and two masks, preserving callbacks and selector installed by scene entry. Reset skips scene and state exit callbacks. The payload accessors return opaque pointers without NULL checks, copying, allocation, or ownership transfer. The lookup returns the first matching `kind` before the `GS_COUNT` sentinel, or NULL; the driver does not guard a failed lookup before accessing the descriptor. [Driver](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A3F.c#L143-L169), [selective reset](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1601.c#L3448-L3455), [payload accessors](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L180-L195), [lookup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L243-L252).

### Flag widths and input controls

The primary/current, primary/previous, secondary/current, and secondary/previous fields `x0`–`x3` are **u8**, not u64. Indexed accessors construct `1ULL << bit`, but this expression does not widen backing storage. Bits 0–7 are representable; defined shifts 8–63 cannot set stored bits, and negative or at-least-64 shift counts are unchecked. Scheduler masks `unk_20` and `unk_28`, in contrast, are u64. [Types](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/types.h#L925-L946), [accessors](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L32-L55).

The default predicates scan valid master-pad records for held X plus triggered D-pad Up, or triggered Z. The dispatcher toggles only primary bit 0 and consults the secondary predicate only while that bit is set. Its separate X-plus-triggered-D-pad-Right diagnostic branch does not check pad errors and can run once per matching port. It emits reports and toggles the diagnostic object; the optional creation hook runs even if creation returns NULL. The loop invokes this dispatcher only at `DbLKind_DebugRom` or higher, but the dispatcher itself does not enforce that threshold. [Predicates and dispatcher](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L57-L158), [caller guard](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L298-L300).

Primary flags are not exclusively developer controls: versus pause handling uses bit 1, training uses bit 2, and conditional match-completion/result paths use bits 4 and 5. Match setup substitutes Start/Z predicates, installs `db_RunEveryFrame`, and sets selector 1. [Match control](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_16AE.c#L1340-L1525), [match setup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_16AE.c#L1976-L1985).

### Queued updates, masks, and presentation

`gm_801A4D34` clears top-level counters and exit state, flushes the pad queue with `HSD_PAD_FLUSH_QUEUE_LEAVE1`, waits for queued samples, and checks reset before processing a batch. Each sample renews master input. Secondary bit 0 or a clear primary bit 0 enables cadence advancement; controller evaluation and `on_frame` additionally require cadence 0 to be due. The separate stored `unk_30` hook is invoked outside this simulation gate, before GObj scheduling. The `GameSceneInfo*` parameter is unused. [Loop](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L264-L378).

Changed flag snapshots trigger cached-mask recomputation, snapshot updates, and clearing of `x2`. **The clear is conditional**, so the implementation must not be described as unconditional exactly-one-update consumption. `gm_801A48A4` ORs selected entries of an eight-element u64 table. Its wrapper substitutes all ones when processing is disabled. The working mask is augmented with a selected `gm_803DA8C8` entry or its complement according to two cadence-due flags—not two separate input queues lacking data. Both table entries initially equal all ones; the complement is applied at use, and named-source search found no other writers. The selector is stored without bounds checking. [Expansion](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L26-L96), [wrapper and publication](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L254-L332), [cadence implementation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lb_0195.c#L120-L159).

The GObj scheduler reads the published mask and suppresses callbacks whose process-link bit is set, with additional per-process exclusions. Calling the scheduler does not mean every GObj updates. [Scheduler](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/gobj.c#L88-L141).

The total-update counter advances after each scheduler pass; the active-update counter additionally requires update permission and cadence 0. Rendering has its own counter. These u32 counters stop incrementing at `0xFFFFFFFE`. Match-statistics accessors use the total-update token for cache refresh, while the active-update count is displayed by diagnostics and used for parity-staggered, guarded coin-item collision work. [Counter updates](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L340-L375), [cache consumers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_16AE.c#L956-L1001), [display](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1601.c#L2583-L2614), [collision consumer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_07C6.c#L67-L124).

### Exit distinctions and evidence limits

The exit setters unconditionally write 1 or 2 and can overwrite an earlier request. A nonzero value observed after an update ends the batch; value 2 additionally bypasses the subsequent render. State 1 permits that render, rather than guaranteeing it against reset or later writes. Reset exits before batch processing and marks the global resetting flag. Normal returning paths reach the final XFB-flush wait. Movie callers preserve an exceptional state-two branch based on `xC` and playback status; no more specific error meaning is inferred. [Exit protocol](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L170-L178), [loop exits](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_1A45.c#L281-L378), [How-to branches](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmhowto.c#L50-L83), [Omake branches](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmomake15.c#L39-L72).
