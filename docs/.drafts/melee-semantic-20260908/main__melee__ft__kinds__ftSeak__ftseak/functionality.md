## Sheik initialization and lifecycle subsystem

`ftseak.c` supplies character metadata and eleven lifecycle/event callbacks; `ftseak.h` declares those callbacks and exported resource records. The motion table contains 24 explicit records: eight neutral-special, six side-special, six up-special, and four down-special records, preserving grounded/aerial and phase distinctions. Each record supplies a submotion, flags, packed move identifier, animation/IASA/physics/collision callbacks, and `ftCamera_UpdateCameraBox`. Comments identify states 341–364; these numbers must not be confused with submotion identifiers. Up-special start variants share submotions but have distinct callbacks. Resource declarations include base and animation archives, four demo identifiers, five costume resource triples, and a five-element uninitialized costume list. These are source-level observations, not proof of compiled section boundaries. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSeak/ftseak.c#L16-L317)

### Initialization and death

`ftSk_Init_OnLoad` enables wall jumping, copies `ftSeakAttributes` into fighter-owned backup storage and activates it, then passes four item resources in order for thrown needles, held needles, Vanish, and Chain. `ftSk_Init_LoadSpecialAttrs` copies external attributes into the already-selected active attribute storage. Neither callback locally changes motion state. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSeak/ftseak.c#L329-L342), [copy callback](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSeak/ftseak.c#L378-L381), [macro definitions](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/inlines.h#L21-L35).

`ftSk_Init_OnDeath` unconditionally clears `u.sk.x0`, `x4`, and `x8`, then schedules model selections `(0,0)` and `(1,-1)`. The helper writes pending selections and a dirty flag; application and visibility processing occur separately. This hook does not itself invoke article destruction. [Death hook](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSeak/ftseak.c#L319-L327), [pending/application logic](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftparts.c#L555-L625).

### Cross-file interruption cleanup

`ftSk_Init_80110198` forwards the same fighter first to needle cleanup, then Chain cleanup. Neutral-special setup installs this wrapper in damage and secondary-death callback slots. Chain setup installs it only after successful article creation; failed creation selects a ground/air exit, while hitlag callback assignments are outside the successful-spawn guard. [Wrapper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSeak/ftseak.c#L344-L348), [neutral setup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSeak/ftseakspecialn.c#L75-L95), [Chain setup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSeak/ftseakspecials.c#L527-L552).

Needle cleanup clears the held-object reference and attempts thrown-needle creation while stock is nonzero, but only when the held-object reference was non-null. Placement uses ground/air-specific attribute offsets scaled by fighter Y scale, with Z forced to zero. A failed spawn still consumes one stock unit. Inside that held-object branch, either callback matching the wrapper causes both callbacks to be cleared. The final stock reset is unconditional. Chain cleanup returns immediately without an owned Chain; otherwise it requests article destruction, invokes guarded Chain working-state handling, and clears ownership and both interruption callbacks. The working-state write is numeric `2`, without a proven enum meaning. Pointer clearing is not by itself proof of immediate item-object deallocation. [Needle path](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSeak/ftseakspecialn.c#L30-L73), [Chain path](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSeak/ftseakspecials.c#L402-L440).

### Charge feedback and shared adapters

`ftSk_Init_UnkMotionStates4` requests color-animation entry 86 with argument 0 only at exactly six stored needles; it does not increment or clamp stock. Ground and aerial charge loops own progression and clamp after exceeding six. The color-animation routine routes requests through shared tables and can return false; this hook ignores that result. Specific colors, timing, and the selected table entry's channel are not established here. [Hook](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSeak/ftseak.c#L350-L356), [charge loop](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSeak/ftseakspecialn.c#L120-L140), [routing](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftcolanim.c#L113-L129).

Pickup/drop callbacks forward the event boolean and two literal ones. Pickup skips heavy-item presentation handling and dispatches hold kinds 1–4 to numeric selections 1,0,2,3; its event boolean gates an additional presentation call. Drop always requests selection -1 and gates its additional call on the event boolean. Visible/invisible adapters select true and skip the presentation call for heavy items. Knockback adapters pass numeric argument 1; shared handlers invoke animation handling for arguments 1 and 0 with 3.0f on entry and 0.0f on exit, rather than computing knockback magnitude. [Adapters](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSeak/ftseak.c#L358-L391), [shared bodies](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/inlines.h#L142-L205).
