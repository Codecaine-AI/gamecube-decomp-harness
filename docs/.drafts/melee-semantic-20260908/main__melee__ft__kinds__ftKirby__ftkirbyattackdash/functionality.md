## Airborne suite and boundaries
`ftKb_AttackDashAir_Anim` calls `ftCo_Fall_Enter` exactly when the remaining-frames predicate is false. That predicate scans eligible parts, choosing primary joints when blend frames equal zero and alternate joints otherwise. No eligible part with a truthy joint predicate produces false. Negative zero selects the zero branch; NaN blend frames select the alternate branch under ordinary floating-point comparison semantics. This is not a local numeric last-frame test. Common Fall entry has hand-kind and common special-condition routes before ordinary Fall; ordinary entry passes `Ft_MF_KeepFastFall`, clamps drift, initializes fall variables, and performs airborne preprocessing if needed. Passing that named mask is established; this pass does not independently prove every mask effect. ## Rotation accessor and actual consumer
`ftKb_AttackDashAir_800F21C0` returns `ftPartGetRotX(GET_FIGHTER(gobj), 0)` unchanged. The helper reads the primary joint unless it uses quaternions, then reads the alternate joint; if both use quaternions it asserts. Valid fighter, parts, and joints are preconditions; the wrapper adds no NULL/bounds guard, normalization, or float validation. Its verified consumer is the Cutter Beam initializer, not a dash-attack callback. `it_8029BB90` snapshots the result into `kirbycutterbeam.angle`, sets speed from item attributes, computes velocity `(facing * (speed * cosf(angle)), -speed * sinf(angle), 0)`, and stores `dir = (facing * sinf(angle), cosf(angle), 0)`. The latter is not the velocity direction. Under conventional facing ±1 it is mathematically unit length, subject to floating-point approximation; finite inputs alone do not guarantee exact unit length. Subsequent item physics uses the stored angle, and collision can replace it from a floor normal rather than resampling the owner. Spawning checks the created item for NULL before initialization; the owner is assumed valid. Kirby's SpecialHi callback invokes the spawner under command-variable and one-shot guards.
