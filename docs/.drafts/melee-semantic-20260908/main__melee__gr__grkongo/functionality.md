## Registration and startup
The module registers Gr_Kind_Kongo, /GrKg.dat, six joint mappings and twelve Ground callback rows. Startup requests objects 0,10,5,3,6,4 in that order, ignores nullable factory results, initializes common boundaries, removes collision joints 0 and 1, and submits startup sound only under both guards. The factory indexes callbacks without a local bounds check, configures rendering, retains callback3, invokes on_init immediately and schedules gobj_proc when present. It does not itself consume callback1. Ground_GetStageGObj initializes framework fields but does not clear the whole Ground payload. OnStart registers map 5 with the two-slot fighter catch registry and creates the Zako manager; registry exhaustion asserts and generator failure is ignored locally. Deferred Ground callbacks execute once after on_start and their queue nodes are freed.

## Raft and supports
Map 10 resolves fifteen raft joints and two support joints, initializes rest angles, and establishes four post/platform joint references. Contact types 1 or 3 with ground kind Unk1 bin horizontal position into fifteen clamped indices and add a configured angular impulse. The solver restores and damps angular velocity, clamps velocity and angle, then applies separately accumulated neighbor corrections only between zero-flag entries. Those final corrections are not followed by another clamp. Geometry publication computes tangent-derived displacements, bounded support slopes, thresholded sway impulses, model rotations and collision-line offsets. Its incoming arg1 is overwritten as a loop counter: passing 1 does not select initialization mode. Only the post-sway helper honors a nonzero reset selector. The literal nested-radian bound and full/half restoring-step branches are preserved.

## Barrel cannon
Map 5 initializes three independent s16 state machines for rotation, animation rate and occupancy. Rotation states 2/3 use stopping-distance and remaining-angle tests and assert on zero angular velocity; braking occurs in state 0. Rate states wait, ramp to a cap, hold, and ramp to zero, with differing pre/post-decrement tests preserved. A first nearby Klap search uses the shared published barrel position and a strict squared 3D radius. Fighter admission separately requires occupancy 0 and the same proximity bound, then stores a fighter, delay and entry feedback. Occupancy state 1 falls through into launch state 2 when the countdown expires; its NULL-keep branch also falls through after writing state 0 and subsequently dereferences NULL. No external invariant proving that branch unreachable was established. Launch distinguishes p_link 8 and 9 and enters state 3; state 3 resets when no nearby Klap exists, not when a generic occupancy flag is empty. Manual fire requests only change 1 to 2. The separate cleanup helper asserts non-NULL keep in state 1 and clears only a link-8 occupant; link 8 identifies a fighter, not intrinsically an invalid fighter. Weighted target-angle selection has eight outputs and a terminal assertion when no bucket accepts the draw, including the all-zero-weight case.

## Waterfall objects and cross-file lifetime
Maps 1/2 start with randomized X placement and lifecycle 0. Initial animation completion installs collision joint 0 or 1 and the retained Ground callback context. Active updates maintain a contact-continuity streak and elapsed count; strict thresholds or a spatial neighbor guard remove collision and callback before exit animation and final Ground destruction. Contact notifications assign previous_streak+1, so repeated notifications before the owner snapshot do not independently accumulate. The position query accepts selected map IDs, uses joint 2 for five variants and root translation for one, and returns NULL on unsupported/missing data. Proximity ignores Y and uses strict -150<dz<-100 and dx squared<6400. Enum spellings in these map-ID tests do not imply that the objects belong to other stages.

Maps 7/8/9 initialize animation set 0 and clear AOBJ_LOOP recursively for category mask 7. The previously recorded material-animation-7 interpretation is disproved by canonical granime.c. Their process short-circuits two distinct AObj flag predicates and destroys on either; rendered collision of the two proposed predicate names is not proof of equivalence.

Map 11 chooses one of three typed file/spline pairs and initializes progress and extrema. Progress uses nearby arc-length samples to scale a nominal step, but zero distance and the near-end guard can prevent further advancement. Final transform evaluation uses Ground_801C4B50; no local endpoint destruction exists. A strict crossing of a fixed five-unit drop triggers sound and a literal depth-ratio volume input, with no local zero-denominator or bounded-range guarantee. The event scheduler resets its timer before no-event or repeated-family rejection; timer 1 can select an event immediately after decrementing to zero, while other negative timers remain unchanged. Klap and Box events create map 11 first, remove it on item-construction failure, and otherwise transfer a retained source pointer into item state. Both item destruction paths call grKongo_801D8058 and clear that pointer; common Ground teardown removes registry/collision associations and destroys the GObj. This cross-file lifetime must not be replaced with assumed endpoint cleanup.
