## Item terrain collision and landing policy

This unit adapts map collision to item state. Grounded wrappers prepare embedded CollData, query support, and usually copy the resolved position back to Item.pos and a successful floor index to Item.xC30. Probe-only variants omit those Item writebacks. Support-loss policies are intentionally different: it_8026D62C establishes airborne state before its callback, it_8026D6F4 delegates without that setup, it_8026D78C performs setup after its callback, and it_8026D82C performs setup without a callback. it_8026D8A4 unusually prepares collision twice and exposes independent edge-event and floor-result channels. Stored-line validation is separate from collision resolution. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itgroundcoll.c#L12-L222)

Airborne adapters select standard or alternate map resolvers, synchronize position, and optionally combine supplemental contact results. Preserve the declared bool/s32 distinctions and numeric mask operations rather than treating every intermediate as a normalized Boolean. The wall classifier returns 8 for left-wall contact but replaces it with 4 when right-wall contact is also present; it does not accumulate both wall bits. Ceiling classification contributes 2 and can overwrite the stored surface index after floor and wall processing. [Adapters](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itgroundcoll.c#L178-L262) · [Classifiers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itmaplib.c#L323-L389)

Landing continuation short-circuits retirement, settling, and finalization. The retirement check increments the landing count, considers destruction only when the new count equals 1 and the throw count is nonzero, and uses high-nibble equality or a short-circuited random test. Settling independently snaps X/Y magnitudes at or below 0.00001f to zero, then applies the per-item threshold and policy overrides. Finalization resets the landing count and initially grounds the item, but may dispatch entered_air and return false. Thus a suppressed supplied event does not establish unchanged state or continued object lifetime. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itgroundcoll.c#L264-L343)

Dispatch variants differ meaningfully: E15C resets hitboxes during accepted landing; E248 omits that reset; E32C directly increments the landing count without retirement and returns the contact result. E414/E4D0 dispatch only for floor contact, while E5A0/E71C dispatch for any selected low-four-bit contact and E664 excludes ceiling-only contact. E7E0 combines wall correction with validated landing. E8C4 separates immediate support-loss dispatch from a guarded supported-contact event. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itgroundcoll.c#L428-L778)

Callback lifetimes matter: D78C uses its retained Item after callback return; E4D0 retains a pre-callback JObj and reads scale through the retained Item afterward. Neither establishes that arbitrary destruction or replacement by the callback is safe. Segment-query wrappers leave the object parameter unused, pass planar endpoint coordinates and optional metadata outputs to mpCheckAllRemap, and replace the endpoint only when the query returns exactly true.
