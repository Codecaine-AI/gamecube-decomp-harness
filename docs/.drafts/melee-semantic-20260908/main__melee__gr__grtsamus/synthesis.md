# grtsamus Synthesis

TSamus is a thin target-stage registration and callback wrapper. Initialization delegates to the shared target initializer; object 2 calls lb_800115F4 before Ground_801C2FE0, while object 1 calls only Ground_801C2FE0. Touch-line always returns NULL and shadow eligibility always returns true. Callback1/flags consumers, mode routing and foreign callee effects remain followups. Independent family synthesis belongs to the lead.
