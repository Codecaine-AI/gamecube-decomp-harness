## Boot and Memory Card startup

`gmboot.c` defines two sentinel-terminated `GameModeState` tables sharing static `load_data` and `leave_data` objects. Boot registers `bootOnLoad` and `bootOnLeave`, with leading values `0, 1, 0`; Memory Card registers `memcardOnLoad` and a null leave callback, with values `0, 3, 0`. Both select `GS_MEMCARD`. These are source-level associations, not proof of compiled section placement. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmboot.c#L20-L99)

`bootOnLoad` clears `x4` and `x0`. When `skip_intro == true`, it selects `GM_TITLE`; otherwise it calls `gm_801BF708(0)` and selects `GM_OPENING_MV`. `memcardOnLoad` instead writes `x4 = 0` and `x0 = 1`, leaving `mode_id` unchanged. Because storage is shared and static, that untouched field must not be described as freshly reset on every Memory Card entry. The meanings of the numeric variants are not established here. [Boot callback](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmboot.c#L50-L61) · [Memory Card callback](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmboot.c#L101-L106)

`bootOnLeave` retrieves the exit payload. Only when `Toy_803048C0(275)` returns zero does it call `lb_8001C2D8`, using channel `0`, company identifier `"01"`, product `"GPIJ"` for Japanese and `"GPIE"` otherwise, and filename `"Pikmin dataFile"`. Only a zero probe result triggers `Toy_803124BC()` followed by `Toy_SetUnlockState(275, true)`. Nonzero trophy data bypasses the probe; a nonzero probe result bypasses both trophy-update calls. All these paths subsequently install `lbCardGame_DecideGameMode` as the override and request the exit payload's `mode_id`. This installs a callback rather than directly invoking it. [Exit callback](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmboot.c#L63-L83)

Independent canonical callee evidence confirms that `Toy_803048C0` reads a record's low byte, distinct from separately queried flag bits. `Toy_803124BC` lazily loads trophy tables, applies the US exclusion list when appropriate, sets `0x4000` for eligible category-2 trophies, and sets category bit `4`. The card helper copies company, product and filename arguments and waits while its task result is `0xB`; rendered proposed names were not used as proof. The source documents transfer of `loadData.mode_id` into `leaveData.mode_id`, but does not implement that transfer locally. Override lifetime, downstream routing and transfer timing remain cross-file responsibilities. The CSS patch comment does not describe an active branch. `gmboot.h` contains only an include guard.
