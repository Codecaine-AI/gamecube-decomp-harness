## Pikachu initialization and dispatch

This unit defines Pikachu's special-move dispatch table, resource metadata, and twelve initialization/event helpers. The header declares that interface. The table contains 26 descriptors, annotated as states 341–366: two neutral-special, ten side-special, six up-special, and eight down-special entries. Every entry supplies the shared camera callback; all down-special interrupt slots are NULL. Motion-state identifiers and animation identifiers must remain distinct: SpecialAirS1 uses ftPk_SM_SpecialS1, while SpecialAirS0 uses ftPk_SM_SpecialS. Numeric phase suffixes do not alone establish phase semantics. [Source](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPikachu/ftpikachu.c#L20-L307)

The source declares a four-element costume list, fighter and animation archive strings, four costume-resource triples, and four demo-motion identifiers. These declarations establish source ownership, not compiled section membership, alignment, or ordering. ## Attribute and article lifetimes

OnLoad obtains the Fighter and its item-resource array, installs ftPikachuAttributes, then registers entries 0–2 using xDC, specialn_itkind, and specialairn_itkind respectively. PUSH_ATTRS copies the current fighter's external attributes into dat_attrs_backup and points dat_attrs at that buffer. The article helper stores pointers in an item-kind-indexed table; it does not spawn items or copy article resources. The rendered registration name is independently supported by that implementation. [Loader](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPikachu/ftpikachu.c#L339-L357), [attribute macros](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/inlines.h#L21-L35), [article store](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L204-L208)

Pichu calls the Fighter-pointer helper before performing its own article registration. Its attribute-reload callback also delegates to Pikachu's loader. Shared layout does not mean shared numeric values. Reload copies external attributes into the active buffer first, then multiplies all six height_attributes collision-box floats by vertical model scale only when that scale differs from 1.0f. Repeated reload therefore starts from external values rather than compounding previously scaled values. Move code subsequently reads dat_attrs. ## Event adapters and exceptional paths

Death writes pending model selections 0 for groups 0 and 1. UnkMotionStates1 requests group 1 pending=-1 and active=0; UnkMotionStates2 requests pending=0 and active=0. The pending setter always marks model state dirty. The active setter updates only when the requested index differs; its DObj processing also depends on a non-null lookup and the visibility-set cleared flag. Later reconciliation can copy pending selections into active selections. Neither anatomy nor the invocation event of the two unknown-motion helpers is established here. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftPikachu/ftpikachu.c#L359-L401), [model implementation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ftparts.c#L555-L670)

Pickup and drop forward the supplied boolean and append two zeros. Shared pickup handling excludes heavy items, maps hold kinds 1/2/3/4 to animation values 1/0/2/3, leaves other hold kinds without that update, and conditionally performs the catch animation call. Drop always requests hold value -1 and conditionally performs its additional animation call; it has no equivalent heavy-item guard. Invisible and visible adapters both pass selector 0, but call complementary helpers; both helpers exclude heavy items. The reviewed heavy-item predicate dereferences the item object without a null guard. [Shared item paths](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/inlines.h#L142-L193), [heavy predicate](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L90-L100)

Knockback entry and exit pass integer selector 1. Included helpers call ftAnim_800704F0 for selectors 1 and 0, using 3.0f on entry and 0.0f on exit. Thus the argument is not merely an enabled boolean option. These inline bodies also expose source consumers of 3.0f and 0.0f overlooked by the baseline constant-pool interpretation, but do not identify their compiled storage.
