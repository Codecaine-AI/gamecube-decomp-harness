## Ownership, optional inputs, and lifetime
Vector requirements are branch-dependent: kind-0 and scalar-only branches need not read arg5/arg6, kind 7 reads arg5 through efAsync_Spawn but not arg6, and 0x49D reads arg5 and only arg6.x. Generic, second-switch, and even unsupported second-switch requests require readable vectors. The helper performs no allocation or error recovery itself. efAsync_Spawn allocates an EF_QueuedEffect and copies vector/scalar values before returning, so this caller's local vectors and angles are not retained as pointers. The joint pointer is retained. If HSD_GObj_804D7838 exists and its s_link is below 9, the request is prepended to the supplied queue; at 9 or above, or with no current GObj, it is processed immediately. Processing frees the queue node. Queue clear frees pending nodes without spawning, and flush processes nodes in list order. Deferred processing therefore requires a still-valid joint; complete fighter teardown safety and downstream effect callback lifetimes are not proved here. No callback is installed by this TU, and asynchronous naming does not guarantee delayed execution. [code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ef/efasync.c#L1318-L1464]

## Fixed CPU script construction
ftCo_800A0098 unconditionally calls ftCo_800B46B8 eight times and ftCo_800B463C once to append bytes 80 00 81 00 8E 01 91 B0 8E 01 81 00 8E 0A 80 00 7F. Successful completion advances fp->cpu.write_pos by 17 bytes. Canonical storage is struct CpuFighter through fp->cpu, not the historical x1A88/Fighter_x1A88_t aliases. It does not reset the cursor, activate the interpreter, or clear unrelated controller inputs. The byte writer checks the upper buffer bound before each byte; it does not validate an arbitrary uninitialized/below-buffer cursor. The caller must provide a valid Fighter and initialized writable cursor with sufficient room. Construction is not atomic and may have partially appended before a later assertion. Operands are consumed through s8*, with wait durations explicitly converted to u8.
