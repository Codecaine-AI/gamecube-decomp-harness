## Fighter-side Samus Bomb

This unit implements grounded and aerial Bomb entry, deferred article placement, temporary compact hurtbox configuration, movement, input handling, and ground/air continuation. The header declares all sixteen public functions. Canonical definitions—not rendered proposed names—support the functional interpretations.

### Entry and command lifecycle
Ground entry scales `gr_vel` by `x6C`. Normally it enters motion `0x163` at frame zero, invokes animation initialization, and performs shared setup. Predecessor motion `0x28` instead selects frame three, performs shared setup, sets `cmd_vars[1]` to 2, invokes the aerial launch helper, and returns without the ordinary animation-initialization call. Aerial entry scales horizontal self-velocity by `x70`, replaces vertical self-velocity with `x58`, and enters `0x164` at frame zero. Shared setup clears commands 0–2, throw flag B0, and `mv.ss.unk6.x0`; it sets command 1 to 1 if the current frame equals 3 and installs the accessory callback. [Entry evidence](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSamus/ftsamusspeciallw1.c#L64-L109).

### Article request and separate lifetime
`ftSs_SpecialLw_8012ADF0` waits for the throw event, obtains a TopN-derived position, adds `x74_vec` with only X mirrored by facing, and calls `it_802B4AC8`. It clears `accessory4_cb` after the request regardless of success. Entry and situation helpers explicitly rearm it; this is not an unconditional once-per-entire-move allocation guarantee. The item constructor copies the supplied position into `prev_pos`, forces its Z to zero, separately obtains `si.pos` from the parent helper, and may return NULL. The fighter does not retain the returned item pointer here. The article has its own owner field, state callbacks, and lifetime timer. ### Hurtboxes, animation, and interruption
The compact configuration first requests intangible hurt capsules, then initializes capsule 0 on XRotN with mid height, nongrabbability, zero endpoints, and scale 3. Command 0 and the `unk6.x0` latch control setup and enabled-status restoration. Ground animation consumes command 1 from 1 to 2 and launches with an early return, skipping hurtbox synchronization and completion processing that invocation. Otherwise completion calls `ft_8008A2BC`; aerial completion calls Fall. Grounded completion is an ordinary neutral-dispatch path, not an unconditional Wait transition: the common dispatcher has exceptional branches. Ground IASA requires command 2 and stick Y strictly below `x80`, clears the command, and enters the SquatWait variant using SkipNametagVis and a false auxiliary option. Aerial IASA is empty. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftSamus/ftsamusspeciallw1.c#L44-L166); [completion exceptions](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/ft_08A1.c#L54-L98); [SquatWait options](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/ft/kinds/ftCommon/ftCo_SquatWait.c#L50-L86).

The exported hurtbox helpers also serve `ftsamusspeciallw0.c`, whose callers use the distinct `mv.ss.unk2.x0` latch. Local Bomb restoration directly calls the collision routine rather than the exported restoration wrapper. Enabled-status restoration must not be confused with reconstructing every original capsule descriptor. ### Movement and situation transitions
Command 0 selects scaled ground control using walk acceleration times `x64` and maximum velocity times `x5C`; otherwise physics delegates to `ft_80084F3C`. Aerial physics applies basic fall and drift products using `x68` and `x60`. Command 0 also selects attribute-parameterized versus default terrain predicates. Ground predicate failure requests `0x164`; aerial predicate success requests `0x163`. These collision transitions set command 1 to 2, clear the hurtbox latch, and reinstall the accessory callback. The launch helper differs: it assigns `x54` to vertical velocity and rearms the callback without calling that shared command/latch reset. Both common situation inlines forward the current animation frame with playback rate 1 and zero blend. The local flag expression adds KeepColAnimHitStatus, SkipHit, and SkipModel to the common ground/air flags.
