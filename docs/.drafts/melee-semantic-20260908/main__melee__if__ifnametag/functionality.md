## Overhead player indicators and saved names

`ifnametag` owns a dedicated camera, shared marker-model descriptor and SIS text context, plus per-slot marker GObjs, text identifiers and visibility overrides. `ifAll` loads the shared interface archive before invoking this subsystem's initializer. Initialization clears retained marker pointers and visibility controls, constructs the camera and SIS resources, extracts `ScInfPnm_scene_models`, and creates a marker for every player slot. This is not a safe live-reinitialization contract: existing resources are not destroyed before their retained pointers are overwritten. [Initialization](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/ifnametag.c#L363-L390), [aggregate startup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/ifall.c#L196-L240).

### Marker selection and creation

`un_802FC9B4` returns an integral animation frame represented as a float. Its branches depend on team mode and zero versus nonzero slot kind. Team-mode numbered markers use resolved player identity and team; the nonzero-kind branch can select a heart when the indexed match flag or global rule flag is set and the team matches slot 0. Otherwise it selects a CP frame. The heart predicate uses resolved `player_id`, whereas the updater's separate `gm_8016B258` call uses the slot directly; these domains must not be silently conflated. The relevant game-mode flags remain semantically opaque. [Selector](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/ifnametag.c#L131-L150), [flag accessors](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_16AE.c#L171-L255).

Creation attaches and scales a marker JObj, registers the render callback, selects and evaluates its animation, stores a one-byte slot payload, and installs the recurring update process. Saved-name text is created only for human slots whose nametag identifier is not disabled. The header defines the sentinel as 120; the implementation also spells it `0x78` and `'x'`. For eligible names, the integer-converted marker frame maps to 28 when at least 16, otherwise to `(frame % 4) + 20`. Text begins offscreen and receives scale 0.4 by 0.55. [Eligibility and creation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/ifnametag.c#L211-L301), [sentinel](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/ifnametag.h#L6-L20).

### Update, rendering and controls

The recurring process requires a non-NA slot, nonzero player-state value and nonzero stocks, followed by an OR of the per-slot override, enabled nametag identifier, auxiliary player predicate and game-mode predicate. These are literal nonzero tests, not proof of a particular numeric player state or strictly positive stock count. Failure hides the marker child, moves eligible name text to (-5000, 0), and returns before projection. Success projects fighter coordinates after adding the player vertical offset and subtracting 2.5; the marker receives screen X and negated screen Y, while text receives screen X and screen Y minus 56. [Update](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/ifnametag.c#L222-L253).

The model callback simply forwards the GObj and pass to HSD's JObj renderer. The camera callback ignores its incoming pass. HUD hiding or local suppression skips camera rendering and moves eligible names offscreen. Otherwise, only successful camera activation permits dispatch and finalization. Mask 7 dispatches callback passes 0–2 over the camera's selected GX-link groups; it is not texture-camera setup. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/ifnametag.c#L155-L182), [dispatcher](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/gobj.c#L158-L183).

The bulk override setters only change one alternative in the update guard. They do not bypass participation, state, stocks or camera suppression. Hide/Show independently set and clear the local camera-suppression byte; Show neither restores text coordinates itself nor overrides whole-HUD hiding. The aggregate interface dispatchers invoke these controls during coordinated HUD transitions. [Controls](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/ifnametag.c#L322-L345), [aggregate dispatchers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/ifall.c#L37-L57).

### Refresh and lifetime boundaries

Refresh assumes an existing marker GObj, recomputes its frame, and replaces SIS text only when the slot currently satisfies name eligibility. The ineligible branch does not remove an old entry, and becoming eligible does not itself prove that the retained old text identifier is valid. Model loading copies archive-backed pointers; absent animation arrays leave the corresponding retained fields unchanged. [Refresh](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/ifnametag.c#L303-L320), [model loading](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/ifnametag.c#L189-L206).

Teardown requests destruction of each non-null marker and then the camera unconditionally. It neither nulls the retained pointers nor explicitly removes SIS entries or destroys the shared text context. Generic GObj destruction normally releases attachments, processes and links, but can defer destruction of the current process object. Consequently, neither immediate destruction of every object nor safe repeated teardown is established. [Teardown](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/if/ifnametag.c#L347-L356), [generic destruction](code://c302741689bd67c361cd7faadb221df3193992c3/src/sysdolphin/baselib/gobjplink.c#L103-L127).
