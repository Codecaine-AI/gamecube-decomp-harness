## All-Star result enrichment
`fn_8018A364` accepts an integer and casts it to mutable `MatchEnd*`. It sets qualifying bits without clearing other flags. Independently of `rules->x4_5`, positive `fn_8017E318()` sets `_x448[2].b3`. Under the rule guard, it sets `[0].b5`, marks CPU level exactly 4 with `[0].b2`, and computes unsigned accumulated-plus-current frame time. A value below 0x6270 sets `[2].b6`; otherwise a value below 0x9AB0 sets `[2].b7`. Threshold equality follows those strict comparisons.

Both accumulated x1C and current player-zero x44 being zero sets `[1].b1`. Persisted xE and xF set `[2].b5` and `[2].b4`. Equality of accumulated-plus-current x44 with `(u32) Player_GetDamage(0)` sets `[0].b1`. Persisted xD sets `[1].b0` and returns immediately, suppressing the final stock comparison. Only otherwise can remaining stocks equal to configured starting stocks set `[1].b2`. Exact bonus identities and numeric condition-byte meanings remain uninterpreted.
