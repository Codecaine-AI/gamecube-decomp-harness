# grtganon Synthesis

TGanon is a thin target-stage registration and callback wrapper. Explicit initialization caches yakumono parameters and requests objects 0, 1, 2; object 2 calls lb_800115F4 before Ground_801C2FE0, while object 1 calls only Ground_801C2FE0. Touch-line selects joint-0 ceiling/right-wall/left-wall descriptors; floors and other joints return NULL. Cache is unchecked. Shadow eligibility always returns true. Callback1/flags consumers, mode routing and foreign callee effects remain followups. Independent family synthesis belongs to the lead.
