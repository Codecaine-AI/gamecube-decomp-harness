## Hassam / Scizor item behavior

The translation unit implements a four-state summoned-item lifecycle. The header exposes initialization, reference invalidation, and the state table. State-table indices are distinct from animation IDs: indices 0, 1, 2, and 3 contain animation IDs 0, 1, 2, and -1 respectively. [Table and initialization](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithassam.c#L46-L69), [header](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithassam.h#L1-L13).

### Lifecycle

- **Initial airborne arrival, state 3:** initialization clears command variables 0 and 1, invokes shared setup using attribute x0, enters airborne state 3, and invokes the sound helper. Arrival animation and physics delegate to shared Pokémon helpers. The physics wrapper discards its helper's boolean result. Terrain processing invokes the landing adapter on floor contact; that adapter performs velocity-reset setup and enters state 0. The shared collision wrapper returns false even when its event callback changes state. Shared terrain processing also restores model scale after invoking the landing callback. [Arrival callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithassam.c#L357-L375), [shared arrival helpers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_279C.c#L1106-L1130), [floor-event processing](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/itgroundcoll.c#L583-L613).
- **Post-landing startup, state 0:** entry installs effect-hitlag callbacks, resets root-motion bookkeeping, and samples dynamic bone 2. Animation updates resample that bone and enter state 1 when animation activity ends, while returning false. Physics performs shared root-motion processing and applies the common falling helper only for GA_Air. Terrain dispatch selects separate air and non-air helpers with the same empty event callback. [Startup family](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithassam.c#L78-L130).
- **Timed run and targeted leap, state 1:** entry loads the timer from x18, initializes horizontal velocity and persistent movement x from x4 times facing, and clears persistent movement y/z. Animation loops independently of the two timer phases. On the first strict-negative timer expiry, the launch helper replaces the persistent vector and velocity, a facing change starts the turn counter at 1, command variable 0 becomes 1, the timer reloads from x1C, and the shared airborne helper is called. The second expiry enters state 2. Terrain maintenance is skipped whenever command variable 0 is nonzero; this is not evidence that all hit detection is disabled. [Active-state implementation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithassam.c#L204-L289).
- **Camera-directed departure, state 2:** entry computes a fixed normalized camera-minus-item vector scaled by x4, stores it in hassam.x5C, clears ordinary velocity and facing, and resets model yaw. Physics invokes the shared root-motion helper and directly adds the fixed vector to position. The collision callback is inert; the animation callback reports true when animation activity ends. The camera-directed vector is sampled at entry rather than continually retargeted. [Departure family](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithassam.c#L292-L355).

### Targeting and movement details

The selector searches the fighter list using relationship, status-bit, and conditional team filters. It prefers the strictly nearest squared XY distance among sampled positions strictly above the supplied position. Equal-distance candidates do not replace the current selection. If none qualifies, it delegates to ftLib_8008627C; the launch caller separately falls back to the owner if selection returns NULL. The target point receives vertical offset x8; a vector initialized from x4 is rotated using atan2f and receives vertical addition xC before being copied into velocity. The selector's declared Item_GObj types must not obscure its effective fighter-object usage. [Selection and launch](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithassam.c#L132-L202).

Root-motion extraction and movement have separate persistent data paths. The shared extractor records scaled bone-translation deltas and history, then clears the source bone translation. Its physics consumer overwrites velocity x and y, but not z. Consequently, state 1's subsequent vector additions do not cumulatively accelerate previous-frame horizontal velocity. Its airborne gravity acts on persistent hassam.x5C.y and clamps that component to -x10. State 2's direct position addition is distinct from the shared helper's velocity writes. [Shared root-motion implementation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_279C.c#L1145-L1200), [active physics](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithassam.c#L261-L276).

Turn processing adds MTXDegToRad(180 / x20) to current yaw and clears the counter when its preincremented value exceeds (u32)x20. Starting at 1 means this is not 'more than x20 rotation updates'; arbitrary attribute values also do not justify an unconditional exact-half-turn guarantee. [Turn arithmetic](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithassam.c#L232-L255).

### References and semantic review

The reference-invalidation wrapper forwards both objects to shared cleanup, which may clear the owner and interaction references and resets source-player attribution to 6 when clearing the fighter reference. The later launch path still uses the owner as a fallback, so owner validity across this lifetime boundary is not established locally. [Wrapper](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/kinds/ithassam.c#L73-L76), [cleanup](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/it/it_26B1.c#L491-L525).

Most existing names and explanations remain useful and are explicitly retained in the checkpoint ledger. The rendered Destroyed name overstates the demonstrated role of the static empty terrain callback; a no-op terrain name is better supported. Other corrections address stale phase uncertainty, turn-counter arithmetic, and velocity-versus-position semantics. The renderer reports no parse errors, but leaves the target selector unchanged with shadowed_binding. Rendered helper names were not treated as proof. No compiled section sizes, layouts, padding, or literal-pool bindings are established by this review.
