## Special-command processing
The N, Lw and Hi dispatchers check kind-indexed callbacks and require command age `x689`, `x687` or `x686` to be zero. Their grounded designation describes the callback table, not a local ground-state test. Directional predicates read pressed-button input: down is strictly below the negative threshold, while up includes equality at the positive threshold. Input processing resets or saturates these ages and saves the previous Hi age in `x68B`. Press/release masks derive from transitions, with optional accumulation; held-level triggering must not be inferred. The restricted aerial Hi path checks **SpecialHi** but invokes **SpecialAirHi**, additionally requiring `x68B >= p_ftCommonData->x1C`. ## In-place item acquisition and buffering
Immediate and buffered input checks require an empty primary item slot, held LR input, pressed A, clear `x2224_b1` and the numeric `x683` threshold. One arms `x209C` from common data; the other searches immediately with mask 1. Recurring service checks only nonzero `x209C`, searches before decrementing, sets the latch on expiry and may still acquire on that tick. It does not revalidate arming guards. Acquisition uses the secondary slot when a primary item exists, runs pickup bookkeeping and attachment, processes immediate-item effects, spawns effect `0x422` and sets the latch. Attachment-part selection tests the primary item's kind even when the acquired object occupies the secondary slot. Immediate-item processing may consume the item or replace fighter state. Service occurs in recurring fighter processing before the animation callback, not necessarily every wall-clock frame. ## Kirby multi-jump selector
`ftCo_800D7268` returns zero for non-Kirby fighters and delegates for Kirby. The inherited delegate review identifies one for Captain Falcon, Sheik, Popo, Nana or Samus copy kinds and zero otherwise. Multi-jump setup uses this integer to shift a pointer by one s32 element when selecting the motion base. This does not prove a different vertical-velocity entry: with a stable selector, the selected base cancels in the velocity-index subtraction, leaving `jumpsUsed - 1`.
