# Opening-mode semantic review

## State and routing
The unit provides sentinel-terminated opening and debug-cutscene state tables. Opening states are 0: opening movie, 1: VS demonstration, 2: title, 3: VS demonstration, 4: How-to movie, and 5: Omake15 movie. Both VS entries share static payloads. Table order does not prove every runtime transition.

`onExitTitle` belongs to `GS_TITLE`, not Event Match. At runtime debug level at least `DbLKind_DebugRom`, its first-match flag priority is 0x100 → debug VS, 0x1000 → menu, 0x400 → sound test, then 0x800 → debug. Below that level, only 0x1000 is handled: bookkeeping precedes `gm_80173754(1, 0)`; menu is selected only when that predicate is false, while a new-mode request is marked pending either way. Unrecognized flags cause no local transition. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmopeningmode.c#L281-L306)

## Demonstration configuration
`gm_SetupTitleDemo` builds eligible character and stage pools, sorts by ascending byte usage counts, and samples the first eight entries. Four characters must be distinct, with Zelda and Sheik additionally conflicting. Accepted fighters receive color zero and increment their history counters. Two retained player slots are drawn in 0–3, retrying the second until distinct. Stage selection converts the selected candidate and rejects equality with the previously exposed stage value. Match kind is drawn in 0–3. Pool-size safety, retry termination, and counter saturation are not established: sampling is fixed at eight, retries are unbounded, and history counters are bytes. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmopeningmode.c#L308-L427)

Accessors retain configuration across generation, preload, and match construction without validating indices or values. Character/color arrays, selected slots, and match kind have u8 backing storage; stage storage is u16 but its getter returns u8. Deferred state storage is s8 and its getter returns u8. Setter interface types do not guarantee arbitrary-value round trips. The deferred state is applied by `gm_Mode_Opening_OnLoad`, rather than immediately by its setter. [Accessors](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmopeningmode.c#L505-L573), [storage](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/types.h#L1091-L1102), [consumer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmmenu.c#L64-L67)

## Resource preparation and match construction
`gm_PreloadTitleDemo` copies four character/color pairs and the exposed stage into the shared DVD cache and requests reconciliation. Its audio mask begins at 4, includes character masks except for CHKIND_NONE, and includes the stage mask. Audio arguments 0x1E and 0xE are category flags: request entries are first marked -1, then selected entries are marked 1, followed by load initiation. The helper does not call the separate completion-wait API. The proposed data-flow correction and the unresolved interpretation of 'synchronous' are consistent. [Caller](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmopeningmode.c#L429-L458), [audio implementation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbaudio_ax.c#L1684-L1851)

`onEnterVs` initializes StartMeleeData, installs retained match kind and stage, disables timing and pausing, sets speed to 1.0, and registers `gm_80183218`. Four CPU players receive retained characters/colors, level 9, and CPU kind 4. Only numeric match kind 1 explicitly receives 99 stocks; other numeric kinds and unknown flags remain unnamed. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmopeningmode.c#L462-L503)

The cross-file controller uses the selected slots for camera and CPU behavior: focus first at 0x190, switch to second at 0x280 or when the first player's predicate is zero, and restore standard settings at 0x370 or when the second predicate is zero. Start/A and timeout at 0x4B0 exit earlier. Timeout includes a scene-index-3/parity branch selecting state 0. Restoration does not visibly advance controller state 2. [Evidence](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gm_181A.c#L1015-L1095)

## Cutscenes and movie lifetimes
The Luigi initializer ignores its argument and seeds shared cutscene descriptors with flags, fixed 0xE values, bounded random values, and a separate fighter configuration seeded with 8. These descriptors are consumed beyond the callback. Regend congratulations exit unconditionally requests GM_TITLE. [Initializers](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmopeningmode.c#L575-L643), [VI consumer](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/vi/vi0401.c#L135-L206)

Movie entry sets up the versus cache, clears persistence flag 1, and reconciles. Clearing this flag is not immediate unconditional resource destruction: unchanged descriptors can return early, and retirement depends on scores and numeric states. [Callback](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmopeningmode.c#L645-L652), [cache implementation](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbdvd.c#L446-L567)

Opening-movie, How-to, and Omake15 exits share `lbMthp_8001F800`. Shutdown is a no-op with power zero; otherwise it clears unk_70, polls outstanding work, cancels the alarm, waits for framebuffer flushing, conditionally frees storage, and clears power last. Sequential repeated shutdown is guarded; concurrency safety is not inferred. [Callbacks](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/gm/gmopeningmode.c#L654-L667), [teardown](code://c302741689bd67c361cd7faadb221df3193992c3/src/melee/lb/lbmthp.c#L637-L654)
