Object reference

StateEnvelope

The durable record for one domain state machine: who it belongs to, what revision it is on, and what is holding it. Two micro-variants of the same row anatomy follow — identical in every respect except where the type sits on the first line.

2A

Tab stop

Type begins at a fixed 164 px tab stop after the name.

Identity

idStateObjectId

Stable identity of the state object.

game_idGameId

Owning game.

kindStateKind

Domain state-machine kind.

Lifecycle

statusdomain-specific enum
  • A value owned by this state kind.
  • Vocabulary is domain-specific; the envelope never interprets it.
revisioninteger
  • Monotonic accepted-transition version.
  • Increments only on accepted transitions; used for stale-write protection.
created_attimestamp

Wall-clock time the object was first written.

updated_attimestamp

Wall-clock time of the most recent accepted revision.

Tracing

trace_idTraceId

Root trace for the object.

caused_by_event_idEventIdoptional

Event that produced the current revision.

Structure

blockersBlocker[]

Blocker

Stable machine-readable blocker code.

messagestring

Human-readable explanation.

source_kindstring

Kind of the object that raised the blocker.

source_idstring

Identity of the raising object.

recoverableboolean

Whether the blocker can clear without operator action.
