# ftFalco — Falco (`ftFc_`)

Fox's clone with the opposite flavor: higher jump, slower fall...ish, and a
Blaster that **stuns** (hitstun on lasers = the best neutral tool in the
game) plus the pillar combo (down-air → shine). Only `ftFc_Init.c` is split;
specials parallel [Fox's](ftFox.md):

- Blaster (neutral B) — slower rate, but lasers cause hitstun
- Falco Phantasm (side B) — shorter Illusion, spikes airborne foes
- Fire Bird (up B) — weaker Fire Fox
- Reflector (down B) — shine that pops foes up, enabling pillar combos
