# ftZakoBoy — Male Wireframe (`ftBo_`)

The blue wireframe hordes of Multi-Man Melee ("zako" = small-fry mook).
Built on Captain Falcon's skeleton with a stripped moveset, no specials, and
kamikaze AI. Only `ftBo_Init.c` is split. Spawning:
`gr/grzakogenerator.c`; female counterpart: [ftZakoGirl](ftZakoGirl.md)
(Zelda-based). See also `it/itzako.c`.
