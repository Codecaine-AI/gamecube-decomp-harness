# ftGigaKoopa — Giga Bowser (`ftGk_`)

The monstrous secret boss (Adventure mode's true ending fight): a scaled-up
[Bowser](ftKoopa.md) with elemental effects added to his moves (freezing
fortress, dark klaw). Only `ftGk_Init.c` is split — he reuses Bowser's
moveset code with Giga-specific attributes/effects layered on.
